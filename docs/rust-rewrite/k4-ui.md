## 外壳给的接口

外壳（`dr-shell`）有一份书的快照，各个视图从快照读，经工作区的命令写。结论和细节在 [f6-shell.md](foundations/f6-shell.md) 的「K4-0」各节。

1. **书的快照** `book.v3()`：条目树、模板、每个层级的有效设置（含来源，在 `levels`）、归属、时间线视图；从 v3 的查询读，书变了就刷新。
2. **导航**：`Target::Entry { id, module }`（可以带模块 id，跳到某一篇正文）、`Target::Template`（模板编辑器）、`Target::Material`、`Target::Book`。标签、前进后退、页内位置跳转照旧。
3. **页面怎么拼**：
   - 叶子页按模板里模块的顺序，一个模块交给一个**模块渲染器**画，注册口是 `dr_shell::v3` 的 `add_module_view`（按模块种类）。
   - 层级页由三块组成：这一层的说明、下面的条目（按「显示」设置交给**显示渲染器**画，注册口 `add_level_display`；左栏和层级页共用一个渲染器，`LevelHost.surface` 区分）、这一层的设置。
   - 渲染器拿到的 `Rendered` 要接 `on_refresh`，刷新时不能冲掉没提交的输入。
4. **条目的记号和颜色**：一个公用函数。按模板的记号和颜色画；章节这类叶子的颜色跟主归属的泳道走。未知的记号退回通用方印，不丢原值。
5. **左栏**：每个顶层层级是一个标签。小说模板默认是书稿、构想、要素、故事线四个。标签里的内容按那一层的「显示」设置交给显示渲染器。左栏底部是模板集合。
6. **条目的悬停卡**：公用的头部和操作行（打开、新建、编辑模板、换模板、归属到、放进最近删除）；各模块用 `add_entry_action`（`EntryAction::{New, ChangeTemplate, BelongTo}`）和 `add_entry_card_rows` 往里加自己的行。
7. **其他注册口**：`add_template_creator`（模板编辑器）、`add_v3_bottom_panel`（底部时间线）。
8. **开发手段**：种子 `seed:v3-tiny` / `v3-lite` / `v3-heavy` / `v3-showcase`（普通的 `seed:<preset>` 现在也生成 v3）；调试桥能打开书、读出页面的状态。

## 仍然有效的规矩

- **作者看到的照旧，但先求能用**：用小说模板的书，结构和操作和切换前一样。样式不用一模一样：先用 `dr-ui` 现成的组件，间距、动画、颜色这类细节等作者安排打磨时再做（2026-11-11 作者定：视觉打磨暂缓）。
- **不放松的**：功能和数据正确性（见「写入不能拿读到的整份去替换」），包括输入与输入法结果、保存／恢复、焦点与导航目标正确、滚动定位不串位。相关测试照旧保留；打字时延、滚动流畅度和视觉细节的打磨暂缓，不能用暂缓为丢字、误写或功能未通放行。
- **写入不能拿读到的整份去替换**：第 49 批（G1 情节规划）和第 53 批（K6 时间线）都因为这个被退回——先读一份（或者只读到过滤后的一部分），改一处，再整份写回，会把别人刚写的、或者没读到的数据冲掉。改用带版本守卫的写（`Workspace::call_guarded`）或者逐项命令；冲突时拒绝旧的写入，保留作者的编辑，不能静默成功。每组都把「两次各自成功的写入不互相覆盖」「没显示的数据不被整份写入删掉」写成自己的永久测试。
- **自己的地方随便改；公共的地方只加不改**（2026-11-10 作者定）：上表里归自己的地方照旧随便改。外壳的 v3 注册口（`dr_shell::v3`）、内核的 v3 命令和查询（`dr-workspace` 的 `commands/v3`、`dr-doc` 的 `v3` 读写）、`dr-ui` 组件这类公共地方，**新增**一个注册口、命令、查询或参数，谁需要谁自己加，带上测试，在交回里写明。要**改动**公共地方已有的行为或签名，照旧先写进待协调，交给监管会话安排，不自己直接改。
- **文案**：新文案写进 `dr-i18n` 的 own，九种语言都写；不自编说明文字。
