## 公共部分

### 规矩

先读仓库根的 `AGENTS.md` 和 [README.md](README.md)（「做的时候」「真窗口验收」「不能替作者做的」三节全部适用）。最容易出错的：

- **只做自己那一节写的。** 作者这次定的形状在 kernel-v5 第 15 节第 51 到 57 条，做的时候非定不可、建议里又没说到的，会话照常理补的在 kernel-v5「替作者定的」最后一组。照那里做；那里也没说到的，写进交回报告的「等作者的事」，按最保守的做法先做，不自己另设计。
- **范围**：只改自己那一节列出的 crate 和文件。确实要动别处时做最小改动，在交回报告里逐处列出原因。数据层（`dr-model`、`dr-doc`、`dr-workspace`、`dr-store`）的接口只加不改；觉得不够用写进报告。
- **worktree 和构建**：用自己的 `next/target`，`CARGO_BUILD_JOBS=3`，测试 `RUST_TEST_THREADS=1`；字体从 `~/Drifting/next/.cache/fonts` 拷到自己的 `next/.cache/fonts`。不在主检出（`~/Drifting`）里构建或改文件。
- **不推送、不开 PR、不合 `main`、不打标签。** 提交说明用英文，不加署名行。
- **界面文字一律写「Agent」，不加靠颜色区分的东西，没有右键菜单，不加作者没要的说明文字。** 文案只加删自己的键，照 [README.md](README.md) 的写法，九种语言都写；`locales/*.json` 是生成的，不手改。
- **测试**：改了期望的、删了的测试，在报告里写改前改后和原因。不许为了通过而放松断言、加重试或 `#[ignore]`。测试数据只用 `dr_testkit::seed`、`dr_testkit::samples`、`dr_testkit::media`。
- **日志和验收证据**放 `~/Drifting-autopilot-logs/v5f-<路>/`，不放进任何工作区。

### 交回

1. 交回前 `git merge main`，在合并后的树上跑，全部通过才算做完；哪条没跑、哪条是红的，如实写：

   ```bash
   cd next
   cargo fmt --all --check
   cargo clippy --workspace --all-targets --locked -- -D warnings
   RUST_TEST_THREADS=1 DR_UI_REQUIRE_FONTS=1 cargo test --workspace --locked --no-fail-fast
   cargo xtask check
   python3 crates/dr-i18n/script/sync-locales.py --check
   cd .. && pnpm public:check && pnpm ci:contract:check
   ```

2. 真窗口冒烟自己这一路的功能：`cargo xtask dev --debug-bridge` 加 `cargo drifting app …`，或一个场景加 `--app target/debug/drifting`。
3. 更新自己涉及的模块结论文档。不改 `progress.md`，过时的写进报告。
4. 建交回指针 `git branch -f handback/v5f-<路> HEAD`。报告用中文，先说大白话（做了什么、作者会看到什么不同），再列改了哪些文件、出了范围的改动、删了和改了期望的测试、检查结果、真窗口结果、等作者的事、分支和提交号。

### 各路之间

## TS 项目模板和「全部项目」的小修（`ts-template-shelf`）

- **开工条件**：现在就能开工。
- **依据**：kernel-v5 第 15 节第 52 条「新建模板没改就关」「失败的提示」「忙的时候一起锁住」，第 53 条「三个导入一律两行」「去掉从一张白纸开始」；「替作者定的」最后一组「失败的提示画现有的警告记号」「新建模板没改就关」。
- **范围**：`dr-view-templates`（`lib.rs`、`view.rs` 新建草稿那一段）、`dr-shell`（`workspace/mod.rs` 的 `template_created`，`workspace/toast.rs`）、`dr-view-home`（`save_template.rs`）、`dr-view-shelf`（`templates.rs`、`view.rs` 的 `rail_cell` 和 `new_card`）、`dr-i18n`；文档 [m01-shelf.md](../modules/m01-shelf.md)、[m02-home.md](../modules/m02-home.md)、[project-templates.md](../project-templates.md)。
- **要做的**：
  - 左栏没铺满时点「新建模板」：现在先存一个「未命名」（`view.rs` 的 `new_draft`）、由外壳开一颗药丸。关这颗药丸时，模板还和刚建出来时一样，就直接删掉这份模板，不进最近删除、不留撤销；改过一处就照常留着。左栏铺满时的浮窗草稿照旧。
  - 窗口底部的提示分成功和失败两种：失败时不画对勾，画另存对话框底部失败那一行用的警告记号（`toast.rs` 现在写死 `Icon::Check`）。调它报失败的地方都改成失败那一种。
  - 失败的字：另存失败「没能另存为模板，请重试。」（`save_template.rs` 原来的 `k4Pages.saveFailed`），读不出当前项目「没能读出这个项目。」，新建项目失败「没能新建项目，请重试。」（`templates.rs` 原来的 `common.saveFailed`），悬停卡「编辑」模板打不开「没能打开这个模板。」（`dr-view-shelf/src/view.rs` 原来的 `common.saveFailed`）。新加四个键，九种语言；原来借的键别处还在用的留着。
  - 忙的时候：另存对话框的名字、描述、写给 Agent 三个输入框跟着按钮一起锁；新建项目对话框里「我的模板」的展开收起也锁。
  - 「全部项目」左栏的导入项目、导入模板、导入（Drifting 0.1）三行一律两行：名字一行、后缀一行，任何字号都这样。「最近删除」后面的数字照旧。
  - 「新建项目」卡去掉「从一张白纸开始」那一行，只留「＋」和「新建项目」；`projectPicker.desk.newCardSub` 没人用了就删掉。
- **回归测试**：新建模板没改就关以后书库里没有多出模板，改过一处再关留着；四处失败各出对应的字和警告记号，成功的提示照旧是对勾（照 `dr-view-home/tests/v5_pt3_template_ui.rs` 的写法注入失败）；忙的时候三个框打不进字；三个导入在默认字号和最大字号下都是两行（量行高）；新建项目卡上没有小字。
- **真窗口**：简体中文和英文各截一张「全部项目」页，三个导入两行、新建卡没有小字；新建模板点开就关，「我的模板」里没多出「未命名」。

- **要做的**：
  - **左栏的悬停卡**：指针停出来的卡也贴在这一行右边，上沿和这一行齐，和按空格开的一样（现在指针的卡在这一行下面、盖住下面几行，`hover_card.rs` 的默认位置）。右边放不下照键盘那张卡现在的规矩翻到左边、收在窗口里。只改左栏；正文里的链接、底栏卡片的悬停卡照旧。
  - **只留一张**：键盘开着一张卡时指针停出另一行的卡，键盘那张收起，键盘停在它那一行，还在左栏里。
  - **右栏铺满动画里月亮挡住下面**：`moon_pair` 那一块吃掉点击，不往下传给拖窗条（现在没有 `.occlude()`，那 420 毫秒里双击会让窗口缩放）。左栏的月亮也一样处理。
  - **1 倍屏的月亮**：窗口的缩放倍数小于 1.5 时月亮的线描粗、描深。先做成一个参数，在 1 倍屏上截三档：现在的、粗半档、粗一档，左栏收着、开着、铺满各一张，加指着后面那颗各一张，放 `~/Drifting-autopilot-logs/v5f-sf/`，写进交回的「等作者的事」由监管会话转给作者挑；挑定之前参数照现在。2 倍屏不动。
  - **层级表的插入线**：拖动时最上、最下和每两行之间都能放，画一条插入线，放下是调先后（`entry.move` 带 `index`）；放在最外层两行之间就是搬到最外层。拖到一行上照旧是搬进它下面。不能放的地方（拖进自己下面、层级关着的）照现在不收。
  - **审阅铺满的列数**：铺满宽减 24 除以 310 取整，1 到 6 列（现在除以 275）。素材库瀑布流照旧。
  - **空着的说明**：不进成书的正文模块空着时只留一行高，写了字往下长；进成书的照旧至少 160（`v3.rs` 现在一律 `min_h(160)`）。按模块的「进成书」开关认，不认模块名。点那一行就是光标进去，不加提示句。
- **回归测试**：左栏指针停出的卡在这一行右边、不盖住下一行（量位置）；键盘开着卡时指针停出别的卡，只剩一张、键盘在原来那一行；右栏铺满动画中途点月亮的位置不触发拖窗（模拟按下）；层级表拖到两行之间调了先后、拖到最外层两行之间搬到最外层、一步撤销；审阅铺满在几种宽度下的列数；空的说明一行高、写了字变高，空的进成书正文照旧 160。1 倍屏的画法测一条缩放倍数 1 和 2 下线宽不同。
- **真窗口**：左栏指着几行看卡的位置；右栏铺满的动画里点月亮；结构里拖一行到两行之间；打开一条故事线看空的说明；1 倍屏的三档截图（没有 1 倍屏的显示器就照缩放倍数 1 起一个窗口截）。

- **范围**：`dr-agent`（`proactive/checkin.rs`、`proactive/state.rs`：出错时存一个原因的种类，不只存一句英文）、`dr-view-agent`（`controller/proactive.rs`、`home_cards.rs`）、`dr-i18n`；文档 [m30-long-tasks-memory.md](../modules/m30-long-tasks-memory.md)、[m02-home.md](../modules/m02-home.md)。
- **要做的**：
  - 「没能看完最近的改动：」后面按原因写：网络、服务不可用、超时写「连不上模型」；上下文装不下写「最近的改动太多，一次看不完」；回复格式不对、结构不对、超过四张、太长、想调工具或联网、没有结束标记写「模型的回复读不出来」。现在一律存成 `suggestion request did not complete`、显示「请求失败（provider 不可用或网络问题）」。

  - 只要有一张卡在开始，或者在看（从请求查看起，包括读改动、算 90 分钟那几秒），整块卡和 × 都点不动，× 画成点不动的样子；在看的那几秒也出「Agent 正在看你最近的改动……」那一行。

## RL2 关系界面的小修（`rl2-relations`）

- **开工条件**：现在就能开工。

- **要做的**：
  - **回车**：正文建关系那一条的 @ 框回车选第一个候选，名字框回车就是「建立」（对方和名字都有了才算，不然什么都不做）；关系图 Shift 点两头以后的名字框回车也是「建立」。拼音组字时的回车不算。现在 `relate.rs` 和 `compose.rs` 把回车丢掉了。
  - **@ 的找法**：建关系、批注、关系描述、右栏「＋」里的 @ 都照正文的 @ 找：标题、别名、拼音首字母。候选范围照各处现在的（建关系和右栏是全书活着的条目）。找法写成一个都能用的函数，放在这几个 crate 都依赖得上的地方，接口加在那里，不复制一份。
  - **条目页几篇正文之间的连线**：指针停在一篇正文的名字上，这一页别的正文里看得见的名字也连，线画在整页这一层；同一个名字在几篇里都出现时取离指针下那一处最近的。指着右栏一行时也一样。整书视图照旧。
  - **关系图的名字**：先画点中那张卡连着的和指针指着的那条，再按线的先后画别的；压到已经画了的名字或卡上的先不画，指到那条线上、或点了它连着的卡才出。
  - **重了的一行**：右栏卡上新加的一行有一对已经在这种关系别的行里，草稿下面写「「地保 → 阿Q」已经在另一行里。」（双向用 ↔，重了几对只说第一对），那一行滚到看得见、亮一下；草稿留着。现在只写「未能保存」「重试」。哪一对重了、在哪一行，界面照读到的行先算出来再提交；命令照旧整次拒绝，当最后一道守卫。
- **回归测试**：两个框里回车的四种情况（有候选、没候选、组字中、名字或对方空着）；三处 @ 用别名和拼音首字母找得到；条目页两篇正文之间连出一条线、同名取最近；关系图上叠在一起的两个名字只画一个、指着那条线时出另一个；重了的一行出那句话、那一行亮、移出重了的人再加别人就存下。
- **真窗口**：样书《阿Q正传》里打开一个有两篇正文的条目页悬停一个名字；关系图铺满看阿Q 周围；右栏「欺辱」里加一行「地保 → 阿Q」。
