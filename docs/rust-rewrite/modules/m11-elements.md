## 一句话

打开一个要素，正文上面是它的页眉、名字、别名、一句话概述和「记 · 传」的节头，正文下面是「字段」，都能直接改、照旧版的时机保存；打开一个类目，正文上面是页眉、大的折角记号和名字、要素数和色标、「札记」的节头，正文下面是「要素清单」，可以按「已填写 / 未填写」筛。第二个里程碑加了要素页 ⋯ 菜单里的「更改类目」「更改分组」「删除要素」和类目的「删除类目」，以及左栏的要素面板（紧凑索引 / 名称列表、排序、折叠、分组、类目的「+」）；第三轮把这几行登记进外壳的 ⋯ 菜单，面板挂进外壳的左栏。关联、补丁、两种模版、引用、帮手改字段的演示还没做（见「还没做的」）。

### 第二个里程碑（大白话）

- **提醒和对话框走外壳的模态层**（`dr_shell::dialogs::show` / `hide`）。整个程序一个要素对话框（`dialogs.rs`），一次一个：名字或别名被占的提醒、更改类目、新建类目、分组、删除要素、删除类目。打开时光标给它；Esc、点雾或它自己的按钮关掉，外壳把光标还给页面。对话框开着时，工作区的快捷键都不响（外壳的规矩）。
- **更改类目**（宽 360）：每个类目一行（记号和名字，当前的加粗、行尾一个勾），最后一行强调色的「+ 新建类目…」。点一个类目就搬过去、关掉。「新建类目…」换成一个输入名字的对话框，回车或「创建」就建好并把要素搬进去；名字空着什么也不做。
- **分组 · 类目名**（宽 420）：上面一个输入框（光标在里面），下面「（不分组）」、这个类目已有的分组（按拼音，当前的加粗带勾，输入的字会筛它们）、输入的是新名字时最后一行「新建分组「沈家」」。回车就用输入的名字（空着就是不分组）。
- **删除**：旧版的通用确认框（`requestConfirmation`）：标题「确认」，正文是旧版那句「删除要素「沈知微」？」（类目是「删除类目「人物」？」，空一行再一句「这个类目下的要素会移到「未分类」……」），「取消」在前、危险色的「确认」在后。确认后要素进废纸篓，外壳自己关掉它的标签；类目进废纸篓，它的要素都变成未分类。失败照旧版弹「删除要素失败，请重试。」之类。
- **⋯ 菜单的几行**（`menu.rs`）：要素页「更改类目」（类目记号）、「更改分组」（文件夹）、细线下面危险色的「删除要素」（字纸篓）；类目页只有「删除类目」。每行就是打开上面对应的对话框。第三轮：`menu::register` 在 `dr_view_elements::init` 里把这几行交给外壳（`pages::add_page_menu`），外壳的 ⋯ 菜单和章节面板的悬停卡读的是同一份清单：「分享」在前，这几行在中间，然后「历史快照…」，危险行在最后、细线下面。「更改类目」那行就是类目的折角记号（F6 第七轮让菜单行收 `RowIcon`）。
- **左栏要素面板**（`panel.rs`，照旧版 `ElementPanel`）：
  - **头一行**：「3 类 · 24 要素」，点它在紧凑索引和名称列表之间切换；右边要素全景、展开 / 折叠全部（有折着的就全展开，否则全折上）、排序菜单（「排序类目内要素」：按字母顺序 / 按创建时间；「外层类目」：同样两种）、「新类目」（建一个叫「New Category」的类目，颜色在六种故事线色里挑一个，不跳过去，照旧版）。
  - **顺序**：类目按名字（中文按拼音，数字按数值、不分大小写，和 dr-editor 排名字同一个 ICU 排序），名字正好是 `others` 的放最后，「未分类」（有要素没类目时才有）放在最最后；或者按创建时间新的在前。类目里先是有名字的分组（按名字），再是不在分组里的要素。新旧两版的 id 都是 UUID v7，id 的先后就是建立的先后，「按创建时间」直接按 id 排。
  - **名称列表**：类目头（折叠箭头、类目记号、结构字的名字、「· 7」，指针下出一个 +；点名字打开类目页）；要素是侧栏格子（要素记号取类目颜色、名字、等宽的日期：今年写「11/08」，往年「25/12/31」，面板窄于 200 px 不写）；分组头（一小横、名字、「· N」，指针下一个 +，双击原地改名，改的是这个分组里每个要素的分组名）。
  - **紧凑索引**：每个类目一圈类目颜色的砂笔框，名字写在切进框里的一块底色上，右边一个 +；要素是一块块会换行的小格，宽度跟着名字长短（80 到 172 px），选中的那块一圈砂笔；分组是一个细线框。折上的类目框淡出；空类目一直折着、没有折叠箭头。
  - **类目的 +**：浮出「新增至「人物」」的小菜单：「新建要素」（建一个叫「New Element」的要素，打开它）、「新建分组…」（换成一个小表单：分组名称、已有同名时强调色的「已有同名分组。」、「返回新增菜单」和「创建并打开首个要素」）。
  - 单击预览、双击留下，和别的侧栏一样。
  - `make_panel` 给出列表和头一行两个视图。第三轮外壳有了挂接点（F6 第七轮 `pages::add_left_panel`）：`dr_view_elements::init` 登记「左栏的『要素』由这个面板画」，外壳每一半第一次显示这个标签时做一个、一直留着，头一行放在标签下面那一行，外壳自己那份要素列表就不画了。
- **作品主页不再自己记「最近打开」**：外壳换前台页面时已经调 `recent.touch`（F6 第五轮），主页那段删了，测试照样过。

## 做了什么（大白话）

1. **挂在正文的上下。** 要素页、类目页本来就是外壳打开的编辑器（正文是它们的「记 · 传」「札记」）。dr-editor 留了在正文上下放东西的位置（`PageChrome`，跟着正文一起滚）；外壳打开这两种页的编辑器时，问一下有没有模块要往上放东西，M11 就把自己的两块交给它。
2. **要素页，正文上面**（照旧版 `elem-overview`）：
   - **页眉**：等宽小字「要素 · （折角记号）人物」，有分组时「人物 - 分组名」；没有类目就只写「要素」。下面一条点线。
   - **名字**：正文字体 38 px、中等字重，没有框，会换行。回车离开，Esc 放回原来的名字再离开，离开就保存；空的或没改不写（框里空着时显示「未命名要素」）。名字和另一个要素的名字或别名撞了（不分大小写），弹出旧版那句「无法重命名：“陆远舟” 已被要素「陆远舟」使用（名字或别名冲突）。」，框里放回原来的名字。
   - **别名**：平的字，用「·」隔开；指针下的那个出一圈侧栏格子的细玻璃环和 ×，点 × 去掉。末尾是一个不装框的输入（没有别名时占位字「添加别名」，有了以后「别名」）：回车或离开就加上，Esc 清空。和自己已有的重复就什么也不做；被别的要素占了，弹出「无法添加别名：“远舟” 已被要素「陆远舟」使用。」
   - **一句话概述**：正文字体小两号、次一级的墨，回车换行，Esc 放回原文，离开就保存（不去掉首尾空白，照旧版）。
   - 下面一条细线，然后是「记 · 传」的节头（结构字 16 px，下面一条点线）。正文就是编辑器。
3. **要素页，正文下面：「字段」**（照旧版 `KvEditor`）：
   - 节头右边是文字按钮「+ 新增字段」：在末尾开一行，把光标放进字段名；末尾已经有一行空的，就只把光标放进去。
   - 每个字段一张静止细玻璃线的输入片，不垫底：左边字段名（等宽 12 px，140 px 宽），右边内容（正文字体 14 px，会换行）。光标在里面时整片是静止的选中玻璃；× 在指针下或光标在里面时出现。
   - 离开字段名或内容就保存这一个字段；名字和内容都清空再离开，这个字段就删掉；× 马上删掉。顺序不变。没有字段时写旧版那句「尚无字段。新建要素时，所属类目的「字段模版」会自动填入」。
4. **类目页，正文上面**（照旧版 `CategoryEditorView`）：
   - **页眉**：「类目 · （记号）人物 · 11 要素」。
   - **名字**：左边一个放大到 30 px 的折角记号（类目自己的颜色），右边名字，规则同要素的名字。
   - **两行读数**：等宽小字「要素数」「色标」，右边「11 个」（斜体）和 F5 的色块（`ColorSwatch`，28 px 的圆形玻璃，里面是类目的颜色）。点它打开系统的取色器（Mac 上是系统的颜色面板，Windows 是系统的颜色对话框），从类目现在的颜色开始；拖着选的时候页上的记号和色块马上跟着变，停下 0.3 秒才经 F3 的 `category.update` 存成 `#rrggbb`，所以选一次颜色是一步撤销。
   - 「札记」的节头，正文就是编辑器。
5. **类目页，正文下面：「要素清单」**（类目里有要素时才出现）：
   - 节头右边等宽「11 个」；下面多选一「全部 11 / 已填写 11 / 未填写 0」。「已填写」是有概述或者正文有字（正文的字数取派生索引）。
   - 每个要素一行：记号（正文没字是空心的），「E.」加四位编号，名字（正文字体 17 px）和两行概述（斜体；没有概述写「尚未填写概述」），右边一个「· / —」加「概述」的小标，指针下出现一个斜箭头。单击预览，双击留下，和侧栏一样。
6. **数据从哪来、到哪去**：读的是外壳那份书目快照（`dr_shell::book::Book`，书一变外壳就重读）；写走 F3 的 `element.update`（名字、别名、概述、字段）和 `category.update`（名字），都在后台线程。写完以后 F3 报书变了，外壳换上新快照，页面跟着变。帮手或另一个窗口改了，也这样跟过来；但**光标在哪个框里，那个框就不被换掉**，作者正在打的字不会丢（作品主页书名的那个教训）。
7. **文案**全是旧版九种语言的原话（`elementEditor.*`、`categoryEditor.*`、`kvEditor.*`、`storylineEditor.labels.color`、`storylineEditor.filters.all`）。

**要作者定的事：没有。**

## 和旧版不一样的地方

- **提醒用对话框，不用系统的 alert。** 标题写「Drifting」（系统 alert 的标题就是程序名），正文是旧版那句话，一个「关闭」按钮。浮在页面上、带雾，Esc 或点雾也关。
- **四位编号取 id 的后四位。** 旧版取前四位；新版的 id 是 UUID v7，前几位是时间，一本书里的要素都一样（截图里第一版全是「E.019A」），后四位是随机的，才分得开。
- **类目改成重名会加「 2」。** F3 的 `category.update` 这样做；旧版允许两个类目同名。
- **选颜色时停下才存。** 旧版的 `<input type="color">` 拖着选时每变一次就存一次；新版每次变化马上显示，停下 0.3 秒才存（`dr_view_elements::swatch::SETTLE`），一次选色是一步撤销，不是几十步。类目页和故事线页都是这样。
- **字段是一行一行存的。** 旧版离开任何一个框就把整张字段表写回去；新版只写这一行（F3 的 `put_fields` / `remove_fields` 按字段 id 改），效果一样，另一台设备同时改了别的字段也不会被盖掉。新开的一行存进去以后，等 F3 的新快照回来认领它的 id，在这之前不会再存第二次（不会多出一个重复的字段）。
- **离开名字框以后光标去了工作区**（旧版是让输入框失焦，焦点落到页面上）。
- **四句旧版没翻译的话换成了意思一样的旧版字符串**：旧版中文里「更改类目」对话框的标题（`elementEditor.category.change`）、新建类目对话框的标题、占位字和按钮还是英文（Change Category、New Category、Category name…、Create）。这里用 ⋯ 菜单的「更改类目」、左栏的「新类目」、「未命名类目」和「创建」（`storyGraph.edge.create`）。
- **名字排序用 ICU 的中文排序**（拼音，数字按数值，不分大小写），和 dr-editor 排名字一样。旧版是 WebView 的 `localeCompare`，跟着系统语言；作者的系统是中文时两者一样（汉字在拉丁字母前面）。
- **名称列表的类目头不吸顶**；旧版滚动时类目头停在上面。
- **面板的悬停卡、帮手改动记号没做**（见「还没做的」）。

## 外壳里改了什么

第三轮没有改外壳：⋯ 几行和左栏面板用的是 F6 的 `add_page_menu`（第六轮）和 `add_left_panel`（第七轮）。第一个里程碑一共三处，都只是挂接点：

1. `dr-shell/src/pages.rs`：加 `pages::add_page_chrome(cx, |target, ws, window, cx| Option<Rc<dyn PageChrome>>)`（模块登记「这种页的正文上下放什么」，第一个回答的算）和内部的 `chrome_for`；文件开头的说明加了一段。
2. `dr-shell/src/workspace/editors.rs`：建单篇编辑器以后、`set_title` 那一处，拿这一页的目标问一下 `chrome_for`，有就 `set_chrome`（共 8 行）。
3. 应用：`app/drifting/src/main.rs` 在 `dr_view_home::init` 后面加 `dr_view_elements::init(cx)`，`Cargo.toml` 加依赖一行。

另外：`next/Cargo.toml` 加成员和依赖各一行；`xtask/src/gates/layers.rs` 把三个新的界面 crate（书架、主页、要素）明写进层级表；`dr-i18n/keys.txt` 加了 30 个旧版的键，跑了 `sync-locales.py`。

| 别的页面想在正文上下放东西（M03 章节页、故事线、素材） | `dr_shell::pages::add_page_chrome`：对自己的页返回 `Some(Rc<dyn PageChrome>)`，别的页返回 `None` |
| 测试、调试桥 | `dr_view_elements::{element_page(id, cx), category_page(id, cx)}` 拿到打开着的页的视图；`ElementHead::{fields, remove_alias, alert}`、`Fields::{rows, add_row, remove}`、`CategoryHead::name_field`、`CategoryEnd::{elements, set_filter, filter, words_read}` |
| 第二个里程碑（关联、补丁、面板） | 关联节放在 `Fields` 后面（`lib.rs` 的 `Chrome.end` 换成一个竖排的视图）；数据读法见 `data.rs` |

## 测试

`cargo test -p dr-view-elements`：单元 3 个（拼音和数字的排序、小格宽度、日期写法），GPUI 测试平台上用 dr-testkit 生成的《慢钟》（经 F3 读写）的 19 个（其中 4 个是 M13 故事线页的）。

要素页和类目页（`tests/pages.rs`，10 个）：

- 打开沈知微的页：名字、概述是存着的值；三个字段的名字和内容和 F3 一样、顺序一样；这一页是外壳打开的编辑器（页头是模块挂上去的）。
- 名字：离开就保存；改成「陆远舟」（别的要素的名字）弹出提醒、框里放回原名、F3 里没变；Esc 放回存着的名字。
- 别名：回车加上；加「远舟」（陆远舟的别名）弹出提醒、没加上；× 去掉「知微」。
- 概述：两行的概述离开就保存，换行原样存。
- 字段：「新增字段」开一行、光标在字段名里；填好离开就存进 F3，这一行认领了新字段的 id、没有多出重复的；改第一行的内容离开就存；× 删掉一个；名字和内容都清空再离开，这个字段也删掉。
- 类目页：名字是「人物」；清单就是这个类目的要素，样书里每个人物都填写了；切到「未填写」；改名离开就存进 F3。
- 类目页的色标：点它打开取色器（测试换上自己的取色器，`color::set_color_picker`），从类目存着的颜色开始；选一个颜色，停下以后 F3 里就是它。
- ⋯ 菜单照外壳列的样子（`page_actions`）：「分享」，「更改类目」「更改分组」，「历史快照…」，最后「删除要素」，危险的那行在最后；「更改类目」带类目记号；从外壳的这一行点「更改类目」，点「地点」就搬过去；「新建类目…」输入「故人」回车，建好并搬进去。
- 分组对话框：光标在输入框里；输入「沈家」回车就是这个分组；空着回车就是不分组；Esc 关掉不改。
- 删除要素（旧版的「确认」框）：Esc 不删；确认后进废纸篓，外壳关掉它的标签；类目页的 ⋯ 最后一行是「删除类目」，点了打开确认，删除后它的要素都变成未分类。
- 名字、别名被占的提醒现在从外壳的模态层出来（测试读要素对话框问的是什么）。

故事线页（`tests/storyline.rs`，3 个）见 [m13-storyline.md](m13-storyline.md)。

要素面板（`tests/panel.rs`，5 个）：

- 类目按拼音是「地点、人物、物件与往事」；每个要素列一次；类目里按拼音；按创建时间时类目和要素都是 id 倒序。
