# M26 沉浸写作与打字机滚动

2026-11-09，F4e 这一路做编辑器这一半（分支 `claude/optimistic-goodall-6739a9`，从 main `eb221684`）。计划见 [modules.md 的 M26](../modules.md)。旧版的设计和验收在 `docs/editor/immersive-writing.md`：2026-11-03 作者在原型里选了「素纸 + 段」。外壳那一半（进出、收起界面、露出区）归 F6，F6 已经做了最基本的进出，下面「给 F6 的接口」写了还差什么、怎么接。

## 大白话

沉浸写作就是两件事：窗口里只剩稿纸（素纸），光标所在的那一段以外的字都淡下去（段）。打字机滚动是另一个开关：打字时光标那一行停在窗口里固定的高度上，字往上走，眼睛不用往下追。

- **谁做什么**：
  - 进出、把侧栏和按钮收起来、露出区，是外壳（F6）的事。
  - 纸上的事是编辑器的：段落淡出、打字机滚动、分清「作者在写」和别的写入。
- **段落淡出**：F4d 做了（`ProseEditor::set_paragraph_focus`），F6 已经接上（只淡拿着键盘的那个编辑器）。
- **打字机滚动**：F4b 做了开关。这一轮补了三处：
  - 沉浸时总是打开，用设置里的「输入行位置」；退出后回到设置本身的开关。
  - 「输入行位置」改了、窗口高度变了，光标不用等下一次按键，马上回到那条线上。
  - 输入法组字时不滚（滚了候选窗会在拼音底下跑掉），确认以后才回到线上。
- **打字时自动进入**：编辑器分清「作者在写」和别的写入，发一个事件，外壳收到后按「打字时自动沉浸」开关决定进不进。
  - 算作在写：打字、输入法确认、回车，素材笔记的表格格子里也算。
  - 不算：粘贴、拖入、删除、撤销、组字中、Agent 或宿主的写入。

**截图**：沉浸中的一页，光标在第六段，其余淡下去，光标那一行在打字机线上（窗口一半高）。外壳的界面收起由 F6 做，这里画的是编辑器本身：[浅色](m26/immersive-light.png)、[深色](m26/immersive-dark.png)。

## 编辑器这一半（已做）

| 接口 | 做什么 |
| --- | --- |
| `ChapterEditor::set_immersive(on, cx)` / `BookEditor::set_immersive(on, cx)`，`immersive()` | 沉浸开、关。开着时打字机滚动强制打开，用设置的 `typewriter_position`，光标马上滚到线上；关了回到设置本身（打字机模式开着就还开着）。主题、设置在沉浸中变了，照样强制开着。不管段落淡出。 |
| `EditorSettings::style_for(base, immersive)` | 上面那一条的样式：旧版的 `typewriterMode \|\| immersive` |
| `dr_editor::WritingTyped { doc }`（两个视图都发；独立的事件类型） | 作者在 `doc` 里写了字（规则见上）。全书视图给的是那一章的文档。 |
| `gpui_prose::AuthorTyped { chapter }`（`ProseEditor` 的第二种事件，和 `FindEvent` 一样独立） | 上一条的来源：`run_input_rule`（打字、输入法确认、跨章打字）和 `on_newline`（回车，组字中不算）里发。 |
| `ProseEditor::set_paragraph_focus(bool)`（F4d，已有） | 段落淡出到 0.26，换段 0.24 s 过渡。 |

`gpui-prose` 里打字机滚动的三处补充：

- **组字时不滚到线上**：`render/element.rs` 的预绘制里，光标所在段有组字时，退回普通的「露出光标」。确认的字照常回到线上。
- **线挪了就回线上**：`set_style` 时 `typewriter` 变成另一个值，记一笔；下一帧画完（`after_paint`）如果编辑器有焦点、是光标（不是选区）、没在组字，就要求滚动。
- **高度变了就回线上**：`after_paint` 记下上一帧的高度，变了照上一条处理。旧版对窗口大小变化也是这样做的（`ResizeObserver`）。

测试：

  - `input::tests::the_author_typing_is_told_apart`：打字、输入法确认、回车算；组字中、粘贴、删除、撤销不算。
- `dr-editor/tests/immersive.rs`（3 个）：
  - 沉浸强制打开、在沉浸中改设置和主题仍开着、退出回到设置；
  - 单章视图分清作者在写和粘贴、删除、组字；
  - 全书视图报的是写的那一章。
- `dr-editor/tests/note.rs`：表格格子里打字也报。

## 给 F6 的接口（外壳这一半，F6 接）

**F6 第十轮接上了**（`dr-shell/src/workspace/immersive.rs`，见 f6-shell.md「第十轮」）：1–7 都做了；8 里控件的淡出没做（出口悬停时直接出来）。同步云还没有，所以「不呼吸」这一条无从谈起。

F6 已有：一炷香按钮和 ⌘⇧↩ 进出；Esc 退出；两侧栏、标签坞、侧栏开关、角落收起，只剩稿纸；右下角浮出的出口；只淡拿着键盘的编辑器（`dim_for_immersive`）；设置里「打字时自动沉浸」（`editor.auto_immersive`）、「打字机模式」「输入行位置」三行。下面是还要接的，规则照旧版设计文档：

1. **进出时调编辑器**：进入、退出沉浸时，对所有打开着的 `ChapterEditor` / `BookEditor`（分栏的两页都算）调 `set_immersive(on, cx)`；新打开的编辑器按当时是否沉浸设一次。段落淡出照现在的 `dim_for_immersive`，只给拿着键盘的那个。
2. **打字时自动进入**：
   - 订阅稿纸（stage）里显示着的编辑器的 `WritingTyped`。设置开着、还没在沉浸，就以「打字进入」进入；光标就在原处，不重新聚焦。
   - 帮手输入框、情节规划、侧栏里的输入框不是 `dr-editor` 的编辑器，不会发这个事件。
   - 进入的来源（打字进入还是手动进入）每次进出都清掉，不存盘。
3. **打字进入的，点别处也退出**：
   - 窗口捕获阶段听主键按下：按在工作区里、又不在正文（编辑器）和出口上，就退出。这一下照常落下，退出时不抢焦点。
   - 浮层（悬停卡、菜单、对话框）不算工作区，点它们不退出。
   - 用一炷香或 ⌘⇧↩ 进入的，点别处不退出。
   - 退出后开关还开着，再打字又会进入。
4. **露出区**：
   - 指针到窗口顶边 56 px 内，红绿灯和标签点回来，标签点照常能换文档。
   - 出口在稿纸右下角（右 16 px、和工具栏同一条中线），指针离它 48 px 以内才出来。左边是这一次写了多少字（`+N`，和左栏「今日」同一来源，全书净增，起点是进入时的今日字数，换文档不清零），下面是今日那笔砂往每日目标长。
   - 一按不带修饰键的键就都收走，指针离开窗口也收走。
5. **macOS 红绿灯**：
   - 沉浸时把三个按钮的透明度设成 0。
   - 改透明度会让 AppKit 当场把标题栏重排，丢掉自定的位置（旧版实测：关闭按钮 x 从 18 跳回 9）。所以要在同一个主线程回合里先记下按钮和容器的位置，改完立刻放回去。
6. **结束沉浸的别的情况**：打开全书视图（Super View）、离开工作区。
7. **留着、不碰**：
   - 正文里的批注砂笔、大纲 rail 按进入前的样子，沉浸不读也不改它们的开关。
   - 要素下划线和悬停卡照常。
   - 稿纸左下角的同步云在沉浸中不呼吸，只有出了问题才照常显示。
8. **减少动效**：侧栏和 Bottom Panel 的滑动、控件的淡出照「减少动效」设置走。

## 和旧版的差别

- **点击不触发打字机滚动**（F4b 定的）：旧版只要光标挪了就滚，包括鼠标点；F4b 定为点哪儿就停在哪儿，只在打字、键盘挪光标、跳转时滚。这一轮没改，记在这里，作者想要旧版的样子再说。
- **输入法组字时不滚**：旧版也是这样（`view.composing` 时不滚），这一轮补上，现在一样了。
