# M25 书架的画：封面、写作热力图、近 30 天砂条

2026-11-08，F5 这一路做（分支 `claude/f5-ui-254e54`，从 main `60d510a6`）。计划见 [modules.md 的 M25](../modules.md)。代码在新 crate `next/crates/dr-view-shelf-art`，书架本身（M01，`dr-view-shelf`）把这些画放进书卡和书架的根上；这一轮只出组件，没有动 M01 的文件，接法写在下面，也写进了共享笔记。

## 大白话

- **封面。** 每本书一张 126 × 226 的封面，十四种画风，和旧版同一个顺序：砂笔、山脊、结绳、织物、等高线（默认）、蓝晒、年轮、色域、剪纸、孔版、星图、地层、包豪斯、字海。画的都是这本书本身：章节按阅读顺序从上往下，每条故事线一种颜色，跑到哪几章、那几章有多长，画里就在哪里、有多重。同一本书每次画出来都一样。
  - 第一次露面时在后台线程画，画好才出现；画之前是一张白纸，换画风时先留着旧的，新的画好再换上。这一次运行里画过的留着（最多 240 张，最久没露面的先丢）。
  - 砂笔那一种只存笔迹的透明度，露面时按当前主题的砂色上色（书卡只是一圈玻璃线，砂直接落在桌面上），所以换浅色深色不用重画；别的十三种是整张画，有自己的底色，不跟主题变。
  - 封面底部可以写一行小字（旧版写体裁），画是深色的就用浅墨。
- **换画风的按钮。** 书架底部一个圆按钮，点一下所有封面换到下一种，读屏念「换封面画风 · 现在是等高线」。
- **写作热力图。** 53 周，周一在最上面。写过字的一天是一下干笔按下去的砂点，字越多点越大越满；没写的一天是几粒散砂。四档按这一年写过字的那些天的四分位分。右边四个数：过去一年多少字、在写多少天、连续多少天、今天多少字。指针在某本书的卡片上时，图只画这本书、用它的颜色，数字也是它的。指着某一天，下面弹出一张卡：日期、那天的字数、每本书各写了多少（多到少）。
- **近 30 天砂条。** 书卡上一条 20 px 高的砂条：写过字的一天是一笔竖着的短砂笔，按这 30 天里最多的那天算高度；没写的一天是两粒散砂。
- 数据都从 F3 读：封面用 `chapter.list` 和 `storyline.list`，热力图和砂条用每本书的 `book.writing_days`（各设备加起来）。都要放在后台线程跑。

## 怎么移植的

旧版的画风是 Canvas 2D 写的。新版在 tiny-skia 上做了一层和 Canvas 一样叫法的画布（`art::paint::Ctx`：路径、弧、椭圆、填充规则、裁剪、径向渐变、阴影、正片叠底、`putImageData`），十三种画风逐行照搬，随机数（mulberry32）、噪声、颜色运算都和旧版一模一样，所以同一本书画出来和旧版是同一张画。字海要排字，用 ttf-parser 从 dr-ui 自带的字体文件里取字形轮廓画成路径，不经过 GPUI，所以也能在后台线程画。

对照：把旧版的 TS 原样用 `@napi-rs/canvas`（Skia）跑出参考图，4 本合成书（24 章三条线、8 章一条线、12 章没有线、40 章五条线的拉丁书名）× 14 种，新版画同样的请求，逐张并排看过，再算每张的平均差（0–255，越小越像）：

| 画风 | 24 章 | 8 章 | 无线 | 拉丁 |
| --- | --- | --- | --- | --- |
| 砂笔 | 0.0 | 0.0 | 0.0 | 0.0 |
| 山脊 | 1.1 | 1.3 | 1.6 | 0.9 |
| 结绳 | 0.2 | 0.1 | 0.1 | 0.3 |
| 织物 | 0.4 | 0.4 | 0.4 | 0.4 |
| 等高线 | 1.1 | 0.7 | 0.5 | 1.0 |
| 蓝晒 | 0.6 | 0.2 | 0.2 | 1.0 |
| 年轮 | 0.8 | 0.9 | 0.2 | 1.3 |
| 色域 | 0.0 | 0.0 | 0.0 | 0.1 |
| 剪纸 | 0.2 | 0.1 | 0.1 | 0.2 |
| 孔版 | 0.0 | 0.0 | 0.0 | 0.0 |
| 星图 | 0.3 | 0.1 | 0.1 | 0.3 |
| 地层 | 0.0 | 0.0 | 0.0 | 0.0 |
| 包豪斯 | 0.2 | 0.1 | 0.4 | 0.1 |
| 字海 | 9.9 | 7.1 | 10.6 | 3.6 |

- 砂笔整张用双精度算，和旧版逐像素一样（四张里只有三个像素差一级）。
- 别的零点几到一点几都是抗锯齿：tiny-skia 按十六分之一像素采样覆盖，Skia 是解析式的；剪纸的阴影、蓝晒的光晕是三次方框模糊代替高斯；结绳的绳结渐变忽略了内圆半径（`r × 0.1`），看不出来。
- 字海的字形、位置、颜色、大小都一样，差在字体：旧版用系统的宋体和 Menlo，新版用 Drifting Serif 和 Sarasa Mono；Sarasa Mono 只带了常规体，拉丁书最浓的那几个字旧版是粗体。

在 `next/` 下：

```bash
cargo run -p dr-view-shelf-art --example covers -- books.json out/ [画风 …]
```

`books.json` 是请求列表（每本 `{ name, seed, chapters, storylines: [{ color, chapters }], words, latin }`），每张写成 `<name>-<画风>.png`。对照用的四本书、旧版参考图的脚本和比较脚本在 `next/crates/dr-view-shelf-art/script/`：`reference-covers.ts`（用仓库自带的 esbuild 打包，再用 node 跑，命令写在文件开头）把参考图写进 `<目录>/ref/`，上面的命令把新版的写进 `<目录>/ours/`，`compare.py <目录> <画风 …>` 拼出并排图、打出平均差（要 Pillow）。

## M01 怎么接（逐条）

都在 `dr_view_shelf_art` 里：

1. **封面**：后台线程里 `cover_request(&ws, &book_id, &title)` 得到 `CoverRequest`（随书名判断拉丁字母，随书 id 定种子），放进 `Rc`，渲染时 `ShelfCover::new(id, book_id, style, request)`，有体裁就 `.label(体裁)`。它自己去后台画、画好自己刷新，不用 M01 管。书的章节、故事线、字数变了，重新读一次请求就行，键里字数只看到平均值的十分之一，打几个字不会重画。
2. **画风**：`CoverStyle`（十四种，`ALL` 是按钮的顺序，`DEFAULT` 是等高线，`slug()` / `from_slug()` 是旧版的名字）。按钮 `CoverTurn::new(当前画风, |下一种, window, cx| …)`。选中的画风存在哪里（旧版是本机的 `shelf:cover-style`）由 M01 / F6 定，比如设置注册表里一个本机键。
3. **热力图**：后台线程里 `WritingYear::load(&ws, &书的 id 列表, &今天)`（今天用 M07 的 `dr_view_stats::clock::today()`），渲染时 `WritingHeatmap::new(id, Rc<WritingYear>, Rc<Vec<HeatmapBook { id, name, color }>>, 指针所在书卡的书 id)`。写作日变了（F3 的总线）重读一次。
4. **砂条**：`SandStrip::new(id, Rc::new(year.recent(&book_id, 30)), cover_seed(&book_id), 读屏说明)`，宽度跟着卡。
5. **i18n**：`projectPicker.heat.*` 缺的六个键、`projectPicker.desk.coverStyle.turn` 和十四个画风名已加进 `keys.txt`，`locales/` 重新生成。

## 测试

`cargo test -p dr-view-shelf-art`：

- 封面数据从真的工作区读：章节按阅读顺序、每条故事线跑过哪几章、每章字数；十四种画风各画两遍结果一样，而且都画了东西；
- 写作年从 `writing_day.record` 写下的日子读回来：一年的天数、总数、某本书最近三天；
- GPUI 测试平台上：封面在后台画好后出现（等高线和砂笔两种），指着热力图上今天那一格弹出当天的卡；
- 单元测试：随机数、种子、哈希和旧版的 JS 逐位一样，颜色读取和混合、运行的合并、年的起点（往前 52 周的周一）、四分位分档、汇总、月份和日期在九种语言里的写法、紧凑字数。

## 测量（只作参考，机器负载一直很高）

release 下一张封面 1–40 ms（山脊、字海、蓝晒最慢；机器负载高时测的），都在后台线程，不挡帧。阴影只模糊图形自己那一块（一开始整张图都模糊，蓝晒一张要 7 秒多）。画坏了的一张（比如画法里的毛病）只让这本书留白纸，不会让程序退出。

## 和旧版不一样的地方

- **封面出现时没有 0.24 s 的淡入。** GPUI 不能给图片做透明度动画（dr-ui 的砂笔笔画也是把淡入烤进图里）。
- **热力图在窄窗口里只显示最近的几周**，旧版是横向滚动、打开时滚到今天。
- **某一天的卡在格子下面弹出**（dr-ui 的浮层往下放，没地方才往上），旧版在上面；卡宽是悬停卡统一的 248，旧版 216。
- **字海的字体**见上面对照。
- 旧版的封面在 Web Worker 里画、存成 JPEG 对象 URL；新版在后台线程画、留在内存里，不编码。
