# M02 作品主页（基础）

2026-11-08，第一个里程碑，和书架（[m01-shelf.md](m01-shelf.md)）在同一个分支 `chihumyum/m01-shelf-home-3bf938` 上。计划见 [modules.md 的 M02](../modules.md#阶段-2写作闭环)，产品规则见 [docs/project-home.md](../../project-home.md) 和 components.md 的「作品主页」。代码在 `next/crates/dr-view-home/`。

## 一句话

没有激活的标签时，稿纸上就是这本书的作品主页：书名（可以在原地改）、字数和全书目标的进度、今天写了多少和连续几天、从哪一章接着写、每条故事线写到哪了、有哪些类目；另一页「设定」改全书目标、每日目标和本书简介。新建一行、帮手的签到卡片还没有（见「还没做的」）。

## 做了什么（大白话）

1. **挂在外壳的「没有激活标签」上。** 外壳原来在这里只画了书名，现在应用登记了作品主页（`dr_view_home::init`），外壳第一次露出主页时造一个，之后这个窗口一直用它；打开别的书，它跟着换。主页在稿纸里，和稿纸一样宽，自己滚动。
2. **书名一段**（照旧版 `HomeTitle`）：
   - 等宽小字「作品主页 · 2025年11月起」（书目文档里的 `created_at`，按界面语言写月份；没有就只写「作品主页」）；
   - 书名用正文字体 34 px。点一下就地变成输入框：回车或点别处保存，Esc 不改；名字空着就保留原名。
   - 一行等宽读数「24 章 · 4 条故事线 · 24 个要素 · 6.2万 / 12万 字」（没有全书目标时只写字数）；
   - 下面一笔砂笔读数是全书进度，旁边是「今日 1,234 / 1,500 · 连续 3 天」（没有每日目标时不写目标）。
   - 右边是多选一「概览 / 设定」。
3. **继续写**：
   - 最近编辑的那一章是一个大一点的砂笔格子：章的印章（主故事线的颜色）、章名、故事线短横、「故事线名 · 3 天前 · 2,345 字」，下面两行梗概（正文字体）。
   - 再下面最多三章，按最近编辑排；单击开预览、双击留下，和侧栏一样。
   - 节头右边是文字按钮「通览全书」。没有章节时是空状态「还没有章节。」。
4. **全书**：每条故事线一行：短横、名字（结构字）、一笔取故事线颜色的砂笔读数（完成的章 / 章数）、等宽的「3 / 8 章 · 2.1万 字」。下面是类目格子（折角记号、名字、要素数）。节头右边是「叙事图」「要素总览」两个文字按钮（打开对应的 Super View）。还没有故事线时是一行等宽小字「还没有故事线。」。
5. **设定**：写作计划（「全书目标」「每日目标」两个数字框，旁边各一笔砂笔读数），本书简介（输入框，回车或点别处保存）。目标设成 0 就是关掉。
6. **数字从哪来**：
   - 章、故事线、类目、要素、章节的标题梗概状态：外壳已经读好的那份书目快照（`dr_shell::book::Book`）；
   - 梗概、目标：F3 的 `book.get`；
   - 每章字数：派生索引（和书架同一个读法）；每章最近编辑：它的正文文档最新一次存进 dr-store 的时间；
   - 今日字数和连续天数：书目文档里的写作日（所有设备加起来，按这台电脑的日历算今天；今天没写，连续就是 0，和旧版统计面板一致）。F3 还没有写作日的查询，所以读的是书目文档的一份副本（见「待协调」）。
   - 都在后台线程读。外壳换上新的书目快照（书改了、换了一本书）就重读；F3 报这本书的正文变了、或者 dr-store 报这本书某一章的派生索引写好了，也重读（主页藏着的时候不读）。
7. **主动建议（签到卡片）留位置不做**：代码里在「全书」后面留了位置，界面上什么也不画（不写占位的说明文字）。

**要作者定的事：没有。**

## 和旧版不一样的地方

- **「继续写」按最近编辑，不按最近打开。** 旧版记着每本书最近打开过什么（`recent-entities-store`），新版还没有这份记录（外壳的导航模型只有标签和历史）。按最近编辑排，第一格和旧版没有打开记录时的退路一样（「上次碰过的章」）；也就只列章节，没有要素。
- **改名的输入框是普通的单行输入框。** 旧版的书名就是一个看不出边框的大字输入框；dr-ui 的单行输入框只有界面字号、带一圈玻璃线，所以平时显示 34 px 的书名，点了才换成输入框。
- **本书简介是单行输入框。** dr-ui 还没有多行输入框。
- **相对时间**用通知中心的写法（「3 天前」），同书架。

## 测量

和书架同一份测量证据 [acceptance/m01-m02-shelf-home-bench.json](../acceptance/m01-m02-shelf-home-bench.json)（M3 Pro，release，离屏，负载约 17，详见 [m01-shelf.md 的「测量」](m01-shelf.md#测量)）：

- **打开一本书到工作区就绪**（从点书卡，到书目列表和作品主页的数字都到、画出一帧）：第一次《慢钟》38 ms、《阿Q正传（示例）》35 ms、重型种子 29 ms，再打开 p50 4.5 ms。发布档「打开项目」≤ 150 ms，在预算内。
- **作品主页整页重画一帧**：p50 0.6 ms、最大 1.5 ms（发布档每帧 8.3 ms）。

## 测试

`cargo test -p dr-view-home`：

- **单元**（1 个）：连续天数到今天为止，今天没写就是 0。
- **GPUI 测试平台上，用 dr-testkit 生成的《慢钟》**（经 F3 读，5 个）：
  - 等后台补建完索引，主页的字数等于派生索引里各章字数之和（中途读到一半的字数，索引写好后会自己更新）；目标、梗概和 F3 的 `book.get` 一样；每章都有字数和最近编辑，「继续写」第一格是最近编辑的那一章；
  - 经 F3 改一章的正文（像帮手或另一台设备那样），那一章跑到「继续写」的第一格；
  - 在原地改书名，回车保存、外壳的书目跟着变；再改一次按 Esc，名字不变；
  - 切到设定；经 F3 改全书目标、关掉每日目标，主页的数字跟着变；
  - 今日字数和连续天数从写作日算。

## 待协调

1. **F3（dr-workspace）**：
   - 写作日的查询（这一天所有设备的字数、按天的列表）。主页现在为了今日字数和连续天数读一份书目文档的副本。
   - 「最近打开」的记录（每本书最近打开过的章节、构想、要素，按时间）：「继续写」要的是它。放在本机表还是外壳的布局里，看谁来做；外壳的导航模型是最近的地方。
   - `BookInfo` 带上 `created_at`，主页就不用从副本里读。
2. **F5（dr-ui）**：单行输入框的「没有边框、跟着外面字号」的变体（就地改名：书名、以后的章名），多行输入框（本书简介、帮手的对话框）。
3. **F6**：同 [m01-shelf.md 的「待协调」](m01-shelf.md#待协调)第 3 条（`pages.rs` 和 `stage.rs` 的接入点）。外壳原来画在主页上的那两行（`stage.rs` 的 `home()` 余下部分）只在没登记主页时用，测试和外壳自己的截图还走它。
