# 内核 v5 T9 栏的铺满

左栏、底栏和右栏各用原来的入口和内容。标题栏两颗月亮分别控制侧栏开合和铺满，底栏的按钮在当前视图头部。一次铺满一处。换到另一处时，先铺满的栏回到原来的开合状态；从铺满退出时该栏保持开着。Esc、药丸、作品主页和全部项目均可退出，⌘[ 第一次先退出。侧栏铺满盖住底栏，拖边可以留出稿纸。此时稿纸上方仍用桌面色，打开的药丸保持露出。底栏铺满保留左右栏，左右边仍用于调侧栏宽度。

左栏铺满沿用当前 Tab，提供列表、网格、看板、岛屿、关系。成书 Tab 的数据来自开着成书时的成书序列。岛屿和关系从选中的 Tab 取范围。岛屿型 Tab 初次铺满显示关系，写书模板的「要素」沿用这项默认。之后的摆法按 Tab 存在本机 `BookLayout.tab_fill_layouts`。铺满状态和宽度留在窗口里。

「模板结构」从左栏下方或作品主页的「结构」缩略图进入，点上面任一 Tab 回来，连进入前选过的 Tab 也可点。左栏下方那一块写「16 个模板 · 88 个条目」，结构头部在模板、层级之后写「16 模板 · 88 条目」或「19 层 · 88 条目」（W12Template）。

模板图从同一书目快照读实际住处和挂名，按模板汇总。模板卡照 W12Template：头一行记号、名字、条目数；模块一行一个，类型和名字不同时写在右边；「层级」「收别处的条目」开着的墨色、关着的淡，开着收别处又设了新条目住处时多写「住在…」；两个开关有一个开着时再写「下面」一行（新建默认、显示、自动链接，模板都没设时写「继承」）。连线从上一层卡的右边连到下一层卡头一行的左边，末端一个点，中间写条目数；住的线三档粗细（1.3，三条起 1.9，十条起 2.7），挂的线是 1.9 的点。右上角的图例画出两种线的样子和条数，点一行隐去或露出那种线。指着一张卡（或浮窗开着的那张）时，碰到它的线和卡加深，其余变淡。点空白处收起浮窗，再点同一张卡也收起。

层级表照 W12Template 是一棵树：每个开着层级或收别处条目的条目一行，按树的先后排，下一层缩进 20（最多两档），最外层之间空一行加一条细线；名字一列没有表头，名字后写模板名。格子三种写法：这一层自己设的墨色加砂笔下划线，模板设的照行的颜色，从上面继承的淡；没有的写淡点，层级关着的行「自动链接」空着。「下面」写住着的按模板计数，挂着的写「挂着 …」。整行可拖到另一层那一行上搬进它下面，拖着时那一行描边并写「搬到这里」；一次 `entry.move`，撤销一步回去。

浮窗复用模板编辑器和条目页的设置控件，模块只列名字；模板浮窗另列它的条目「住在」哪些模板下面、「挂在」哪些模板上（§9 小卡的两组）。浮窗是铺满上面单独的一层：Esc 先只收浮窗，再按一次才退出铺满。在浮窗的输入框里按 Esc，和作品主页的名字、条目标题一样，框里回到存着的内容，浮窗随之收起；其余改过的（开关、选择）在浮窗收起时存下，不丢。点「完整编辑」后仍铺满，先存浮窗里改过的，完整编辑器作为一颗药丸在露出的稿纸上打开。

「新建模板」不先写：左栏铺满时（结构头部或左栏下方）浮窗里是一个还没存的新模板，作者改了什么才在浮窗收起、点「保存」或「完整编辑」时写成；没改就关掉，什么都不留，计数不变。左栏没铺满时从左下新建，照 T9 之前的做法在对话框里打开完整编辑器，第一次保存后才写成并作为药丸打开（药丸要对应一个存着的模板；没存的新模板没有药丸）。

## 拖动与写入

- 住着的行拖在左栏里是搬家。按住 ⌥ 拖到两个开关都开的条目上可以多挂。从左栏拖到泳道上按刻度放置并挂名，住处保留。
- 点线表示挂着的一行。拖到别处换挂，按住 ⌥ 多挂，拖回它所住的条目摘名。同组拖动时，有泳道就改该宿主所在第一个视图的刻度，其余按挂名本身的键排序。这照 2026-11-16 夜里定下的 [第 33 条](../kernel-v5.md#15-作者的答复与还没定的)。从底栏泳道拖回左栏摘掉来源那处挂名。
- `membership.add` 和 `timeline_view.place` 带来源宿主时，在一笔写入中完成换挂，只有失去最后一条适用泳道的视图会清除刻度。同组排序复用 `membership.add` 的界面写入入口。历史记录包含本次改变的挂名、需要清掉的主归属和视图刻度。拖动用的参数由界面提交，Agent 与 MCP 目录保持已有契约。
- 原生捏合时，鼠标位于刻度区调横向，位于泳道名栏调纵向。按住 ⌥ 或 Shift 也调纵向。修饰滚轮可用同样的两轴。泳道以普通栏的 36 px 和铺满的 76 px 为缩放基准。卡片最窄时按字的实际宽度显示完整字符，空间够时再显示梗概。拖放后先显示落点，书目确认写入后才能再次拖动或改长度。

## 外壳与代码

- `dr-shell/src/workspace/fill.rs` 控制开合、宽度与退出，`chrome.rs` 画月相，`stage.rs`、`sidebar.rs`、`bottom.rs` 和 `dock.rs` 共享中间列。
- `dr-shell/src/v3/tab_fill.rs` 提供 Tab 范围与摆法。`v3::set_tab_canvas` 由 M22 接上岛屿和关系，隐藏的画布暂停跟随，显示时追上最新书目。
- `dr-shell/src/v3/template_structure.rs` 画模板图与层级表。`v3::add_compact_template_editor` 由 K5 接上模板编辑控件，M02 的缩略图复用模板图的读取和连线。
- `dr-view-review` 以栏宽决定每行展示几个批注分组。`dr-view-material` 使用同一个素材库和列表／瀑布流设置，铺满时显示文件用处。
- 旧全窗舞台、切换器与 M23 拆除，旧的三个快捷键撤销注册。格式 5 的整书稿纸照常使用 M05。

## 验收

- `dr-view-page/tests/shell_workspace.rs` 验证铺满状态、交换时两种恢复路径、层的退出顺序、幕后的稿纸键盘和按 Tab 安装画布。
- `dr-view-elements/tests/v5_t1_lists.rs` 和 `dr-view-timeline/tests/v5_t4_views.rs` 验证住处、换挂、摘名、同组排序、刻度和窄卡片。DV/DV2 的数据层测试继续验证旧泳道清理和挂视图的 Tab 被拒。
- `dr-shell/tests/v5_t9_structure.rs` 验证层级表的树序和缩进、整行拖到另一层下是一次 `entry.move` 且一步撤销、浮窗两组用「住在」「挂在」、Esc 先只收浮窗、图例点击隐去和露出一种线。`dr-view-templates/tests/v5_t9_panel.rs` 验证新建模板没改就不写、改了才写（铺满的浮窗和未铺满的完整编辑器两条路），以及浮窗输入框里 Esc 回到存着的名字、收起浮窗、不退出铺满、开关改动在收起时存下。`dr-view-home/tests/v5_t9_thumbnail.rs` 验证缩略图 300 × 226、头部计数、位置和点击进入模板结构。
- `crates/dr-cli/scenarios/v5-t9-fill.json` 用 lite 种子的独立进程驱动真实窗口，检查泳道行高、从左栏拖挂与摘名、层级表拖动撤销、浮窗保存、未铺满时新建模板只开编辑器不写（关掉后模板数不变）、药丸退出和重开后的摆法。截图库只随运行保存。
