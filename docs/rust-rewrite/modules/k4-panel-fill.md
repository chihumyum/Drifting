# 内核 v5 T9 栏的铺满

左栏、底栏和右栏各用原来的入口和内容。标题栏两颗月亮分别控制侧栏开合和铺满，底栏的按钮在当前视图头部。一次铺满一处。换到另一处时，先铺满的栏回到原来的开合状态；从铺满退出时该栏保持开着。Esc、药丸、作品主页和全部项目均可退出，⌘[ 第一次先退出。侧栏铺满盖住底栏，拖边可以留出稿纸。此时稿纸上方仍用桌面色，药丸行露在上面，和平时一样是一排小点，手指上去才长成药丸（W11Right），点药丸退出铺满。底栏铺满保留左右栏，没有调高度的上边，左右边仍用于调侧栏宽度。沉浸写作时顶上那一条带回小点，药丸行按整个窗口居中。

两颗月亮照 W25Final：收着是空心月牙在前、空心整月在后；开着是月牙在前、空心整月在后；铺满是黑月在前、月牙在后。后面那颗暗度 0.42，两颗同一种墨色；指着后面那颗只把它变浓（不透明度到 1），不换前后、不换颜色，指着前面那颗什么都不变。右栏停在统计或 Agent 时整月暗着点不动，这个暗度 0.18 板子上没有给（`MOON_DISABLED_DIM`）。样子由 `chrome::moon_look` 算出，画和测试共用。

左栏铺满沿用当前 Tab，提供列表、网格、看板、岛屿、关系。成书 Tab 的数据来自开着成书时的成书序列。岛屿和关系从选中的 Tab 取范围。岛屿型 Tab 初次铺满显示关系，写书模板的「要素」沿用这项默认。之后的摆法按 Tab 存在本机 `BookLayout.tab_fill_layouts`。铺满状态和宽度留在窗口里。

「模板结构」从左栏下方或作品主页的「结构」缩略图进入，点上面任一 Tab 回来，连进入前选过的 Tab 也可点。模板图从同一书目快照读实际住处和挂名，按模板汇总。层级表列开着层级或收别处条目的条目，整行可拖去换住处。浮窗复用模板编辑器和条目页的设置控件，模块只列名字。点「完整编辑」后仍铺满，完整编辑器作为一颗药丸在露出的稿纸上打开。新模板命令写成后等待书目刷新，再从原入口进入浮窗或完整编辑器。

## 拖动与写入

- 住着的行拖在左栏里是搬家。按住 ⌥ 拖到两个开关都开的条目上可以多挂。从左栏拖到泳道上按刻度放置并挂名，住处保留。
- 点线表示挂着的一行。拖到别处换挂，按住 ⌥ 多挂，拖回它所住的条目摘名。同组拖动时，有泳道就改该宿主所在第一个视图的刻度，其余按挂名本身的键排序。这照 2026-11-16 夜里定下的 [第 33 条](../kernel-v5.md#15-作者的答复与还没定的)。从底栏泳道拖回左栏摘掉来源那处挂名。
- `membership.add` 和 `timeline_view.place` 带来源宿主时，在一笔写入中完成换挂，只有失去最后一条适用泳道的视图会清除刻度。同组排序复用 `membership.add` 的界面写入入口。历史记录包含本次改变的挂名、需要清掉的主归属和视图刻度。拖动用的参数由界面提交，Agent 与 MCP 目录保持已有契约。
- 原生捏合时，鼠标位于刻度区调横向，位于泳道名栏调纵向。按住 ⌥ 或 Shift 也调纵向。修饰滚轮可用同样的两轴。平时和铺满各有一套缩放（W9Bottom 的 `zb`、`zf`）：平时一格 24 px、泳道 36 px，铺满一格 100 px、泳道 76 px；横向在 12–200 px、纵向在 28–140 px 之间，捏一处不动另一处。两套都记在本机的 `timeline-v3`（`zoom`/`zoomY`、`fillZoom`/`fillZoomY`），记下的滚动位置只是平时的。进出铺满时滚动回到开头，照板子。泳道名那一列平时 96 px、铺满 140 px，只画记号和名字，条数铺满时才露出；泳道的按钮手指上去时盖在名字末尾出现。卡片最窄是标题第一个整字加两边留白，不少于 14 px（`model::card_min_width`），所以刻度捏得再密也露出整字；空间够时再显示整个标题和梗概。拖放后先显示落点，书目确认写入后才能再次拖动或改长度。

## 外壳与代码

- `dr-shell/src/workspace/fill.rs` 控制开合、宽度与退出，`chrome.rs` 画月相，`stage.rs`、`sidebar.rs`、`bottom.rs` 和 `dock.rs` 共享中间列。
- `dr-shell/src/v3/tab_fill.rs` 提供 Tab 范围与摆法。`v3::set_tab_canvas` 由 M22 接上岛屿和关系，隐藏的画布暂停跟随，显示时追上最新书目。
- `dr-shell/src/v3/template_structure.rs` 画模板图与层级表。`v3::add_compact_template_editor` 由 K5 接上模板编辑控件，M02 的缩略图复用模板图的读取和连线。
- `dr-view-review` 以栏宽决定每行展示几个批注分组。`dr-view-material` 使用同一个素材库和列表／瀑布流设置，铺满时显示文件用处。它的预览缓存在换库开始时丢掉、换库期间不再取书库、换完重新取，所以素材库铺满时也能换库。
- 旧全窗舞台、切换器与 M23 拆除，旧的三个快捷键撤销注册。格式 5 的整书稿纸照常使用 M05。

## 验收

- `dr-view-page/tests/shell_workspace.rs` 验证铺满状态、交换时两种恢复路径、层的退出顺序、幕后的稿纸键盘和按 Tab 安装画布。
- `dr-view-page/tests/v5_t9_fill.rs` 在画出来的月亮上逐格点状态机（左右两栏、三种样子、指着前后两颗、统计时整月不动、铺满时切到统计退回开着），验证铺满时药丸行是小点、指上去才展开，沉浸时药丸行按整窗居中，底栏铺满没有调高度的边、拖两条边改的是左右栏宽，⌘[ 先退出铺满再后退，左栏没铺满时新建模板开完整编辑器的新药丸，素材库铺满时换库。
- `dr-view-timeline/tests/v5_t9_bottom_fill.rs` 验证平时和铺满各自的缩放与泳道名宽，以及刻度捏到最密时画出来的卡片仍露出标题的第一个整字。
- `dr-view-elements/tests/v5_t1_lists.rs` 和 `dr-view-timeline/tests/v5_t4_views.rs` 验证住处、换挂、摘名、同组排序、刻度和窄卡片。DV/DV2 的数据层测试继续验证旧泳道清理和挂视图的 Tab 被拒。
- `crates/dr-cli/scenarios/v5-t9-fill.json` 用 lite 种子的独立进程驱动真实窗口，检查泳道行高、从左栏拖挂与摘名、层级表拖动撤销、浮窗保存、药丸退出和重开后的摆法。截图库只随运行保存。
