# 交互

## No right-click menus

- Drifting 没有自绘的右键菜单（2026-10-28）。右键一律交给系统原生菜单：renderer 不再拦截 `contextmenu`，也不在右键时弹出任何东西。
- 一个东西能做的事放在它的**悬停卡**里：指针停在章节、要素、构想、故事线、类目、构想分组、时间线片段/幕/时间钉、批注/TODO 卡、素材与文件夹等对象上，经过悬停延迟后出现卡片（`HoverCardShell` / `EntityHoverCard`；批注与 TODO 的来源卡 `CommentSourceHoverCard` 也是同一张卡），上半是这个东西本身，下面是原来右键菜单里的操作（`HoverCardActions`）。指针离开对象后有 `220ms` 宽限可以移进卡片（`useHoverPreview` 的 `onLeave`）；点击对象、开始拖动或选完操作时卡片立即收起（`dismiss`）。
- **悬停卡的样子**（2026-10-31 作者在原型上逐条定）：所有悬停卡同一张卡，宽 `248px`，侧栏同色的桌面底、`16px` 圆角（Agent 对话框那种），边是静止的细玻璃线（`.glass--rest` 的强度、没有内晕、纹理切出、不流动），保留浮起投影。整张卡只有一个字号（`--ui-font-secondary`），只有标题加粗。所有文字从同一条左边开始：有记号的行记号贴左边（标题前是这个东西自己的砂笔记号，元信息里故事线、类目、构想分组的记号放在各自名字前），没有记号的行文字贴左边；标题右边是同字号的等宽数字（字数、章数、要素数、条数），和标题按基线对齐。上半依次是标题行、一行元信息（故事线 / 类目 / 分组 / 别名，次要故事线淡一档；卡里没有写作状态这一节时写作状态也写在这里）、摘要（没有就不写「暂无摘要」）、键值两列、引用原文（来源卡：作者原文放在一张稿纸色小片上，正文字体）。
- **悬停卡的行**：能按的东西一行一个、竖排、等宽字体、和标题同字号，行首是记号（动作用砂笔图标，种类相关的用该种类的 `KindMark`），记号贴左边，文字落在标题文字那一列；只有指针下的那一行有一圈流动的发丝玻璃（和菜单行同一种），离开就消失。各节之间用菜单的分隔线隔开（`--menu-separator`：`0.5px`、墨色 `14%`、上下各 `5px`，左右缩到卡片文字的左缘 `14px`），危险操作（删除…）总是收在最后一节，只用危险色的字。转换为章节… 这类打开对话框的行不加记号。
- **一个格子背后有多个选项时，它就是单独的一节**（作者 2026-10-31 定为通则）：节名一行（淡字、贴左边、不加记号），选项竖排在下面，各带记号。选项固定的（写作状态、构想状态）一直展开，节名不能按；选项不固定、可能很多的（移动到分组、更改类目、更改分组、编辑故事线、移动到文件夹、绑定构想）默认收起，按节名展开或收起，高度与透明度在 `0.28s` 内过渡，节名右边的展开箭头跟着转；按过之后节名不留玻璃环，鼠标离开就消失。单选时当前那一项是一圈静止的玻璃环加深色字（再按无效）；可以多选的（编辑故事线）在行尾打一个批阅勾，按一下就加上或去掉，卡片不收起。要素的「更改分组」最后一行是「新建分组…」，在原位打开能打字的分组选择器；搜索式的选择（关联…）仍打开选择器。
- **滚动时悬停卡收起**：卡片所在对象的列表（任何包含它的滚动区域）一滚动，卡片就收起，不跟着列表走；卡片自己的内容或别的面板滚动时只重新定位。滚动中滑到指针下的行不算“被指着”：列表停下 `180ms` 后，指针真正移到某一行上才会出现那一行的卡片。指针停在对象上滚轮时，如果卡片内容比卡片长，滚轮先滚卡片。
- 原来要右键空白处才能做的「在此处新建」（时间线空轨上的章节/幕、叙事轴上的标记、幕轨上的幕）改为在那个位置双击；头部的 ＋ 按钮照旧。
- 具体落点：顶部标签没有卡片，分屏操作在编辑器中缝的竖条上；Review 卡的来源卡片承接批注/TODO 的操作，卡上的 ⋯ 按钮立即打开同一张卡并把焦点放进去；素材文件夹树的行卡片在该行属于多选时改为对整组选择的操作；幕标签在键盘聚焦时按 Shift+F10 / ContextMenu 键立即打开卡片；时间钉与幕标签在触摸长按时也打开卡片。故事图谱与要素全景的格子在拖动、连线或点击弹出层打开时不显示卡片。
- 正文编辑器里选中文本后，一条横向玻璃长药丸自动出现在选区上方（`EditorSelectionBar`，选区稳定 `180ms` 后浮入，选区变化、输入、失焦、Escape 或在外面按下时收起）：「格式 ▾」（悬停或点击后在浮条另一侧展开第二条长药丸，里面是块级格式与行内标记的砂笔符号）、添加批注、新建补丁、Copilot 修改，每个是一颗短药丸。按钮按下不夺走选区；在第二条里按下格式不影响第一条（见 [components.md](components.md) 的选区浮条）。

## Menu surfaces

- 三点按钮、排序按钮与窗口控件只决定菜单如何定位，不决定菜单长什么样。按钮锚定面继续由 `AnchoredPopover` portal 到 `body` 并使用 `position: fixed`；坐标锚定的选择器（分组选择等）使用 `ContextMenuSurface`。编辑器选区浮条与悬停卡保留各自的生命周期 owner，同样 portal 到 `body` 并固定定位；悬停卡使用共享的菜单外壳 token，选区浮条是玻璃长药丸，不用菜单外壳。
- 所有动作菜单使用 `.menu-surface`。宽度只有两档：一列动作的菜单 `240px`（compact / standard 两个类名同值），装着更多东西的菜单（图片、对象列表、表单）`320px`（wide / panel 同值）；关系类型管理这种设置面板仍是 `420px`（settings）。即 `240 / 320 / 420px`，窄视口再由浮层 primitive 的 viewport max-width 收缩，不为单个入口另写任意宽度。
- 外壳（桌面，2026-10-31 菜单统一）：圆角矩形，`--menu-radius: 16px`，与悬停卡浮窗同值；底色是侧栏同色的不透明 `--menu-surface-bg`；边是静止的细玻璃线，与顶部药丸未选中、右栏批注卡、Agent 输入框同一种不均匀的玻璃边（玻璃色 50% 的 1px 线被玻璃纹理切开，没有内晕，不流动）；外面只有浮起投影 `--menu-shadow`，不再有 `0.5px` 墨色 hairline。菜单自己就是滚动容器，伪元素画的环会跟着行滚走，所以这条线画成背景：`ringgen.py` 把玻璃纹理预先着成浅色／深色的玻璃色（`glass-ring.png` / `glass-ring-dark.png`，`--menu-ring-texture`），只露在 1px 透明边框里。悬停卡是同样的圆角矩形与静止玻璃线（见 [surfaces.md](surfaces.md)）；对话框、全局搜索与查找仍用原来直角的 `--menu-surface-*` 外壳。
- 行：菜单里的 `.menu-surface__item` 左右各缩进 `6px`（`--menu-row-inset`），`5px 10px` padding、`4px` 圆角，桌面单行 `30px`（随界面字号档增加），UI 字体 `14px / 20px`。每一行都以图标开头：`16px` 的砂笔图标（`BrushIcon`），或这一行要变成、要插入的对象的记号（转换为章节＝章节圆印，`@` 提及的实体＝它自己的记号，`MenuRowIcon`），图标与文字同色，间距 `10px`；同一个菜单里不混用有图标和没图标的行。文本超过一行时正常换行，不截断。行不填色：悬停时这一行沿自己的圆角一整圈变成 hairline 流动玻璃（与侧栏 cell 的悬停环同一张纹理）；删除这类危险操作的环是危险色；在行之间移动只淡出旧行、淡入新行的环。
- 分组之间是一道 `0.5px` 发丝线（`--menu-separator`，上下各 `5px`，左右缩进 `16px` 与图标对齐）；section label 是 `12px` 中等字重的淡色字，不大写、不加字距。单选组的当前项文字转深，行尾一个批阅一勾（`.menu-surface__check`）；不绘制 inset-left accent bar。编辑器 ⋯ 菜单按普通操作、写作状态、删除分三组。
- 正文编辑器的 `/` 与 `@` 菜单也是 `.menu-surface`（`lib/editor-suggestion-menu.ts` 用 DOM 拼出同样的外壳与行），不再自带写死的米白底与填色选中行：`/` 分块级格式与插入两组；`@` 的实体行行首是它的记号、行尾淡色标出种类，「创建要素」在发丝线下。
- 键盘移到的当前行（全局搜索的结果、下拉选择的选项、查找结果）是同一圈环的静止选中态（`.menu-surface__item.is-current`），指针下的行照旧流动。下拉选择的列表与触发器同宽、不窄于 standard 档，这是宽度档位唯一的例外。
- 账户、通知中心、Agent 配置/历史、关系类型管理、设定图、资料卡摘要和“未放置”内容不是普通动作列表。它们使用 `.menu-surface--rich` 保留表单、摘要、图片、chip 或多列布局，但外壳、基础字号、菜单行的缩进与悬停玻璃（不垫底）、分组发丝线与浮层层级仍与简单菜单一致；账户菜单的分组同样以发丝线分开、图标 `16px`；不为了视觉整齐把富交互压成 30px 动作行。
- App 自绘菜单受上述约束；系统原生右键菜单不属于 renderer 可定制范围。静态测试能证明 token、class 与 portal/fixed 路径已收敛，不能证明不同平台上的字体栅格化、阴影观感或系统原生菜单外观；这些仍由用户在实际窗口中目测验收。

## 按压、悬停与焦点

- 玻璃控件按下时加深，松开退回；文字型的选择（Panel Tab、筛选项）没有按压态，点击后文字立刻变成选中样式，玻璃方块随后滑过去。
- 选中靠材料状态表达，不改按钮上的字：开关是一个永远不变的词；当前标签、当前章节、当前 Panel 都是静止的选中玻璃。
- 悬停只改变正在被指着的那一样东西（或它所在的那一栏 Header）；不让整行、整栏一起变色。
- 叠在一起的玻璃各管各的：一级与它展开的二级（选区浮条与它的格式条）是并排的两块，不是一块套着另一块，指针、流动与按压只属于被指着的那一块；装按钮的长药丸是容器（`.glass--surface`），里面的按钮被按下时它不加深。
- 玻璃控件的键盘 `focus-visible` 与悬停同效（玻璃晕开）；筛选项与章末动作用下划线；侧栏 cell 保留独立的焦点轮廓。

## 拖动

- 拖在手里的东西按弹簧跟手、略落后、不回弹，其余东西让位而不是被推挤（[motion.md](motion.md)）。
- Dock 药丸：拖离药丸行后原位收拢，拖回时按指针位置让出空位；拖到稿纸左半或右半即分屏。
- 时间线章节块：只有手里这一块移动，跨泳道越过中线才吸附，吸附的同时换上那条泳道的颜色；回到原泳道或取消时换回原来的颜色。
- 拖动开始时，被拖对象的悬停卡收起。
