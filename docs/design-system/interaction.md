# 交互

## No right-click menus

- Drifting 没有自绘的右键菜单（2026-10-28）。右键一律交给系统原生菜单：renderer 不再拦截 `contextmenu`，也不在右键时弹出任何东西。
- 一个东西能做的事放在它的**悬停卡**底部：指针停在章节、要素、构想、故事线、类目、构想分组、时间线片段/幕/时间钉、批注/TODO 卡、素材与文件夹等对象上，经过悬停延迟后出现卡片（`HoverCardShell` / `EntityHoverCard`），卡片上半是摘要，底部一行是原来右键菜单里的操作（`HoverCardActions`）。指针离开对象后有 `220ms` 宽限可以移进卡片（`useHoverPreview` 的 `onLeave`）；点击对象、开始拖动或选完操作时卡片立即收起（`dismiss`）。写作状态这类带标题的选择组单独占一行，当前项用加粗与静止玻璃边表示；需要从一组里挑一个的操作（移动到分组…）在卡片里原地展开第二行选项，较长或需要搜索的（更改分组、文件夹、绑定构想）仍打开各自的选择器。只有悬停卡底部的那一个按钮流出玻璃。
- **滚动时悬停卡收起**：卡片所在对象的列表（任何包含它的滚动区域）一滚动，卡片就收起，不跟着列表走；卡片自己的内容或别的面板滚动时只重新定位。滚动中滑到指针下的行不算“被指着”：列表停下 `180ms` 后，指针真正移到某一行上才会出现那一行的卡片。指针停在对象上滚轮时，如果卡片内容比卡片长，滚轮先滚卡片。
- 原来要右键空白处才能做的「在此处新建」（时间线空轨上的章节/幕、叙事轴上的标记、幕轨上的幕）改为在那个位置双击；头部的 ＋ 按钮照旧。
- 具体落点：顶部标签没有卡片，分屏操作在编辑器中缝的竖条上；Review 卡的来源卡片承接批注/TODO 的操作，卡上的 ⋯ 按钮立即打开同一张卡并把焦点放进去；素材文件夹树的行卡片在该行属于多选时改为对整组选择的操作；幕标签在键盘聚焦时按 Shift+F10 / ContextMenu 键立即打开卡片；时间钉与幕标签在触摸长按时也打开卡片。故事图谱与要素全景的格子在拖动、连线或点击弹出层打开时不显示卡片。
- 正文编辑器里选中文本后，一条横向浮条自动出现在选区上方（`EditorSelectionBar`，选区稳定 `180ms` 后浮入，选区变化、输入、失焦、Escape 或在外面按下时收起）：「格式 ▾」（悬停或点击后在浮条另一侧展开一行块级格式与行内标记）、添加批注、新建补丁、Copilot 修改。按钮按下不夺走选区。

## Menu surfaces

- 三点按钮、排序按钮与窗口控件只决定菜单如何定位，不决定菜单长什么样。按钮锚定面继续由 `AnchoredPopover` portal 到 `body` 并使用 `position: fixed`；坐标锚定的选择器（分组选择等）使用 `ContextMenuSurface`。编辑器选区浮条与悬停卡保留各自的生命周期 owner，但同样 portal 到 `body`、固定定位并使用共享视觉 token。
- 所有动作菜单使用 `.menu-surface`。外壳唯一来源是 `--menu-surface-bg`、`--menu-surface-border`、`--menu-surface-radius` 与 `--menu-surface-shadow`；宽度只能从 compact / standard / wide / panel / settings 五档中选择，对应 `180 / 220 / 280 / 360 / 420px`，窄视口再由浮层 primitive 的 viewport max-width 收缩，不为单个入口另写任意宽度。
- 菜单是从桌面掀起的一块：`--menu-surface-bg` 取侧栏同色的不透明 `--workspace-ui-bg`，直角（`--menu-surface-radius: 0`），没有实线边框，边缘是 `--menu-surface-shadow` 里的 `0.5px` 墨色 hairline 加浮起投影；菜单整体没有自己的玻璃边，流动玻璃只出现在被悬停的那一行。悬停预览卡共用这组 token。
- 普通行使用 `.menu-surface__item`，桌面采用 `14px / 20px`（较大档 `16px / 22px`）UI 字体，共享移动 fallback 为 `12.5px / 18px`，`6px 14px` padding、直角，左右贴齐菜单边缘。桌面单行内容至少为 `32px`；文本超过一行时允许正常换行，由所选档位的行高自然撑高，不截断为单行，也不把富表单强制压进固定 cell。行不填色：悬停时该行四边一整圈变成 hairline 流动玻璃（与侧栏 cell 的悬停环同一做法，同一张纹理切出，四边粗细一致）；在行之间移动只淡出旧行、淡入新行的环。
- section label、header 与 accelerator 分别使用共享的小型层级；分组之间用 `8px` 空白代替分隔线（divider 保留为空白）。当前项只以字重显示，不绘制 inset-left accent bar。
- 账户、Agent 配置/历史、关系类型管理、资料卡摘要和“未放置”内容不是普通动作列表。它们使用 `.menu-surface--rich` 保留表单、摘要、chip 或多列布局，但外壳 token、基础字号、hover wash、圆角阶梯与浮层层级仍与简单菜单一致；不为了视觉整齐把富交互压成 30px 动作行。
- App 自绘菜单受上述约束；系统原生右键菜单不属于 renderer 可定制范围。静态测试能证明 token、class 与 portal/fixed 路径已收敛，不能证明不同平台上的字体栅格化、阴影观感或系统原生菜单外观；这些仍由用户在实际窗口中目测验收。

## 按压、悬停与焦点

- 玻璃控件按下时加深，松开退回；文字型的选择（Panel Tab、筛选项）没有按压态，点击后文字立刻变成选中样式，玻璃方块随后滑过去。
- 选中靠材料状态表达，不改按钮上的字：开关是一个永远不变的词；当前标签、当前章节、当前 Panel 都是静止的选中玻璃。
- 悬停只改变正在被指着的那一样东西（或它所在的那一栏 Header）；不让整行、整栏一起变色。
- 玻璃控件的键盘 `focus-visible` 与悬停同效（玻璃晕开）；筛选项与章末动作用下划线；侧栏 cell 保留独立的焦点轮廓。

## 拖动

- 拖在手里的东西按弹簧跟手、略落后、不回弹，其余东西让位而不是被推挤（[motion.md](motion.md)）。
- Dock 药丸：拖离药丸行后原位收拢，拖回时按指针位置让出空位；拖到稿纸左半或右半即分屏。
- 时间线章节块：只有手里这一块移动，跨泳道越过中线才吸附。
- 拖动开始时，被拖对象的悬停卡收起。
