# 触屏

同一套砂笔与素玻璃，换成手指。手机端（`html[data-shell-mode='mobile']`）与桌面共用全部材料、组件与动效词汇；本篇只写手指和指针不同的地方。手机工作区的结构（一张稿纸压在桌面上）见 [mobile-ui-foundation.md](../mobile-ui-foundation.md)。

## 从指针到手指

| 桌面 | 手机 |
| --- | --- |
| 指针停在东西上出现悬停卡 | 手指按住不动 `420ms`，出现同一张卡（`mobile-touch-hold.ts`）；不松手滑到卡里的一行再松开，就是按了那一行 |
| 单击打开（预览） | 轻点打开 |
| 在空白处双击新建 | 长按空白处（同一张卡里的新建）；面板头的 ＋ 照旧 |
| 选区浮条浮在选区上方 | 同样的动作在键盘上方那条玻璃长药丸里（`MobileKeyboardBar`），选区上方留给系统自己的拷贝菜单 |
| 正文里的链接悬停出卡 | 读的时候轻点名字出卡，不放光标；写的时候轻点放光标 |
| 侧栏从窗口边滑出 | 推开稿纸，下面是桌面；稿纸留一条边在屏上，点它或拉回来就盖上 |
| 时间线从稿纸下方滑上来 | 在标签条上往上一甩，稿纸的脚被抬起，露出下面的 Bottom Panel |
| Super View 覆盖窗口 | 从右边盖上来；从左边缘往右拖、按返回或系统返回键收回 |
| 键盘快捷键 | 没有；手机不显示快捷键提示 |

## 玻璃在手指下

- **没有悬停。** 手指没有悬停态，触屏还会把上一次点过的控件一直当作“被指着”，所以玻璃的悬停晕开与流动只在能悬停的指针下生效（`materials.css` 里的 `@media (hover: hover)`）。手机上玻璃只在三种时候变化：**按住**（`40ms` 加深，松开 `0.28s` 退回，和桌面一样）、**在移动**（被推开的稿纸边线、滑动的 Panel Tab 方块随距离流动）、**在等**（等作者决定的 `.glass--waiting`、等 App 准备的 `.glass--loading` 自己流动）。
- **选中照旧。** 选中是静止的选中玻璃（D），当前标签、当前 Panel、开着的开关都一样。
- **按住要能感觉到。** iOS 只有在页面挂着 `touchstart` 监听时才给 `:active`，手机工作区挂了一个空的被动监听。
- **滑到行上。** 长按出卡后手指不松、滑到卡里的一行，那一行垫一层极淡的墨色（`[data-touch-armed]`），松手就按下它。

## 尺寸

- 圆形玻璃按钮 `40px`，砂笔图标 `20px`（`--glass-round-size` / `--glass-round-icon` 在手机上的值）；和它排在一行的药丸同高，装按钮的长药丸四边仍是一个托盘留白（`4px`），所以标签条与键盘条是 `48px`。
- 列表行、卡片的行、菜单行至少 `44px`（`--ui-row-height`、`--menu-row-height`）；面板头里的小按钮至少 `40px` 见方。
- 界面字号：正文 `16px`、次要 `15px`、注释 `13px`、强调 `17px`、标题 `19px`（`mobile-foundation.css`）。正文的字号与行距仍由编辑器设置决定。

## 手势与它们的主人

一个手势只有一个主人，方向一定就不再改：

- **稿纸**：横向的拖动推开稿纸（`useDeskPan`），竖向交给原生滚动（`touch-action: pan-y`）；手指先停住再动的是在选字，不接。写作时只有从屏幕最边上起手的横拖才推稿纸。
- **标签条**：横向滑动在标签之间换选，竖向一甩抬起或放下稿纸的脚（`touch-action: none`）。
- **书口**：竖向滑动在全书各章之间翻（`touch-action: none`）。
- **桌面的标签行**：横向滑动换 Panel；面板内容里的横拖把稿纸拉回来。
- **Super View**：从左边缘起手的横拖把它拉走。

## 不留的东西

- 点过之后的系统焦点框（读屏有它自己的焦点框）、点击高亮、对界面文字的长按选择与系统弹出菜单。正文、输入框与 Agent 的文字仍可选择。
- 悬停才出现的提示与快捷键文字。
