# 材料

## Sand and glass

界面只有两种材料，其余一律是平的：**玻璃是手按的东西**（控件、浮起的滑块、移动中的面板边缘），**砂笔是作者留下的痕迹**（每类实体的记号、选中时画出的框、按钮与菜单里的图标）。两者都是 `src/assets/design/` 里的白色 alpha 蒙版，在 CSS 中着色；生成脚本与来源见 `scripts/design-assets/` 与 `ASSET_PROVENANCE.md`。共享样式在 `src/styles/materials.css`。

玻璃与砂笔一般不叠在一起。唯一的例外是 Dock：标签小点在悬停时晕开成玻璃药丸，玻璃只把砂压开、磨淡，不放大也不扭曲底下的砂。

## 玻璃

### 构造

一块玻璃只有一圈边，由同一张纹理 `glass-thick.png`（`--glass-texture`，150px 平铺）切出：

- **边**：`1px` 内描边，粗细随纹理起伏，四边一样，不是整齐的实线；
- **内晕**：沿边向内晕开的一圈（`--glass-rim`，默认 `9px`），由 `--glass-sp` 控制有无与宽度；
- **底**（只有浮起的玻璃有）：`--glass-fill`，稿纸色 80%，加 `1.6px` 背景模糊，不扭曲底下的文字。

玻璃从不填实色、不下沉、不反色，也没有高光与投影。

### 令牌

| 令牌 | 作用 |
| --- | --- |
| `--glass-clear` | 无色玻璃的颜色：浅色 `#B4B6AE`，深色 `#6B6D67` |
| `--glass-cc` | 这块玻璃的颜色，默认 `--glass-clear`；有归属时取故事线或类目颜色 |
| `--glass-edge` | 边的浓度，默认 `33%` |
| `--glass-rim` | 内晕宽度，默认 `9px` |
| `--glass-bleed-lift` | 内晕往白里提亮多少：浅色 `0%`，深色 `45%`（只提内晕，不动那条边） |
| `--glass-g` / `--glass-sp` | 当前强度与内晕倍数，由状态决定（见下表） |
| `--glass-gx` / `--glass-gy` | 在纹理上取样的位置 |
| `--glass-dense-gx` / `--glass-dense-gy` | 纹理上最稠密的那块（`-96px -132px`）：小块玻璃与会移动的小方块都从这里取样 |
| `--glass-fill` | 浮起玻璃的底 |
| `--flow` / `--flowa` | 随距离流动时纹理已走的距离与强度（`lib/glass-flow.ts`） |

### 状态

| 状态 | 怎样触发 | 样子 |
| --- | --- | --- |
| 隐藏 | `.glass` 静止 | 看不见边 |
| 静止细线 | `.glass--rest` 静止 | 只有那条不均匀的细线，没有内晕，略淡（强度 `0.85`，内晕 `0`） |
| 悬停 / 聚焦 | `:hover`、`:focus-visible` | 内晕在 `0.24s` 内晕开（强度 1、内晕 1 倍），纹理缓慢流动 |
| 选中（D） | `aria-pressed`、`aria-expanded`、`.is-on` | 和悬停一样的边与内晕，但静止不流动；悬停也不让它流动 |
| 按住 | `:active` | 边变浓变宽（强度 ×1.7、内晕 ×1.3），`40ms` 内出现、停止流动，松开后 `0.28s` 退到当时该在的状态；写在选中规则之后，覆盖选中 |

变体：`.glass--rest`（有静止细线）、`.glass--surface`（卡片只借用流动的边，按下不变浓；装按钮的长药丸——选区浮条与它的格式条——也用它，里面的按钮被按下时长药丸不加深）、`.glass--round`（圆形）。组件用到的修饰（各自的用法见 [components.md](components.md)）：

- `.glass--still`：只读的东西（发出的话、任务清单、结束的工具步骤）悬停时保持静止细线，不晕开、不流动。
- `.glass--field`：输入框；光标在里面时（`:focus-within`）是静止的选中玻璃。
- `.glass--primary`：主按钮；常驻强调色的选中玻璃，字用强调色墨，停用时退回淡淡的无色细线。
- `.glass--waiting`：等作者决定的东西；和其他玻璃相反，平时就流动，悬停时停下。
- `.glass-sweep`：刚到的一步；`::after` 上一道切出窗口的玻璃从左往右推过一次，静止细线在它推过之后才淡出。
- `.glass--small`：小块玻璃，固定取稠密的纹理（见下面的「纹理取样」）；`.glass--round` 同样算小块。

悬停与选中的边和内晕相同，区别只在是否流动：作者确认这样已足够区分，不再加一档。

### 纹理取样

`.glass` 按同类兄弟的序号在纹理上取四块不同位置（`-14 -46`、`-96 -132`、`-168 -18`、`-58 -186`），相邻的玻璃因此不会一模一样。这张纹理的稠密处集中在一条横带上：边短的玻璃只露出一小块纹理，落在第一块或第四块时有一半的边几乎看不见。

- **小块玻璃一律取稠密的那块。** 矮的控件（短边不到约 48px：按钮、开关、标签、chip、单行输入框与下拉、选区浮条里的短药丸）加 `.glass--small`，圆形玻璃（`.glass--round`）自动算小块；两者都固定取 `--glass-dense-gx` / `--glass-dense-gy`。共用的 `Button`、`GhostIconButton`、`ScopeToggle`、`GlassSelect` 已经带上，新写的小控件照做，不再在组件样式里单独写坐标。
- **大块玻璃留在轮换上。** 卡片、托盘、长药丸、多行输入框的边够长，四块位置的浓淡差不多；如果都取稠密的那块，稠密带总落在上边，上下边就不对称了。竖着排成一列的卡片（Agent 记录、Review 卡、情节规划的纸条）在稠密那块与 `-168 -18` 之间交替。
- **会移动的小方块在稠密那块上加位移**：Panel Tab 方块与筛选滑块取 `calc(var(--flow, 0) * 1.2px + var(--glass-dense-gx))`，随自身移动的距离流动。
- **水波同族照旧轮换。** Dock 药丸与时间线章节块是同一组里传递选中的玻璃，水波在一张共用的纹理上推过各成员，所以它们不加 `.glass--small`。
- 不是 `.glass` 的玻璃层（开关的轨道细线与强调色晕、笔记里的引用块、素材文件夹的放下环）也从 `--glass-dense-gx` / `--glass-dense-gy` 取样；开关轨道原来取最稀的那块，深色里关着时只剩一颗圆钮（2026-10-29 深色复核时改）。

### 颜色

- 有归属的玻璃取归属颜色：Dock 药丸取记号的颜色，时间线章节块取故事线颜色，幕标签取幕的颜色，侧栏 cell、时间线泳道名与未放置章节行的悬停环取故事线/类目颜色。
- 没有归属的玻璃一律用 `--glass-clear`（浅灰），Dock 里没有颜色的药丸也是（2026-10-29 定，此前用墨灰 `--ink-3`）。
- 强调色的玻璃只有三处：开着的 Switch（晕染整条轨道）、主按钮、等你处理的卡片。危险色的玻璃只有一处：危险操作的按钮，静止时是一圈危险色细线，悬停晕开流动，按住加深，不常驻红晕（2026-10-29 定，此前是无色细线加危险色的字）。
- 整行开关打开时取这一行的颜色（章节归属里的故事线颜色），和侧栏 cell 的悬停环同一来源。
- 深色主题里，有颜色的内晕按边的浓度叠在深底上会发浑（故事线的红变成锈褐），所以深色下内晕往白里提 45%（`--glass-bleed-lift`），在自己的颜色里发亮；那条边不动。无色玻璃的晕也随之略亮一点。2026-10-29 深色复核时在 28% 与 45% 之间选了 45%。

### 会流动的线

侧栏贴向稿纸的边、Tab 行下沿、账户 cell 上沿、双栏分隔线、Bottom Timeline 顶边与泳道分隔线，静止时都是 hairline。面板滑开、收起或被拖宽时，这些线按面板实际移动的距离推动玻璃纹理（`--flow`，横线每移动 1px 纹理走 1.2px，竖线 1.6px），强度跟随速度（`--flowa`），停下后整体淡出（`lib/glass-flow.ts`，`.flow-line`）。同一机制也驱动移动中的玻璃方块：Panel Tab 方块与筛选滑块的纹理随自身移动的距离流动，落地即停。Bottom Timeline 拖动幕或时间点时的落点线也是这样一道无色玻璃，纹理随拖动距离流动（`--flow` 由 `TimelineGuideLines` 与 `ActRail` 写在线上）。

### 同族选中的水波

同一组玻璃里换选中项时，选中的晕像一道水波从旧项推到新项（`lib/glass-wave.ts`）。每个成员带一层 `.glass-wave`，水波在成员自己的坐标里开窗，途经的成员按自己的颜色依次亮起又退去。目前用在 Dock 药丸与 Bottom Timeline 同一泳道的章节块上。时长与细节见 [motion.md](motion.md)。

## 砂笔

砂笔是颗粒干笔：边缘毛糙、越走越干、末端散成丝，旁边偶有几粒散砂。浅色主题以 `multiply` 叠色，深色主题直接叠上并提亮 14%（`--pigment-blend`、`--pigment-lift`）。砂笔出现与消失都要过渡，不允许一帧切换。

- **砂笔记号**（`KindMark`）：凡是能出现在顶部 Dock 里的实体都有固定记号，在左栏、Dock、Review 分组与时间线泳道名里一致：章节＝圆印（按章节 id 固定取六枚之一），要素＝方印，故事线＝短横，要素类目＝折角，构想＝小漩涡（不在分组里的更淡），素材＝竖直纸条，通览全书＝强调色的粗钝星号。颜色取故事线或类目颜色；没有归属时用中性墨色。Preview 用空心记号（只留沿形状边缘的一圈砂，由 `hollowgen.py` 从实心记号生成）。批注、TODO 与文件夹不进 Dock，因此没有记号。
- **砂笔框**：侧栏 cell 选中时，干笔从记号旁起笔绕格子一圈（`SandFrame` 画在 `.cell-frame` 画布上，笔迹由 `lib/sand-frame.ts` 按这一格的实际尺寸现算）：四角各自抖动、四边微微鼓起，转角是笔转过去的圆，沿线有长短两种抖动；落笔先压一下，越走越干，后半程刷毛断开成丝；收笔多半搭过起点几像素，有时差一点没合上，末端一挑变细；笔迹带颗粒，旁边有几粒散砂。笔触粗细按像素固定，不随格子拉伸。每次新的选中换一个随机种子、沿路径约 `0.38s` 画出来；挂载时已选中的直接显示画好的样子；减少动效时不画过程。格子尺寸变化（拖宽侧栏、标题改变小格宽度）时用同一个种子按新尺寸重算：随机量都钉在各条边自己的坐标上，所以左边不动、右边随边缘平移、上下边在右端伸缩，拖动中不会爬动。颜色跟随 `--cell-c`，主题或强调色变化时重绘。
- **类目砂笔框**：要素面板紧凑索引里，展开的类目被一圈该类目颜色的干砂笔框包住，框是九宫格切片（`frame-box.png`），任何尺寸下笔画粗细一致；详见 [workspace.md](workspace.md)。
- **砂笔读数**（`.sand-stroke`）：统计面板里的每个值是一笔干笔，长度就是值。笔是干笔下划线（`ul.png`）按自己的比例（720 × 26）取用：短的值从笔的起头截取，所以每一笔都从墨足开始，长的值把整笔拉长；最后 `12px` 总是变干变细。不把整笔压进一段短值里，那样颗粒会被挤成一抹灰。`--dry` 只留三分之一的颗粒（草稿），`--loose` 只剩散砂（待写）；`.sand-track` 在值的整条长度下铺一层淡淡的散砂，表示还没写到的部分。笔迹出现时淡入，值改变时滑到新长度，减少动效时直接到位。颜色取 `--sand-c`，和记号一样随主题叠色。
- **封面流带**（`lib/sand-cover.ts`）：书架封面上，每条故事线是一道从上往下流的砂带，竖排的时间线上有它的章节处粗、没有处细成一丝，带边甩出几粒散砂；一条故事线一张白色蒙版，颜色取故事线自己的颜色，和记号一样随主题叠色。笔迹按作品 id 取种子，同一本书每次一样；蒙版第一次显示时一本一本现画并缓存，小封面按自己的尺寸另画。
- **章末记号**：章末 ⁂ 是三尊石（三点砂印，完成时用强调色）；悬停时展开成一列三个动作，见 [components.md](components.md)。
- **滚动标记的砂印**：滚动条上的批注与 Agent 改动刻度是圆形砂印（`sand/blob-0..5`），每颗按它的 key 固定取六枚之一、转一个角度，悬停加深；出现时砂淡入，离开整颗淡出。
- **幕扉页的一笔**：通览全书里每一幕的扉页，幕名下面一笔干砂（`sand--ul` 那张笔迹，`.act-break__stroke`），随扉页整块淡入；稿纸页眉里的故事线也是它的砂笔短横，见 [components.md](components.md) 的通览全书与稿纸页眉。

### 砂笔进正文

正文里作者留下的痕迹是砂笔，桌面端（2026-10-29）；暂停中的移动端保留原来的平涂底色。候选在画布上逐项挑定（批注静止、TODO、悬停、选中、Agent 改动、实体链接六处都取 A）。

- **批注锚点**：每处锚点是一道干笔荧光（`hl.png`），按它跨过的每一行各画一道，看起来垫在字下面：批注用批注色（静止 `0.46`），TODO 用 TODO 黄（`0.5`），Copilot 提议平时不画、指着它的卡时用它的蓝。短的一行从笔的起头截取（起点按批注 id 和行号取种子、每次刷新不变），最后 `12px` 变干变细；长的一行把整笔拉长。浅色主题把故事线色加深 16% 让它在稿纸上立得住，深色主题提亮 14% 并淡到 `0.72` 倍（`--prose-sand-deepen`、`--prose-sand-strength`）。
- **批注的状态**：指着它的 Review 卡、便笺或 TODO 卡时，整道笔 `0.24s` 加深（批注到 `0.84`，TODO 到 `0.9`），移开退回；作者主动选中它——点卡上的「跳到原文」、点滚动标记、刚写下这条批注——时，这道笔沿着行从左往右重画一遍（第一行 `0.38s`，每多一行多 `0.12s`，一口气缓出），画完停在加深的浓度，直到作者在正文里点一下或打字，再整块退回静止；桌面上这几处跳转不再闪整段的平涂底色。批注解决、删除或它的字被删掉时整块 `0.3s` 淡出；新出现的锚点整块淡入；减少动效时都直接到位。
- **批注的实现**（`lib/comment-sand.ts`）：锚点不是元素，所以画在锚点所在 `.editor__spread` 里、稿纸之后的自己一层（`.comment-sand-layer`，通览全书每一章一层）：不接指针、读屏与选区都跳过它、没有文字，所以光标、选区、输入法查询和 ProseMirror 的协调都碰不到它；它和正文在同一次原生滚动合成里移动，没有滚动监听。这一层叠在字上，像颜料一样与下面混合（`--prose-sand-layer-blend`：浅色 `multiply`，深色 `screen`）：每个字保留自己的颜色（墨字、彩色的链接字都一样），链接自己的那道砂笔也透得出来，看起来就是砂笔垫在字下。放在正文下面不行：WebKit 里 span 的混合只看得见它自己那一行画过的东西，链接下划线那一条会把批注的砂笔遮成稿纸色（负 z-index、放在稿纸之前、隔离与否都试过）；用 `darken` / `lighten` 也不行，比砂浅（浅色）或深（深色）的彩色链接字会被砂吞掉。这一层不能形成层叠上下文（不设 z-index、不加 containment、不设 opacity），否则混合看不到下面的字。正文的 DOM 一变，下一帧就重读行盒，打字时砂笔不会落后于字；锚点按存下的偏移重新匹配仍是 150ms 防抖（与移动端同一套匹配）。通览全书里正在编辑的章，静态副本隐藏（`aria-hidden`）在实时编辑器下面，锚点取显示着的那一份，两者交换时（`aria-hidden` 翻转）重新匹配。通览全书只测视口上下各一屏内的章，读被 `content-visibility` 跳过的章的行盒会逼它排版。
- **实体链接**：字仍取实体颜色，色带换成同色的一道干笔下划线（`ul.png` 按自己的比例取用，7px 高：短链接从起头截取、末尾 `12px` 变干，长的拉长），每一行各画一道；指针下 `0.24s` 加深（`0.7` → `0.95`）。「点线」样式只留这道笔的颗粒；「只悬停显示」时平时没有、指针下淡入；「只变色」没有；「与正文同色」时这道笔是正文的墨色。设置里的三档（两者都有、只要色带、只变色）不变。
- **Agent 改动**：Agent 写进正文、等作者看的改动还不是作者压实的痕迹：新增与修改的字保持墨色，下面铺一层没压实的散砂（干笔荧光只留颗粒，新增绿、修改蓝）；删掉的字变淡、被一笔干砂划掉（紫）。打字机揭示（`AgentEditAnimator` 的 `agent-reveal__ins` / `__del`）里，删掉的字在散砂划线下被擦去，新字一个个打在散砂上，揭示完整块 `0.3s` 淡出；审阅模式的就地装饰（`agent-diff-*`，代码仍在，旧的审批记录现在都按自动处理）用同一套，出现时淡入。整段改动原来那层淡绿底去掉了：揭示与滚动标记已经说明 Agent 写在哪里。
- **span 的画法**：实体链接与 Agent 改动是正文里的 span，只有背景能按行片段重画（`box-decoration-break: clone`），而背景贴图不能被 CSS 上色。所以从上到下叠三层：稿纸色（浅色以 `multiply` 叠在白遮罩上，深色以 `screen` 叠在黑遮罩上，`--prose-sand-cover-blend`）、遮罩（`ul-cover.png`、`ul-loose-cover.png`、`hl-loose-cover.png` 与 `-dark` 版，除了颗粒处处不透明，由 `covergen.py` 从 `ul.png`、`hl.png` 生成）、一条 span 颜色的色带（浓度 `--prose-sand-a`，已注册为属性，加深与淡入都能过渡）。合起来除了颗粒处处是稿纸色、颗粒处透出色带，任何颜色都行；span 再以 `darken`（浅色）或 `lighten`（深色）与它下面的稿纸混合（`--prose-sand-blend`）；落在隔离组里（通览全书被跳过排版的行、Agent 揭示层）时这三层就是稿纸色，同样看不出来。批注的砂笔层叠在它们上面像颜料一样混合，所以两道砂笔交叠时都看得见。截取处的 `12px` 收笔是一条稿纸色渐变。散砂遮罩是可横向平铺的宽条，按自然大小平铺，颗粒始终是圆的。
- **探针结论**（合成正文，WKWebView 与 Chromium）：单章 20 处批注，叠层首次绘制约 2ms、每键 0.2–0.7ms、打字时 0 帧错位；canvas 逐像素现画首次 27ms、换行时峰值 12ms，没有采用；沿用 150ms 防抖重读几何会让砂笔一直落后于字。通览全书 60 章、1200 处批注时，合成探针里 `::highlight()` 在 WebKit 中随落进 `content-visibility` 被跳过行的高亮数线性变慢（60 处每键 150ms，1200 处 2.7s）；但在真实应用里（压力种子，39 章已载入，在被跳过的行里放 60 / 320 处高亮）没有复现，每键都在 50–53ms，所以这不是现在通览全书打字慢的原因。叠层只测近处的章，探针里首次 4ms、每键 0.75ms。叠层不加长 WebKit 的输入法查询（200 片叠层 0.13–0.23ms，对照 0.14–0.17ms）。3000 个混合模式的实体链接不改变每键排版与滚动帧。
- **真实应用复测**（压力种子：100 章、150 万字，通览全书里一章实时编辑、批注锚点在正在打字的段落上，WKWebView）：60 次键入，砂笔每一帧都跟着字（0 帧落后）；砂笔每键约 0.5ms（重读几何），键入到下一帧 p50 31–33ms，同一场景暂停砂笔时 29–32ms（基线是通览全书的编辑器本身）。
