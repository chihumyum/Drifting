## 工作区级按钮

工作区级控件是圆形玻璃——左右侧栏开关、双栏按钮、Project Home、通知、Dock 的锁与 `+`、时间线开关、稿纸工具栏里的每个按钮，以及进入全书视图的入口（通览全书、要素全景、TODO 与素材库、全屏故事图谱）。静止时只有细线，悬停流动，按住加深；开着的（锁住的 Dock、打开的时间线）是选中态。它们都是同一个尺寸：直径 `--glass-round-size`（`28px`），砂笔图标 `--glass-round-icon`（`16px`）居中，按钮各自不再写像素（见 [materials.md](materials.md) 的「尺寸」）；唯一放大的一族是面板 header 里的全书视图入口，随 header 放大 1.25 倍。侧栏收起时，它的开关单独浮在桌面上，和稿纸工具栏、时间线开关一样常驻静止细玻璃线并垫浮起的底色（`--glass-fill`，轻微模糊），悬停时底色不变、只有边流动；侧栏展开后开关落进 Tab 行，线和底色一起淡出（`0.24s`）。

## 面板与菜单里的图标按钮

面板 header 里的普通低层按钮（排序、新建、折叠、显示模式）保持朴素：没有玻璃框，悬停只加深前景并垫一层 `--paper-deep`。全部用 `GhostIconButton`，不另写按钮，这样面板 header 的放大（`--panel-header-scale`）能统一作用到每个图标；“新建”保持强调色墨（`.panel-header-new`）。

## Dock 药丸

- 收起时是一排砂笔记号小点；悬停或键盘聚焦时，每个小点原地长成药丸，砂迹在玻璃下散开淡去，药丸的玻璃边取该记号的颜色，随后出现标题和关闭按钮。
- **药丸文字**：药丸长出来的那颗砂印在药丸起点下方散开淡去，同一位置留下该实体的砂笔记号（`KindMark`，Preview 为空心）作为标题前缀，记号从玻璃边内约 `10px` 开始；分栏药丸两半同理。药丸里的文字不能被鼠标选中（WebKit 需要 `-webkit-user-select`），按住拖动总是拖药丸，指针在药丸上是手形。
- **状态**：静止细线，悬停流动；当前标签是选中态；换标签时选中沿药丸行流过去（水波）；按下选中的直接从按住态过渡到选中态。
- **拖动**：手里的是一份静止的药丸副本，按弹簧跟手；拖离药丸行后原位收拢，拖回时让出插入的空位；放下时从所在处弹入新位置。细节见 [workspace.md](workspace.md)。
- **锁与 `+`**：锁在药丸行左端，`+`（新建：切到作品主页，新建那一节浮在下沿）在右端，都是圆形玻璃，和其他圆形玻璃一样大；药丸和它们一样高（`--glass-pill-height`），整行是一条齐平的玻璃。它们在药丸滚动区的两侧而不在滚动区里，药丸横向滚动时它们不动、也不压在药丸上。
- **关闭**：关掉的药丸照长出来的样子倒着走——标题先淡去，药丸收回小点的宽度、在两侧邻居合拢的地方淡出；两侧的药丸、锁与 `+` 同时滑拢补上空位（关闭前先读出每样东西的位置，提交后从那里缓回原处，FLIP），和长出用同一个时长与曲线（`340ms`，`DOCK_PILL_MS`），一起落地。小点状态下关掉的记号照砂印出现的样子倒着淡去，邻居一样滑拢。减少动效时直接到位（`dock-leave.ts`）。
- 普通药丸悬停没有卡片。

## 稿纸工具栏

情节规划、要素图片、大纲、引用链接、批注（带数量）与三点菜单组成 `.editor-bar` 横排玻璃长药丸，药丸内每个按钮是圆形玻璃并使用砂笔图标，停在每个编辑器 pane 的右下角。Bottom Timeline 开关是工具栏左边单独的一个圆形玻璃按钮，不并入工具栏，和工具栏里的按钮一样大（不是和长药丸一样高）；长药丸四边留一个托盘留白（`--glass-tray-padding`），所以比按钮高 `8px`。它和工具栏里的情节规划按钮开的是稿纸下面同一个位置，二选一（见下面的情节规划）。

## 选区浮条

正文里选中文字、选区稳定 `180ms` 后，选区上方浮出一条和稿纸工具栏同一种的横向玻璃长药丸（静止细线、稿纸半透底、不带投影；`160ms` 上移 3px 淡入）。里面每个动作——「格式」、添加批注、新建补丁、Copilot 修改——是一颗短药丸：平时看不见玻璃，悬停晕开流动，按住加深。悬停或点击「格式」时，浮条另一侧展开第二条玻璃长药丸，里面是一排圆形玻璃按钮，每个是一枚砂笔符号：¶ 正文、H1、H2、H3、引用（两点）| B 粗体、I 斜体、U 下划线、S 删除线，块级与行内之间空 `8px`、不画分隔线；已用的格式是静止的选中玻璃，「格式」在第二条展开期间也是。第二条 `150ms` 展开，离开 `140ms` 后 `110ms` 收回。

一级与二级各管各的：两条长药丸是 `body` 上并排的两块，第二条不长在第一条里面。指针在哪一块上，只有那一块流动；在第二条里按一个符号，只有那颗按钮加深，第二条和第一条都不变。长药丸本身是装按钮的容器（`.glass--rest.glass--surface`）：指针在上面时流动，里面有东西被按下时它不加深。暂停中的移动端仍是桌面色浮层。

## 大纲 rail

稿纸左边的大纲是纯字标签，按深浅表达层级：幕用衬线结构字（不再有前面的短线），章与标题用非衬线，越深越淡；可见范围内的标签字深一档；没有「·」分支点。不在视野里、也不在当前路径上的章和幕、场景一样淡（`--ink-3`），所以通览全书时整列章名不会抢眼。当前阅读位置只靠字变明显：它和往上的各级（所在的章、幕）都是加粗的墨字（`--ink-1`、`600`），底下不再抹砂，也没有底色、框或强调色。「⋯」省略号展开的是一块紧凑的菜单浮层，行是菜单行，悬停的那行流出玻璃环。桌面上 rail 从 Dock 药丸的下沿开始（药丸居中在窗口控件行上，下沿在 `(--window-titlebar-height + --glass-pill-height) / 2`），所以最上面一项正好贴在药丸下面，不会和药丸落在同一行。

## 滚动标记

叠在右侧原生滚动条上的批注与 Agent 改动刻度都是砂印（浅色主题正片叠底）：批注、TODO、Copilot 批注是横跨滚动条的一颗 `6px` 小圆印，Agent 的新增、修改、删除是各自细道里的一颗 `3.4px` 小印，颜色与分道不变。每颗印按它的 key 固定取六枚之一、转一个角度（`scrollMarkerSeal`），刷新也不变。悬停只让砂印加深，不出玻璃环。新刻度出现时砂淡入（`0.34s`），看过的改动整颗淡出（`0.3s`）后才移除，已解决的批注只剩淡淡一印。

点批注的刻度在桌面上不再闪整段的平涂底色，而是选中这条批注：正文里它的砂笔沿行重画一遍（见下面的「正文里的批注、链接与 Agent 改动」）；Agent 改动的刻度仍闪一下它的段落。

## 情节规划

情节规划和 Bottom Timeline 共用稿纸下面同一个 Bottom Panel，二选一：时间线开关与稿纸工具栏里的情节规划按钮各开一边，打开一边就收起另一边，两个都关就收起整个 Panel（结构性开合 `420ms`）。

Bottom Panel 是一个共享的壳子（`BottomPanel`）：顶边那条线、线上的拖高把手和高度都属于壳子，两边共用一份高度并记住它（沿用时间线原来的存储键，作者拖好的高度两边都用）；拖动时最低停在时间线泳道放得下章名的高度。壳子里的每一边是一整块，带着自己的 header 行——header 是两边共用的 `BottomPanelHeader`（`.bottom-panel-head`：桌面色、`30px` 高，前端写这一边是什么，后端放它的操作），样式只写一处。Panel 开着时两边互换，壳子不动，只有里面那整块（连同 header）像重冰一样被推开（`265ms`，先慢后快）：从时间线换到情节规划，时间线整块向上推出顶边，情节规划从下面同时升上来，它的 header 落在原来时间线 header 的位置；换回去则反过来向下推。推进途中新来的那块四边晕出发丝玻璃，时间线泳道之间的线也一起晕开，落地后 `340ms` 整体淡出；中途再切换就从两块当时的位置接着推。情节规划跟随当前获得焦点的章节或构想（分屏时跟着焦点走），由那个编辑器把自己的网格放进这个位置，推走或收起的途中网格也跟着走；离开那一章时，网格在原处留下一份静止、不可操作的副本（连滚动位置），陪 Panel 收起或等下一章的网格到来再换掉，不会先闪空；header 前端是它的记号和名字，后端是不带玻璃的文字按钮（加行、加列、铺满、清空，清空悬停是危险色），header 下有一条 hairline 与网格的列头分开。当前不是章节时情节规划自己隐藏（作品主页、通览全书、故事线、设定等；分屏时看焦点那一边）：Bottom Panel 收起，时间线也不出来；再回到章节或构想，它跟着那一章回来，开着的选择一直记着。新开的章节编辑器还没就绪的那一瞬，只有一行写着「情节规划」的 header 先占位。

样子是这一章自己的小时间线（泳道），数据仍是原来的行×列：每一行是一条泳道，名字用衬线结构字写在左边桌面色的栏里；每一列是顶上的一个节拍，用等宽索引字；泳道是稿纸白，之间是和时间线轨道一样的桌面色 `0.5px` 线。每一格是一张纸条：稿纸底、`2px` 圆角、静止细玻璃线，悬停晕开流动，光标在里面时是静止的选中玻璃（`.glass--rest.glass--field`）；空着的纸条平时什么都没有，指针或光标到了才出细线和「写点什么…」。表头改名时也是静止的选中玻璃，「⋯」和右下角的缩放把手悬停只加深墨色，拖把手时的尺寸读数是桌面色上的等宽字。没有底色变化、投影或强调色。暂停中的移动端仍是原来的 hairline 表格。

## Panel Tab

左右栏每个半栏顶部一行 Panel Tab（`PanelTabTray`）。

- Tab 本身只是文字，没有玻璃框，也没有按压态；悬停只加深文字，点击后文字立刻变成选中样式。
- 选中项下面垫一块玻璃方块：没有圆角，稿纸半透底加静止的选中态玻璃边，宽度是这个 Tab 均分到的整格，上下离 Tab 行边缘各 `2px`。
- 换 Tab 时方块和 Panel 推进共用同一个时长与曲线（`265ms`、先慢后快的“重冰”，`PUSH_MS` / `PUSH_EASING`），两者同一刻落地；方块移动时玻璃纹理随移动距离流动，落地就静止，悬停也不会让它流动。
- 整个 Tab Header 区域就是方块的轨道（`PanelTabRowEdges`）：指针停在某一栏的任一 Tab 上（选中或未选中都算）时，这一栏 Header 的四条边一起晕出缓慢流动的玻璃（窗口上边、Tab 行下面那条线，以及它与窗口、另一栏或稿纸相接的两侧），另一栏不动。

## 多选一

多选一（Review 的全部／批注／TODO、新建素材的文本／图片／PDF）用 `GlassSlider`：直接放在面板上并排的几个字，底下不垫轨道，只有一块没有圆角的玻璃滑块——浮起的底色加静止的选中玻璃，和 Panel Tab 下面的方块同一种，玻璃边也取同一块纹理（这么小的块取别处几乎看不见边），滑动时纹理随移动距离流动——压在选中项下面；换选时它沿底部时间线同一条临界阻尼弹簧（`520ms`）带着重量滑过去，选项本身没有边框。

放不下并排的几个字时（Review header 剩下的宽度装不下三段，例如较大字号或侧栏拖窄），`GlassSlider` 收成单个 tab：只留选中的那一项，玻璃方块仍垫在它下面；指针移上去，几个选项在 tab 正下方竖排展开（menu surface，portal 到 body），玻璃方块垫在当前项下；点另一项时同一块重玻璃带着流动的边沿竖向滑过去（和并排时同一弹簧、`520ms`），列表不随选中收起，指针离开 tab 和列表 `160ms` 后才收起；方向键在 tab 上直接切换。一份隐藏的副本持续测量并排时需要的宽度，所以空间回来后自动展开回并排。

同一个多选一在一次提交里被另一份替换时（三个 Super View 各有自己的头部，换视图就换下一条切换器、换上另一条），两份共用一个交接键（`handoff`，`components/ui/glass-slider-handoff.ts`）：离开的一份留下玻璃所在的位置（静止时就是它最后画的位置，不读布局；还在滑时才量一次），新的一份先把玻璃画在那里，第一次落位就从那里滑到自己的选中项。留下的位置只在那一次提交里有效，之后打开的滑块照常原地落定。只用于并排的滑块，收起的单个 tab 不交接。

## 范围开关

只有两种状态的（只看当前标签页这一项，或看整个项目）用 `ScopeToggle`，和 Dock 的锁一样：一个永远不变的词——各个 panel、各种对象一律写“当前”，不再按章节／构想／要素／故事线换成“本章”“本故事线”——没有圆角，关时只有静止玻璃那条细线，开时是静止的选中玻璃；当前标签无法按它筛选时置灰。切换状态一律靠选中态，不靠改按钮上的字。

## Switch

圆角药丸形状与干净的白色圆钮（深色主题为浅墨色），轨道是玻璃：关时只有静止态那条细玻璃线；开时整条轨道晕上静止的强调色玻璃（同一张纹理切出、不流动，`.ui-switch__tint`），圆钮压在上面不沾色；悬停只让无色的边晕开并流动。

## Chip

Chip 只指一种东西：一组里各自独立开关的小件，可以同时开好几个（画布上画哪些关系类型、素材库列哪些类型）。只能选一个的不是 chip，用多选一（`GlassSlider`）；只有两态的用范围开关。Chip 是范围开关那一族（`FilterChip look="glass"`，`.ui-chip`）：

- 等宽索引字，不大写、不拉字距，词永远不变；关时只有静止玻璃那条细线，开时是浮起的底加静止的选中玻璃（`aria-pressed`），小圆角 `2px`，取稠密的纹理（`.glass--small`）。
- 玻璃是无色的；类型的颜色只在名字前那道砂笔短横（`KindMark kind="storyline"`），关着时短横淡到三成五。没有可显示的（数量为 0）时字退到最淡一档、细线也淡一半。
- 数量写在名字后面，等宽、次级墨，不垫灰块。来自构想的关系在短横前多一个构想的砂笔小漩涡，不再用发光虚线框。
- 不再有实心墨块、描边小块或「· 开／· 关」换字。暂停中的移动端仍用纸底的 `FilterChip`；桌面书架与作品主页都不再有筛选。

Chip 旁边不属于一组的同类小件（两态的「聚焦」「粘带」、打开菜单或弹层的「全部」「未放置」）是同一种玻璃的不变词开关（`.ui-word-toggle`），开着或展开时是选中态（`aria-pressed`／`aria-expanded`），后面可以跟一个等宽数字。

不是按钮的小件各只有一种写法：指向某个实体的**引用**是它的砂笔记号加名字，没有框，能点开的悬停出一圈取它颜色的流动细玻璃（侧栏 cell 的语法）；**数量、方向、读数**是等宽索引字、次级墨；**状态字**是一个有颜色的等宽字（Review、补丁、TODO 卡已经这样）。三者都不垫底、不套胶囊。

## 侧栏 cell

**Cell 语法**（`SandCell`）：左栏的章节、要素、构想、故事线标题，以及素材库条目，记号始终显示；悬停时整圈轮廓变成一条故事线/类目颜色的 hairline 流动玻璃（同一张纹理切出的一个环，四边粗细一致）；单击打开预览 Tab 时，砂笔从记号出发绕 cell 画一圈框（见 [materials.md](materials.md) 的砂笔框），离开时整框淡出后再复位；双击固定 Tab 不改变 cell 外观。面板构建时已选中的 cell 直接淡入框而不重画。不再使用 `--surface` 或强调色底色，也不用 hover wash；键盘 `focus-visible` 轮廓独立保留。

## 时间线章节块

Bottom Timeline 的章节是有重量的玻璃块：静止时是稿纸底色加故事线颜色的玻璃边，占满泳道高度；当前章节是选中态；在同一泳道里换章节时选中沿泳道流过去，换到别的泳道时原地淡入淡出。拖动时只有手里这一块移动，横向是临界阻尼的弹簧（略落后于手、不回弹），跨泳道时停在原泳道，直到指针越过下一泳道的中线才一次吸附过去并带极轻微的回弹，放下的位置就是它所在的泳道（`chapter-lane-drag.ts` 的 `weighted`）。拖到别的泳道上方时（吸附过去的那一刻），这一块的玻璃边就换成那条泳道的故事线颜色，`0.24s` 晕过去，不等放下；拖回原泳道、拖离所有泳道或取消时回到原来的颜色。颜色只写在手里那一块（拖动的副本）上，每换一条泳道写一次：不重渲染 React，也不在根元素上写变量（`laneColor`，2026-10-30）。泳道名前是故事线的砂笔短横；时间线上不画砂笔笔记。

## 时间线头部

Bottom Timeline 的头部和面板 header 同一级，都在桌面灰上：

- **书序／叙事时**是多选一（`GlassSlider`）：两个字直接写在头部，选中项下垫一块玻璃方块，换视图时按时间线同一条弹簧滑过去。
- **未归属**（显示或隐藏未归属泳道）和**未放置**（叙事时下打开未放置章节的弹层）像范围开关：一个永远不变的词加一个等宽数字，静止细玻璃线，开着或弹层打开时是浮起底加静止的选中玻璃（`btl__toggle`，`aria-pressed`／`aria-expanded`）。不再把字换成「隐藏未归属」。
- **铺开**和**定位当前**是面板 header 的平面砂笔图标（`GhostIconButton`），悬停只加深墨色；旁边进入故事图谱的入口是圆形玻璃。幕栏与时间轴头上的 ＋ 同样是平面图标。
- **未放置弹层**是菜单外壳；每一行是菜单行（`btl__unplaced-row`）：不垫底，前面是章节的砂笔圆印，悬停时这一行出一圈故事线颜色的细玻璃环，按住加浓，可以直接拖到叙事时间轴上。

## 幕标签与时间点

书序下的幕栏和叙事时下的时间轴用同一种标签，贴着各自的边界线（`ActRail` 的 `glass`，根上是 `actrail--glass`；`TimelinePin` 的 `glass`）：

- 标签是没有底色的静止细玻璃小块（小圆角 `2px`，取稠密的纹理），幕有颜色时玻璃取幕的颜色；幕名是结构字（`11px` 中等字重，与稿纸大纲里的幕同一套，改名时输入框也是），后面的章数仍是等宽；悬停流动，按住拖动边界时加深。改名时输入框是浮起底加静止的选中玻璃（`<input>` 没有自己的 `::before`，玻璃在外面一层）。
- 绑定了构想的时间点或幕，名字前是构想自己的砂笔小漩涡；不再用强调色描边或强调色底。
- 幕边界在悬停时晕出一道缓慢流动的无色玻璃竖线；拖动幕标签、边界或时间点时，落点线从幕栏一直贯穿到最下面的泳道，是同一道无色玻璃，纹理随拖动的距离流动（`--flow`，竖线每移动 1px 纹理走 1.6px）。时间线里不再出现强调色的线。
- 故事图谱的幕栏与时间点打开了同一个 `glass`（见下面「故事图谱」）。

## 时间线泳道名

泳道左端的故事线名是侧栏 cell 的语法（`SandCell`，嵌在名字栏内留出画框的位置），名字是结构字：故事线的砂笔短横常驻；悬停出一圈故事线颜色的细玻璃环；这条故事线正在编辑器里打开时，砂笔绕它画一圈框。本书与未归属两条合成泳道没有实体，不出玻璃也不画框。章数写成「5 章」，泳道白底的圆角是 `2px`。

## 构想托盘

故事图谱与要素全景底部的构想托盘（`DriftPanel`）浮在图谱上，所以用浮起的玻璃（稿纸 80% 底加 `1.6px` 背景模糊）：

- 收起时的入口是一个小圆角的静止细玻璃块：构想的砂笔小漩涡、「构想」与等宽数量；悬停流动，按住加深，不再反成墨色。
- 展开后上方的关闭是圆形玻璃按钮。
- 每张构想卡片是浮起底加静止细玻璃线，标题前是构想的小漩涡（构想没有书序，不再写 § 编号）；悬停流动，按住拖动时加深；Shift 点选的连线起点保持按住的浓玻璃，选中连线的一端是静止的选中玻璃；搁置中的构想只变淡。没有灰底、虚线外框或强调色描边。

## 章末 ⁂

章末是三点砂印（三尊石，完成时用强调色）。悬停（短暂停留后）、点击或键盘聚焦时，⁂ 缩小淡出，三个动作从它的位置上下展开成一列：主动作“新建下一章”留在 ⁂ 那一行，上下两项伸进章末留白，不挤动稿纸；每项前是它的砂笔图标，被悬停的那项出现一圈和侧栏 cell 一样的淡玻璃轮廓，禁用项没有。离开后直接收回成 ⁂（展开 `150ms`、收回 `110ms`）。

## 分屏中缝

两个编辑器之间的中缝可以横拖调整比例，中间有一根 I 形小竖条。指针停在竖条上（或键盘聚焦）时，竖条留在原处，左侧展开「左右互换」、右侧展开「解除分屏」，离开后收起。

## 主按钮

一组操作里只有一个主按钮，是这组里作者最该按的那个（发送、仅这一次、继续此任务）。它常驻强调色的选中玻璃——和开着的 Switch 同一种晕——字用强调色墨，不填色；悬停时这圈玻璃流动，按住加深；停用时退回一条淡淡的无色细线，字变浅（`.glass--primary`）。只有图标时是圆形玻璃（Agent 对话框的发送、补充），有字时是小圆角的矩形。

## 次按钮与文字按钮

同一组里的其余按钮是次按钮：静止细玻璃线（`.glass--rest`），悬停晕开流动，按住加深，字用次一级的墨（拒绝、本会话允许、停止）。不值得一圈玻璃的操作是文字按钮：没有玻璃，悬停只加深字（查看原始参数、面板 header 里的历史与新对话）。

共用的 `Button` 在桌面就是这几种按钮（2026-10-29）：`variant="primary"` 是主按钮，`default` 是次按钮，`ghost` 是文字按钮，`danger` 见下一节；字是非衬线 13px 中等（与 Agent 面板一致），高度跟随 `--ui-control-height`（28px），`size="sm"` 矮 4px，用在行内（版本历史的恢复、关系卡的删除）。砂笔图标放在字前、与字同色；在跑的按钮把图标换成转动的缺角圆相。暂停中的移动端保留原来的实心按钮（`Button` 按 `isMobileShell` 不加玻璃）。设置页的按钮也已换成它（`SettingsButton`，见下面「设置页」）；`.set-btn` 只留给暂停中的移动端设置，和设置以外还借用它的数据库恢复、全屏状态、项目运行时与 Super View 加载失败四处。

## 危险操作的按钮

删除、清空、不能撤回的覆盖用危险操作的按钮：它就是次按钮，只是那圈静止细玻璃线、字和砂笔图标（字纸篓）都用危险色（`--destructive`）。悬停时红色的玻璃晕开流动，按住加深；停用时和别的按钮一样退回一条淡淡的无色细线。不垫红底，平时也不常驻红晕，按下前不吓人（2026-10-29 改，此前是无色细线加危险色的字）。全应用的 `Button variant="danger"` 都是这一种：危险确认（`ConfirmationDialog`）、书架的移到最近删除与永久删除、最近删除里的「立即删除」等。危险确认的对话框打开时焦点先落在「取消」上，回车不会直接删掉；普通确认仍先聚焦主按钮（`ConfirmationDialog`）。菜单与悬停卡里的危险项照旧只用危险色的字（`.menu-surface__item--danger`），书架卡上的字纸篓图标按钮也只在悬停时变成危险色的墨。

## 对话框

对话框是又一块从桌面掀起的浮层，和菜单同一组外壳（`--menu-surface-*`）：侧栏同色的不透明底、直角、半像素墨线加浮起投影，整体没有玻璃（`ModalRoot` / `ModalCard`，`.modal-*`）。背后不压暗，蒙一层桌面自己颜色的薄雾（`--workspace-ui-bg` 的 58%）。标题、正文与操作区之间不画线，用留白分开：标题 16px 中粗（heading 档），标题上的小标题用等宽索引字、不强制大写，副标题用次级墨；关闭是右上角的平面砂笔图标按钮。操作区靠右，主按钮在最后；结果或进度写在操作区左边。正文里的分节是等宽小标题加控件（`.dialog-section`），不画框。导入、所属故事线、新建补丁、绑定构想、版本历史、分享为 Markdown、公开测试版说明与 Debug 面板都用这一个外壳；首次运行的选择页保留它透明的遮罩。移动端保留原来的白卡与遮罩。

## 单行输入框

照多行输入框做：稿纸色片加一圈静止细玻璃线，悬停晕开流动，光标在里面时是静止的选中玻璃；圆角按形状语法用 2px（多行仍是 16px 的 `.ui-field--area`）。搜索框在字前放砂笔搜索图标，计数这类读数用等宽字放在框尾（`.ui-field__meta`）。停用时片子变淡、细线更淡。写法是 `<label className="ui-field glass glass--rest glass--field">` 包住 `<input>`，小号 `.ui-field--sm` 用在列表行里（导入队列的标题）。

## 下拉选择

选项多于 4 个、或选项是一个个实体（故事线、类目）时用下拉选择；不超过 4 个的短选项用多选一（`GlassSlider`），两态用范围开关或 Switch。触发器是一块单行输入框，前面是当前项的砂笔记号，右端一笔折（`GlassSelect`）。点开是菜单外壳的列表（portal 到 `body`、固定定位），与触发器同宽、不窄于 standard 档；每项前是它的砂笔记号，当前项中等字重并带一枚批阅一勾；方向键移到的那一行是一圈静止的选中玻璃，指针下的行流动；多于 8 项时列表顶上出现搜索框。

## 整行开关（复选）

在一组里勾选几项（章节归属的故事线）用整行开关：整行就是那个勾选框，和侧栏 cell 一个语法——悬停时一圈流动玻璃，打开时是静止的选中玻璃，都取这一项的颜色（`--toggle-color`），名字变中等字重；行前是它的砂笔记号（`.ui-toggle-row`，`role="checkbox"`）。行尾附带的单选（「主线」）是范围开关那样一个永远不变的词，没勾上的行里它停用。

## 空状态

一句平实的话，次级墨，居中，不用斜体（中文没有真斜体）。编辑器里某一节空着时不用它，而是更小的一行等宽说明 `.ui-section-empty`（见「实体编辑器」）。缺的是哪一类东西，就在上面放那一类的空心砂笔记号（Dock 里 Preview 用的那种）；不是某类东西时放这个地方淡淡的砂笔图标（通知中心的风铃）；能就地新建时下面跟一个文字按钮（`EmptyState` 的 `mark`、`icon`、`action`）。移动端保留原来的斜体灰字。

## 加载与进度

等数据用砂笔的缺角圆相，次级墨，匀速转（`0.9s` 一圈）：块级 20px、字在下面（`LoadingStatus`），行内 14px、换掉按钮或行首的图标（`BrushIcon name="loader"` 加 `.ui-spin`）。加载超过 `240ms` 才出现，免得一闪。Agent 思考的「砂聚成点」只表示 Agent 在想，不拿来表示加载。有进度时是一根细线：1px 轨道上一段 2px 的强调色直头填充，不知道总量时一小段来回走（`.ui-progress`）。减少动效时都不转、不走。

### 全屏加载与字海

整个窗口要等的时候（启动、检查登录、打开项目、项目代码还在载入）不再转圈：桌面窗口底下铺着一片**字海**（`CharSea`，`lib/char-sea/`，2026-10-31）。

- **静止**：一张稿纸。每 14px 一格（英文 9 × 14，阿拉伯文 10 × 14），格心一个次级墨约 7.5% 的小点（深色 9%），底色就是桌面色 `--workspace-ui-bg`；有一格的中心落在窗口正中。水面静止时什么都不算、不画，像不存在。启动占位（`index.html`）就是这张静止的稿纸，同样的格子、同样的对齐、同样的桌面色，React 接手时看不出换了一层。
- **水面**：底下是一层水（7px 一格的二维波动方程，9 点拉普拉斯让波纹是圆的，四边吸收、不反弹；每秒 100 步，与刷新率无关；波每秒走约 310px）。波经过的地方，格里的点浮成这一格的字：格里按阅读顺序写着一段文字，所以涟漪里读得出半句话。字整块随坡度漂几像素、在波峰略放大加深（放大 20%、最浓 62%，深色 58%），不会被撕开。一圈波纹一秒半后还看得见；整片水面平静下来之后会更快收住，按一下约五秒后完全静止，循环随之停下。
- **语言**：字跟着界面语言走：中文写汉字，日文写汉字与假名，阿拉伯文写阿拉伯字母（从右往左，一格一个独立字形，去掉附加符号），其余写拉丁字母（窄格，像一排排活字）。每种文字各有一段 Drifting 自己写的散文（不读作者的稿子），字形用捆绑的结构字体（Noto Serif SC、Newsreader），日文、阿拉伯文用系统的衬线字。
- **加载**：`FullScreenStatus` 在等待时只告诉字海「在等」（字留给读屏）。等过加载延迟（`240ms`，`LOADING_DELAY_MS`）还没好，就开始落水滴：每 `1.1s` 一滴；如果等待是两秒内的一次按下引起的（点开一本书），水滴落在按下的地方，否则落在窗口正中。点开书的那一下当场就荡起一圈，作为即时的反馈。等完了不再落滴，余下的波纹在接下来的页面底下荡完。出错的等待照旧是文字、重试与回书架。
- **退潮**：等待打开的是工作区（不躺在字海上的页面）时，字海不立刻收起，而是退潮：不再落滴，指针也不再搅动它；已经荡出去的波纹在工作区底下照常走完。这段时间里工作区的桌面色让开（`html[data-char-sea='ebb']` 下 `--workspace-ui-bg` 是透明），稿纸照旧不透明，左右栏像书架上的作品卡一样只透出 12%；工作区整块从 0 淡入（`--motion-structural`，减少动效时不淡）；静止的小点同时在约 0.3 秒里淡掉。水面静止后桌面色回来（和字海的底色同一个颜色，看不出换层），字海收起、不再计算；窗口被挡住画不出帧时最多 8 秒也收起。退潮中回到书架，字海直接回到平常的样子。
- **书架**：书架躺在字海上（`.pp--sea` 不铺自己的底色）。指针移动拖出一道很轻的尾迹（越快越明显），在空桌面上按下荡起一圈；对话框与菜单上的按下不算。作品卡的静止细玻璃线改由字海画（`.pp-card--sea` 去掉 CSS 那圈线）：同样是 1px 的无色玻璃、同一张纹理切出的深浅（`glass-thick.png`，150px 一块，按 `:nth-of-type` 的轮换起点），线本身不动；只是线里的玻璃随底下的水变化：波峰经过的那一段变粗变深并向内微晕，波谷经过时变细变淡。悬停与键盘聚焦照旧是晕开与 `15s` 一圈的流动。「新建一本」平时没有线，只在波经过时短暂显出它的玻璃边。卡片底下的字海只剩 12%。
- 只在桌面、且有 WebGL2 时铺；暂停中的移动端与没有 WebGL2 时，全屏等待仍是转圈，书架与作品卡保持 CSS 的样子。减少动效时字海只留静止的点阵。

## 全局搜索与查找条

全局搜索（`GlobalSearchModal`）、稿纸内查找条（`FindToolbar`）与它下面的结果列表（`FindResultsList`）都是平面浮层，用菜单外壳。搜索框是单行输入框，计数用等宽字写在框尾；关闭、上一个、下一个是平面砂笔图标按钮。全局搜索的组头是实体的砂笔记号加名字，数量与种类用等宽索引字；每条结果与组头都是菜单行，键盘移到的当前项是一圈静止的选中玻璃，指针下的行流动。命中的字只加深加粗，不垫底色（`.search-hit`）。稿纸正文里的命中仍是平涂（全书查找用的 `::highlight()` 只认底色），颜色取强调色，跟着作者自定的强调色走。

## 通知中心与账户菜单

账户 cell 里的头像与名字也是一块玻璃，和旁边的 Project Home、通知一样：平时看不见，指针在上面时边晕开、缓慢流动，账户菜单开着时是静止的选中玻璃；不再像旧样子那样整块变亮。通知中心与账户菜单都从左栏底部的账户 cell 向上展开，用菜单外壳的富内容版。通知中心（`NotificationPill`，panel 档 360px）每条是一行菜单行：行首是状态的砂笔图标（完成、有问题、失败、在跑），来源与时间用等宽字，未读的标题加粗；能跳到章节的行悬停时流出那圈玻璃，删除按钮只在指着的行上出现；出错用危险色的字，同步进度用细线；清空是文字按钮，没有通知时是空状态。上次出了故障（崩溃后补充说明，2026-10-31）是一条失败行，来源记号是断笔；它未读时铃铛一直是危险色的「！」墨印，打开通知中心才回到风铃；点它打开反馈对话框。账户菜单（`UserMenu`）的头部、各组之间都不画线，组与组之间 8px 留白，行贴齐菜单边；名字不用斜体，状态用次级墨的等宽字；主题与语言用多选一（`GlassSlider`）；Copilot 二级页的返回是平面图标按钮。

## 书架

打开应用、或在项目里按红灯（`⇧⌘W`）回到的这一页是一张平的桌面（`--workspace-ui-bg`），字直接写在桌面色上，没有白底框、实线框、底色 wash、实心强调色块与投影；书架上的红灯照旧关窗口（`ProjectPickerView`，`project-picker.css`）。

- **页头**只有结构字的「书架」（22px，2026-10-31 起不再跟作者的正文字体走；书名与封面首字仍用正文字体）与右端一颗圆形玻璃里的头像；名字、账户与本地书库都在它打开的账户菜单里。没有「YOUR WORKSPACE」小标题与副标题。
- **页面上只有页名、头像和书**（2026-10-31）：这是写作软件，书架不会长到要筛选、搜索或换成列表，所以没有工具栏（「全部作品」与本数、筛选、搜索、卡片 / 列表切换、「新建作品」按钮）、没有列表视图，也没有页脚。新建一本是网格末尾的「新建一本」；「最近删除」挪进头像打开的账户菜单，有删除的作品时才出现，后面是等宽的数量；「本地书库」与邮箱本来就在账户菜单里。
- **封面**是书架上唯一一张稿纸色的小页（126 × 226）：作品的故事线竖排成时间线，上面是第一章，每条故事线一道往下流的砂带，按作者的顺序并排，有它的章节处粗、没有处细成一丝，所以封面读得出书的结构；没有故事线的书是一道中性墨色。左上是书名首字（正文字体），没有书名时换成通览全书的星号；左下是等宽的体裁。砂带是白色蒙版、颜色在 CSS 里叠（浅色正片叠底，深色直接叠并提亮，和所有砂笔一样，换主题不重画）；笔迹按作品 id 取种子，同一本书每次打开都一样（`lib/sand-cover.ts`）。蒙版在第一次显示时离开主路径一本一本画、本次会话里缓存。数据来自只读查询 `readProjectCover`（每条故事线一行：颜色与它所在章节在阅读顺序里的位置），不动表、不加迁移。
- **作品卡**是不垫底的细线卡（`.glass--rest`）：静止时一圈细玻璃线，悬停流动，按下加深；桌面上这圈线由底下的字海来画，线里的玻璃随水的起伏变粗变细（见上面的「全屏加载与字海」）；整张卡打开作品，编辑与移到最近删除是两枚只在悬停时出现的平面砂笔图标按钮。卡上依次是书名（正文字体）、副标题、梗概、等宽的字数 / 章 / 故事线 / 要素，进度是一笔墨色的砂笔读数（`.sand-track` 上的 `.sand-stroke`，长度就是进度、没写到的是散砂），最后一行是等宽的状态字（在写 / 草稿 / 搁置，越久越淡）与最近编辑时间。网格末尾的「新建一本」是砂笔 cell：两笔十和一句话，悬停出一圈玻璃环。
- **空书架**：还没有书时，网格里只有「新建一本」那一格。
- **对话框**都用共用外壳与控件：新建与编辑一本书是两个上下排的输入框（书名、梗概）、操作区左边写快捷键 `⌘↵`，取消是文字按钮、确认是主按钮；移到最近删除与永久删除用危险操作的按钮，打开时焦点在「取消」；最近删除的每本是一行砂笔 cell，带次按钮「恢复」与危险按钮「立即删除」，确认那一步在同一个对话框里，Escape 先退回列表。出错是危险色的字加砂笔图标。
- 暂停中的移动端书架保留原来的样子：它的对话框仍是 `.pp-modal*`（`mobile-project-shelf.css` 依赖）。

## 登录与注册

登录是从账户菜单或设置里打开的对话框，盖在当前画面上（`AuthDialog`，共用外壳），首次运行的选择页里也是同一个流程（`AuthFlow`）。桌面对话框（`presentation="dialog"`，`.auth-flow--dialog`）用控件层：邮箱、密码、笔名与验证码是单行输入框，标签用等宽索引字；登录 / 创建账号是通栏的主按钮，「忘记密码？」「用邮箱验证码登录」「换个邮箱」「重新发送」是文字按钮；页脚只有一行字加墨色的文字按钮（注册 / 登录），不画线、不垫底；出错是危险色的字加砂笔图标，不垫红底；连接书库时是缺角圆相（`LoadingStatus`）；同步没完成时是文字按钮「稍后再说」与主按钮「重试」。暂停中的移动端登录页（`presentation="page"`，`mobile-auth.css`）保留原来的输入框与按钮。

## 反馈对话框

提交反馈（账户菜单、设置 → 关于、通知中心里的「上次出了故障」）用对话框外壳（`FeedbackDialog`，`feedback.css`）：多行输入框写话，下面一节等宽小标题加单行输入框填联系邮箱（地址不对时那圈细线换成危险色），再一行 Switch「附上脱敏诊断摘要」，行尾文字按钮「预览」在下面展开一张只读细线卡，等宽字排出要发的摘要。操作区：取消（崩溃补充时是忽略）是次按钮，发送是主按钮；发出后左边是完成墨印加「已发送」，只剩关闭；发不出去时左边是危险色的「没能发出」，主按钮换成带斜出箭头的「用邮件发送」，没有托管服务或离线时一开始就是它。崩溃补充时标题上的小标题是故障时间。

## 多行输入框

作者写字的框是一张稿纸色的圆角片（圆角 `16px`），平时就有一圈静止细玻璃线（像 Dock 药丸）；悬停时晕开流动，光标在里面时是静止的选中玻璃（`.glass--field`）。文字和按钮之间不画分隔线，用留白分开。左下的菜单（模型与思考、语音输入）装在一条玻璃长药丸里，每个是圆形玻璃按钮，和稿纸工具栏一样（同一尺寸、同一托盘留白）；右下的停止、补充、发送是单独的圆形玻璃，也是同一尺寸，图标都是 `16px`。语音输入的状态（录音时长、转写中、出错）写在药丸右边，录音中是按钮的选中玻璃加红色的停止方印，不再闪红底。

## 卡片

卡片不垫底色，只有一圈静止细玻璃线（`.glass--rest`，和 Dock 药丸同一种不均匀的线），小圆角。只读的卡片（任务清单、读取类的工具步骤）悬停不变（`.glass--still`），免得看起来能按；能展开的卡片（带输入与结果的工具步骤）悬停时流动，按下不加深（`.glass--surface`）。作者已经发出的话也是只读的：和对话框同一张稿纸色圆角片，同一圈细线，悬停不变。

## 等你处理

等作者决定的卡片（Agent 请求执行操作、Agent 提问、被中断的步骤、需要继续的任务）和其他玻璃正好相反：强调色玻璃平时一直缓慢流动，直到作者做出决定；指针移进卡片，卡片停下；再移到卡里的主按钮上，按钮也停；移开后接着流（`.glass--waiting`）。卡里的主按钮同样平时流动、悬停停，次按钮照常。

## 刚到的步骤

Agent 工作时新出现的一步（工具调用）先由一道流动的玻璃从左往右推过去一次，推过之后它的静止细线才淡出来（`.glass-sweep`，`1.125s`，见 [motion.md](motion.md)）。从历史载入的、已经结束的步骤直接出现，不推。

## Agent 面板

右栏 Agent 的正文按上面几条组合：作者发出的话是稿纸色圆角片，Agent 的话直接写在侧栏上，工具步骤与任务清单是细线卡片，请求与提问是等你处理的卡片，本轮改动的实体是砂笔记号加名字、没有框、悬停出一圈流动玻璃（侧栏 cell 的语法），出错用危险色的字加砂笔图标、不垫红底，跳到最新是一个圆形玻璃按钮。对话框见上面的多行输入框；发送是「上提」，补充进正在跑的任务是「弯杆上提」，回答 Agent 的提问也是「上提」，停止是实心方印（见 [materials.md](materials.md) 的砂笔图标）。只有桌面的 Agent 记录打开 `AgentGlassContext`；暂停中的移动端渲染同一批消息组件时保留原来的样子。

工作记忆（`WORKING_MEMORY.md`，`AgentWorkingMemoryView`）照 Project Memory 的做法：文件名与说明直接写在侧栏上，用量是一笔砂笔读数（统计面板同一种，量到第三档提示 Agent 整理的 8 万 tokens），读数下面是等宽的 token 数与更新时间；文档本身是一张只读细线卡（`.glass--rest.glass--still`），下面是带砂笔图标的文字按钮「编辑」「清空」，清空用危险色的字。编辑时整块换成多行输入框的圆角片，操作区是文字按钮「取消」（放弃草稿）与主按钮「保存」。还没有内容时是空状态加一句说明与一颗次按钮「创建工作记忆」。没有强调色的底、进度条与描边纸框（2026-10-29 候选 A）。

首次引导（2026-10-31 候选 A「就地连接」，`AgentOnboarding`，见 [agent-runtime/agent-onboarding.md](../agent-runtime/agent-onboarding.md)）不加浮层，空对话本身就是引导：节名是等宽小字（「连接模型」「试试」），下面是侧栏 cell——行首一颗章节砂印（能用的实、不能用的空心，同设置页的服务商连接行）、名字、行尾等宽来源，悬停一圈流动玻璃。没连上的一行就地展开，内容从名字那一列开始：等宽单行输入框加主按钮「连接」，下一行是带斜出箭头的文字按钮「获取 API Key」，出错是危险色的字加砂笔图标；ChatGPT 订阅展开是等宽大字的一次性代码、转动的缺角圆相、主按钮「打开验证页面」与文字按钮「取消」。展开不是选中：展开那一行的玻璃环随指针离开而消失。连上后同一位置换成一行实心印的服务商与等宽模型名，下面「试试」三行请求，行首是它指向的章节或要素的记号，点一行直接发出。第一次有改动的那一轮结束时，「本轮改动」的链接用强调色的等你处理玻璃（`.glass--waiting`），旁边一个文字按钮「版本历史」，作者打开其一后恢复成普通链接。

历史对话弹层与配置菜单（2026-10-29 候选 A）都是菜单外壳，行一律是菜单行：不垫底，指针下的行流出一圈玻璃。历史里当前对话中等字重，带一圈静止的环（和写作状态那组的当前项同一种）；正在跑的对话在名字前留一颗强调色小点；时间是等宽小字；改名与删除是平的砂笔图标，只在指着的行上出现；改名时这一行换成单行输入框。配置菜单的分组之间用留白、不画线，组名是菜单的小标题；切换模型与项目记忆是带当前值与展开箭头的菜单行，扩展思考与允许危险操作是 Switch，推理强度是一块下拉选择的单行输入框（里面是原生 `select`，它的列表是系统的，选的时候不会被当成菜单外的点击而关掉菜单）。模型列表的当前模型也是中等字重加静止的环；记忆列表里「未生效」是条目前的等宽小字，不再是灰底小块，启用与删除是平的砂笔图标，未生效的条目一直显示、其余指着才出现。暂停中的移动端保留原来的行（`AgentComposerConfig` 只在 `glass` 时用菜单行）。

## Review 卡

右栏 Review 的卡片按卡片的定义：不垫底色，只有一圈无色的静止细玻璃线（`.glass--rest`），悬停时流动、按下不加深（`.glass--surface`），取稠密的两块纹理交替；批注、TODO、Copilot 建议的颜色只留在类型字上，玻璃不取颜色。已解决的卡整张变淡。

- **建议的摘要与引文**：去掉底色，退到次一级墨；引文（建议的证据、便笺里被选中的原文）缩进而不加框。
- **TODO 完成**：圆形玻璃按钮（静止细线，悬停流动，按住加深）。完成时是选中的玻璃，里面画出一笔批阅勾（`BrushIcon` 的 `check`，`0.38s` 从左往右画出，和砂笔画框同一个时长；减少动效时直接到位）；改回未完成时勾整笔收回。素材库的 TODO 卡共用这个开关。
- **让 Agent 处理**：悬停卡片时出现在完成按钮旁边的文字按钮，没有底也没有尾巴，悬停只加深字；Agent 处理中时字前面转着加载圈。
- **分组标题**：按位置分组时的标题是文字按钮：记号取实体自己的颜色（章节取主故事线色，要素取类目色，故事线、类目取自身颜色，没有的用中性墨），悬停只加深字，不垫底。「已解决」折叠行用砂笔的展开箭头，不用原生三角。
- **来源卡**：悬停卡片时贴在旁边的悬停卡（和实体的悬停卡同一张，见 [interaction.md](interaction.md)），每个来源是一行标题：实体的砂笔记号加名字，类型字不再出现；「来源」「绑定文本 · 原文摘录」两个小标题去掉了，绑定的原文放在一张稿纸色小片上、用正文字体；没有来源时标题行是淡字的「项目级 · 未关联对象」。下面是这张卡的操作行。
- **在卡里改字**：双击正文，原地换成 Agent 对话框那种稿纸色圆角片（`16px`，`.glass--rest .glass--field`，光标在里面时是静止的选中玻璃）；「取消」是文字按钮，「保存」是主按钮（`.glass--primary`）。

只有桌面加 `.review-card--glass`；暂停中的移动端保留原来的浅底卡片、实心完成圆与旧按钮。

## 正文里的批注、链接与 Agent 改动

正文里作者留下的痕迹都是砂笔，材料与实现见 [materials.md](materials.md) 的「砂笔进正文」。

- **批注锚点**（`CommentAnchorHighlights`，桌面由 `lib/comment-sand.ts` 画）：每处锚点是逐行的一道干笔荧光，垫在字下（叠在字上、像颜料一样混合，字保留自己的颜色），批注用批注色、TODO 用 TODO 黄，Copilot 提议只在指着它的卡时出现。指着 Review 卡、便笺或 TODO 卡时换成同一笔更疏的砂粒、浓度略升，字仍读得清；点卡上的「跳到原文」、点滚动标记或刚在便笺里写下它，算作选中：这道笔沿行重画一遍并保持指着卡时的样子，作者在正文里点一下或打字后退回静止。解决、删除时整块淡出。
- **实体链接**：彩字加一道同色的干笔下划线，悬停加深；点线样式只留颗粒，只悬停显示时指针下淡入。
- **Agent 改动**：Agent 写进来的字是彩色墨字、不垫底色：新增绿、改写紫（`--agent-new-ink`、`--agent-chg-ink`，同色相加深到能在稿纸上读）。
  - **揭示是原地覆盖**（`AgentRevealText` 的 `overwrite`）：每一处改动从它的开头开始，一步一个字：原文比新文长，先像 Backspace 一样原地删、后面的字往左收，删到一样长再逐字覆盖；原文比新文短，先逐字覆盖，覆盖完再逐字插入、把后面的字往后推；只增或只删就一路插入或删除。不留大块空白，也不在中途突然换排版；总步数是每处较长那一边，比先擦后写少。叠层铺稿纸底色：原文更长时它暂时盖住下一段开头几行，删短的过程中那几行露出来，下面的段落始终不动。
  - **写完留色到指针停住**：揭示交给真正的段落后，这些字仍是绿或紫（`::highlight(agent-recent-*)`，`lib/agent-recent-changes.ts` 记、`AgentRecentChangeHighlights` 画），作者的指针在某一处停 `0.2s`，那一处才分两步、`0.3s` 退回墨色；指针扫过不算。颜色留在这次打开的应用里：切走再切回、通览全书都还在；那几个字被改掉，或 Agent 再改这一段，旧的标记就去掉。
  - 审阅模式的就地装饰（代码仍在）用同样的墨色；整段改动的淡绿底已去掉。

暂停中的移动端保留 `::highlight()` 的批注底色、色带与绿底红删除线。

## 批注便笺

贴在编辑器右边的便笺栏（`StickyNoteRail`）在稿纸窄时会压在正文上，所以便笺是浮起的玻璃：稿纸色 80% 的底加 `1.6px` 背景模糊，再加静止细玻璃线，正文在下面只透出一点字影。便笺里的卡片、完成按钮与改字和 Review 卡一致。

- **位置**：编辑器一直伸到窗口顶边，顶上那一行是窗口控件（拖动条、窗口两角的侧栏开关、Dock），右下角是稿纸工具栏；便笺栏从这一行下方开始，到右下角工具栏上方为止，所以它的按钮不会被拖动条或侧栏开关盖住。
- **工具栏**：数量用索引字；「叠放」与「移除全部」是两个圆形玻璃按钮，带浮起的底。「叠放」是一个开关，字永远是「叠放便笺」，叠着时是选中的玻璃。
- **叠起来的便笺**：只露出最上面一张和数量；下面几张只剩错开 `4px`、`8px` 的静止细玻璃线，最上面一张带浮起的底，不画假的白纸层。
- **写一条新批注**：便笺里一张稿纸色圆角片（`.glass--field`）；「取消」是文字按钮，「添加」是主按钮。

## 统计面板

右栏统计（`EntityStatsContent`、`AllChaptersStats`、`MaterialStats`，原语在 `StatsPrimitives`）是平的排字：节标题、键、数量与说明用索引字（等宽，不大写、不拉字距，`--ui-font-caption`），值用实体字（`--ui-font-secondary`），节与节之间只留空，键值行之间不画线；值不再用斜体。

- **名字旁的颜色**：换成该实体的砂笔记号（`KindMark`）：故事线是短横，要素是方印，类目是折角，素材是纸条；幕没有自己的记号，压一枚圆印。
- **跳转行**：能打开所指对象的行用侧栏 cell 的语法：不垫底，悬停时一圈取该对象颜色的流动细玻璃（`.sand-cell > .cell-ring`）；打不开的行（未归线）不变。
- **读数是砂笔**：每个值画成一笔干笔（`.sand-stroke`，见 [materials.md](materials.md)），长度就是值，末端变干；没写到的部分是散砂（`.sand-track`）。几部分合成的整体（分幕节奏、完成度）是一笔接一笔。完成度看砂的多少：完成是墨足的一笔，草稿是干笔，待写是散砂；颜色用墨，不用强调色。分幕取幕的颜色，故事线进度取故事线颜色。章节长度节奏每章一笔短干笔，悬停一笔时其余变淡，下面读出那一章。
- **没有可数的东西时**：一句平的斜体字，退到次一级墨，不垫底。
- **历史快照**：通栏的次按钮（静止细玻璃线）。

这些样式只在桌面渲染（`stats-panel.css` 的类只在桌面出现）；暂停中的移动端保留各原语里原来的内联样式。

## 实体编辑器

稿纸里打开的要素、故事线、类目与章节编辑器按上面几条组合（2026-10-29 定）。只有桌面这样；暂停中的移动端渲染同一批组件，由 `getPlatformRuntime().isMobileShell` 门控，保留原来的样子。

- **页眉（folio）**：和通览全书同一写法——章节写「第 N 章 · 故事线短横 + 墨色名字 · 字数」，构想写「构想 · 分组的砂笔记号 + 墨色分组名 · 字数」，要素、故事线、类目编辑器把所属类目或自己的名字也写成记号加墨色名字（`.page__folio-storyline`）；名字不再用故事线色或强调色的粗字。
- **页头**：故事线与类目的页头不再有渐变色块，标题前是放大的砂笔记号（故事线＝短横，类目＝折角），颜色取自身颜色。色板是一排圆形玻璃按钮，每个里面一颗该色的砂印；选中的是该色的静止选中玻璃，悬停流动。要素的别名是平的字、用 · 隔开，被悬停的那个出一圈侧栏 cell 的细玻璃环和 ×，末尾的输入不装框。标题、摘要与正文是稿纸上的字，保持平的。
- **光标就是焦点**（2026-10-30）：标题、摘要、别名、字段名与值、补丁标题、素材的标题与说明获得焦点时只有光标，不画强调色的环，也不换成别的框或底色。表单控件的强调色环（`index.css` 的 base 层）在桌面上不进编辑器（`.editor-shell`）与玻璃字段（`.glass--field`，它的玻璃本身就是焦点）里的文字输入；下拉、复选、单选与滑块这些有框的控件照旧带环，编辑器以外没有迁移的输入框也照旧。移动端不变。
- **节标题**：稿纸上每一节的标题（`.page__scene-title`：「记 · 传」「字段」「札记」「章节模版」「字段模版」「章节序列」「要素清单」；`.refs-section__title`：「关联」「补丁」，以及右栏统计面板里的「被引用」「引用其他」）是结构字：和 Panel Tab 共用 `interface-fonts.css` 里同一条结构规则（`--font-structure`，正体、常规字重、不拉字距），不再是斜体非衬线；字号仍是节标题的 `16px`，颜色仍是次级墨。
- **一节空着时**：节下面那一句说明（没有字段、没有补丁、此筛选下没有章节或要素、没有可选项、没有被引用、素材上还没有区域批注）在所有结构化编辑器里写法一样：共用 `.ui-section-empty`——索引字（等宽，`interface-fonts.css` 的索引规则）、caption 档字号（`--ui-font-caption`）、居中、正体、不强制大写、常读辅助文字的墨色（`--ui-text-muted`），上下各 `12px`；不加底色和框，也不加砂笔记号（那是整块的「空状态」）。各处原来的类名（`.kv-editor__empty`、`.refs-empty`、`.mgr-empty`、`.refs-picker__empty`、`.material-comments__empty`）只留给暂停中的移动端回退。
- **字段**：`KvEditor`（要素与故事线的「字段」、类目的「字段模版」、作品主页的设定）每行一张静止细玻璃线的输入片（`.glass--rest .glass--field`），不垫底，字段名与值之间不画线；光标在里面时整片是静止的选中玻璃，只读时是 `.glass--still`。删除与「添加字段」是文字按钮。
- **Agent 改字段**：改动行仍在字段列表上方，删除与新增只用颜色和删除线，不垫底；这一行滚进视野、开始演示时被一道玻璃推过一次（`.glass-sweep`）。
- **关联**：一条关联一张卡片（`.glass--rest .glass--surface`），不垫底；种类是对方实体的砂笔记号（颜色取它的故事线或类目），关系类型是一个字加该类型颜色的砂笔短横。没有虚线添加卡，添加从节标题右侧的文字按钮「关联实体」进入。
- **关联选择器**：在节标题下就地展开，不包信封：种类是 `GlassSlider`，搜索是单行输入框（`.ui-field`），候选是侧栏 cell 行（记号、名字、种类）；选中候选后下面一行是关系类型（次按钮）与「创建」（`Button variant="primary"`）。
- **提及行**：右栏统计面板里的「被引用 / 引用其他」保持点线分隔的平行；圆点换成记号（记号的标题说出种类），悬停只加深名字、出斜出箭头，不垫底。
- **补丁**：一条补丁一张卡片（`.glass--rest .glass--surface`），不画分隔线。「失效」是危险色的字加砂笔墨印白「！」，能点开原文快照，快照是只读卡片（`.glass--still`）。Agent 新增、改动或删除的补丁被推波推过一次，标签只是一个强调色（删除为危险色）的字，不垫绿底红底；删除中的标题与正文变淡并划掉。改挂章节的浮层行用菜单行的玻璃环。
- **章节序列与要素清单**：筛选是 `GlassSlider`，每项带等宽的数量。每行是侧栏 cell：不垫底、没有左侧竖条，悬停出故事线或类目颜色的细玻璃环与前进箭头；状态点换成该实体的砂笔记号（章节圆印、要素方印），未起的章节与还没有内容的要素用空心记号。
- **对话框里的选择**：要素「改类目」「移到分组」与漂流「移动到分组」是菜单行（被悬停的行流出玻璃，当前项加粗带一勾），名字输入是单行输入框（`.ui-field`）；漂流「转为章节 / 转为要素」是两列细线卡，玻璃边取各自故事线或类目的颜色，选中是该色的静止玻璃。对话框外壳与底部按钮跟随对话框的统一定义。

守护测试是 `entity-editor-glass.acceptance.test.ts`（见 [acceptance.md](acceptance.md)）。

## 素材页

图片与 PDF 素材的标签页（`MaterialEditorView`）：页头（标题、来源、说明、关联）直接写在桌面上，不垫白条、不画底线；图片或 PDF 那一页是这里唯一抬起的一张（稿纸投影 `--page-elevation`，`2px` 圆角）。来源是一个文字按钮加展开箭头，展开的生成参数是只读细线卡。说明是一个平时看不见边的输入框（`.glass .glass--field`）：悬停时玻璃晕开流动，光标在里面时是静止的选中玻璃。

画框批注、缩小、比例、放大与全屏在舞台右上角合成一条玻璃长药丸（与稿纸工具栏同一个 `.editor-bar`），每个按钮是圆形玻璃，比例是药丸里的一段等宽字；画框批注开着时是选中态，提示写在药丸下方，不再是黑色胶囊。多页 PDF 的翻页是舞台底部单独一条药丸：两枚圆形玻璃箭头夹着「3 / 12」。全屏查看用桌面色幕布（`--paper-deep` 96%），图片仍是抬起的一张，右上角一个圆形玻璃关闭按钮，Esc 或点幕布也关。右栏的批注列表平铺在桌面上，左边一根 hairline；选中的那张卡是静止的选中玻璃。

## 区域批注

画在图片或 PDF 上的框是作者留下的痕迹，用砂笔：每个区域按自己的尺寸画一圈干笔框（`RegionFrame`，与侧栏 cell 的选中画框同一支笔，`lib/sand-frame.ts`），种子由批注 id 决定，所以同一个框每次打开都一样；平时淡（约五成），指着它或指着右栏它的卡片时加深，选中时整圈重新画一遍（`0.38s`，减少动效时直接到位），已解决的淡到三成。颜色跟 Review 一致：批注取 `--comment`，TODO 取 `--story-4`（略加深）。编号是一枚圆砂印（`blob-2`），数字留白，右栏卡片前的编号同一枚印。正在拖出的框先是淡砂的九宫格框，松手后才落成。指着图上的框，右栏那张卡流出玻璃；指着卡片，图上的框加深。画完框后弹出的输入是平面浮层（与菜单同一组 `--menu-surface-*`）：多行输入框（`.ui-field--area`），「批注 | TODO」多选一，取消是文字按钮，保存是主按钮。

## 笔记正文

笔记本身就是抬起的稿纸，稿纸里不再有第二层底色（`MaterialNotePage`，`.note-prose`）：引用缩进、次一级墨；行内代码只换等宽字；表头只加粗；选中的表格单元格用文字选区同一种蓝。提示块与代码块是只读卡片：不垫底，一圈静止的无色细玻璃线，悬停不变。高亮是一道干笔荧光（`sand/hl-mark.png`，深色主题 `hl-mark-dark.png`），跨行时每一行各画一道（`box-decoration-break: clone`）；这是唯一事先上好色的砂笔贴图，因为只有背景能按行片段重画。清单的勾选框是砂笔方框（与 Agent 任务清单同一组图标：空框、框里一勾），没有玻璃；关联了 TODO 的行尾写一个 TODO 色的等宽「TODO」，不垫底。

## 笔记浮条与嵌入素材

光标停在清单行或表格里时浮出的操作条（`NoteFloatingBar`）和正文的选区浮条是同一块玻璃（2026-10-30 定，此前是菜单外壳）：一条横向玻璃长药丸（静止细线、稿纸半透底、不带投影，`160ms` 上移 3px 淡入，portal 到 `body` 并固定定位），每个动作——转为 TODO／不作为 TODO，加一行、加一列、删除行、删除列、表头行、删除表格——是一颗短药丸，平时看不见玻璃，悬停晕开流动，按住加深；长药丸本身按下不加深（`.editor-selection-bar.glass--surface` 与 `.editor-selection-bar__item`，直接复用选区浮条的类）。「已同步为 TODO」是一句次级墨的字，TODO 与表格两组之间空 `8px`、不画竖线；空行上停用的「转为 TODO」变淡、指着也不出玻璃。暂停中的移动端保留原来的纸面浮条。嵌入笔记的图片本身没有框，悬停时出一圈玻璃，整块被选中时是静止的选中玻璃；PDF 是一张不垫底的细线卡（`.glass--rest`），没有缩略图时用素材的竖笔记号；素材已删除只留一行灰字加墨印白「！」。插入素材的选择器里，每一格也是细线卡，「导入文件…」是次按钮。

## 素材库卡片

「TODO 与素材库」全书视图里，素材按种类分组，组头是结构字的种类名（笔记、图片、PDF，和要素画布上的类目图例同一种）加等宽数量；素材卡是砂笔 cell（`LibraryItemCard`）：竖笔记号 + 名字，下面一行等宽的类型、文件夹与尺寸；不垫底，悬停时整圈流动玻璃，当前标签页打开的那张画砂笔框；缩略图不描边不垫灰，PDF 是一小页白纸；展开、在系统中打开是悬停才出现的砂笔图标按钮，没有框。TODO 卡（`TodoCard`）是不垫底的细线卡（`.glass--rest .glass--surface`）：TODO 色的等宽「TODO」、跳到原文的箭头、悬停出现的字纸篓，底部「＋ 关联」是文字按钮，完成钮沿用 Review 的 `TodoStatusToggle`。侧栏素材树里，文件夹名是结构字、素材条目是实体字（文件夹之于素材，就像类目之于要素）；文件夹行也按 cell 处理：悬停出玻璃环，⌘ 多选的行是静止的选中玻璃环，拖到文件夹上时它的环流动，拖到根上时整个列表的边流动；改名是稿纸色的玻璃输入框。文件夹选择器的行不垫底，当前文件夹是静止的选中玻璃并加粗；对话框与选择器里的输入框是共用的单行或多行输入框（`.ui-field`、`.ui-field--area`），主按钮是 `Button variant="primary"`，取消是 `variant="ghost"` 的文字按钮，错误只用危险色的字加砂笔图标。暂停中的移动端保留这些组件原来的样子。

## 通览全书

每一章是只读的静态正文，点进去才换成活的编辑器。编辑区现在是一整片稿纸白（`index.css` 里 editor-shell 把稿纸压平了），所以章与章之间不画线：上一章末尾的 ⁂ 和其后的留白就是分隔。幕的扉页落在两章之间的留白里：结构字体的小字「第二幕」、正文字体的幕名，幕名下面一笔干砂（砂笔下划线那张笔迹；幕的划分是作者留下的结构，所以是砂笔），再下面是等宽字的章数与字数；那一笔随扉页整块淡入，不画出来。还没有章节时，一句话下面是主按钮「新建第一章」和次按钮「回到作品主页」（鸟居）。暂停中的移动端保留章间细线、大罗马数字与原来的描边按钮（`AllChaptersEditorView` 的 `desktopChrome`）。

## 作品主页

作品主页是舞台上没有活动标签时露出来的那一层（`ProjectDashboard`，`dashboard.css`），和编辑器一样是一整片稿纸白，内容列与稿纸同宽（`--editor-max-width`）。2026-10-30 与新建合成一处，「新建…」占位标签已退场；候选在画布上挑定（作者选单栏的扉页，又按两轮意见改成下面的样子）。

- **文档流**：作品（书名与读数、继续写、全书）→ 新建 → Agent；书名右边的多选一（`GlassSlider`）切到「设定」。节标题用结构字体（与实体编辑器的节标题同一条规则），读数用等宽字。
- **书名与读数**：等宽小字「作品主页 · 某年某月起」，书名用稿纸标题的正文字体、就地改名；一行等宽读数（章、故事线、要素、字数 / 全书目标），下面一笔砂笔读数是全书进度，旁边是今日字数、日目标与连续天数。
- **继续写**：上次打开的那一章（或构想）是一个砂笔 cell：记号、名字、故事线短横与名字、多久以前、字数，下面两行梗概；再下面最多三个最近打开的章节与要素。节头右边是文字按钮「通览全书」（星号记号）。没有章节时是空状态。
- **全书**：每条故事线一行砂笔 cell：短横、名字（故事线与下面的类目在这里组织全书，名字用结构字，和侧栏一样；「继续写」里的章节与要素仍是实体字）、一笔取故事线颜色的砂笔读数（已完成 / 章数）、等宽读数；下面是类目 cell（折角记号、名字、要素数）。节头右边是进叙事图与要素总览的文字按钮。原来的状态筛选、完成度圆环、强调色按钮与英文副标题都不要了。
- **新建**：节头「新建」，右边是等宽的快捷键。六块大一号的砂笔 cell（章节、构想、要素、故事线、类目、素材），放大的记号在上、名字在下。不写名字，也没有确认：指针停在有次级选项的那一块上（或用键盘把焦点移过去），它正上方竖着排出一列小药丸（`glass--small` 的短药丸，一样宽、与那一块居中对齐，太长时这一列自己滚动；故事线与类目的取各自颜色）——章节是「未归属」与各条故事线，构想是「根层」与各分组，要素是各类目（没有类目时是一颗强调色的「先建一个类目」），素材是文本 / 图片… / PDF…——点一颗就建；故事线、类目，以及书里还没有故事线时的章节、没有分组时的构想，点那一块直接建。小药丸与那一块之间留一段桥，指针离开 `160ms` 后才收起；点一下那一块也能把小药丸钉住。没建成时下面一句危险色的字加墨印白「！」。
- **Agent**：节头是式神图标、「Agent」、签到状态（上次签到时间、签到中的转圈、已关闭）、文字按钮「现在签到」与「Project Memory」（切到设定页并滚到那一节）。签到卡片在对话框上面：细线卡（`.glass--rest .glass--surface`），点卡交给 Agent，右上 × 忽略。对话框是多行输入框那张圆角片，右下是圆形主按钮发送（`⌘↵`）。
- **设定**：写作计划（两个等宽数字框，各带一笔砂笔读数）、作品简介（多行输入框）、作品设定字段与故事线模板（字段输入片，见「实体编辑器」）、每日签到（Switch）、Project Memory。
- **浮着的那一份**：每次来到主页都从顶上开始，并让一节浮在页面下沿（离底 `26px`）：从 Dock 的 `+` 或 `⌘N` 来浮新建，从鸟居、`⌘1` 或关掉最后一个标签来浮 Agent。浮着的是另一套更精简的样子，没有外框、没有标题与说明，只有能按的东西，每件各自垫一层浮起的底加静止细玻璃线（稿纸工具栏那一种，不带投影）：新建是一排只放记号的圆形玻璃（`46px`，比工作区级圆形玻璃大一号），名字只在悬停时淡淡出现在圆下（字后垫一圈稿纸色，压在正文上也读得清），次级选项同样在那个圆正上方竖着排出；Agent 是一行一张的短药丸（记号、它指的东西、一句话、×）加对话框（保持稿纸色不透明，打字时底下的字不透上来）。浮着时文档流里那一节是透明的、位置照占；滚到那一节整节进入视线（它的底边到了浮层的高度），浮着的淡出、那一节淡入（`0.24s`），之后往回滚也不再浮，直到下一次来到主页。一进来就整节看得见的那一节不浮。从 `+` 来时焦点落在上回用的那一种上，但这一下落下的焦点是安静的：不弹次级选项、不出名字，直到作者按键挪动它、指针进到这一排或焦点离开（2026-10-30 改：原来焦点一落下就弹，作者没悬停也展开、移开也不收）；在次级选项里按 Esc 回到那一块时同样安静。浮着时焦点在里面的话，落回时跟进文档流里的那一份。
- **建好之后**：新东西作为固定标签加在 Dock 末尾并打开它的编辑器；章节与构想的标题已选中，直接打字改名。建的过程中离开了主页，就作为标签加在后台、不抢焦点。图片与 PDF 先走素材的新建对话框（种类已选好）。

## 要素全景

要素全景（`DesktopSuperElementView`）在桌面上是一片**类目群岛**（2026-10-30 定，原型「要素全景原型」的 A 案）：位置固定，没有章节带。

- **类目**是一座岛：类目颜色的一片淡色，只比类目框大一点，四边羽化，相邻的岛之间留着清水，不叠在一起；没有框、没有投影、不铺玻璃纹理。岛名在岛内的上岸，是类目的砂笔折角、结构字的名字与等宽的要素数，挪过的岛后面写等宽的「已固定」。排布仍由求解器决定（上下两排之间留一格海），作者拖岛名把岛挪到别处，岛就固定在那里（`layoutMode: 'pinned'`），其余的绕着它排；岛的悬停卡有「恢复自动排布」与「在这里新建要素」。
- **要素**是侧栏 cell（`SandCell`）：方印加名字。**远近**三档（头部的多选一：远 `0.5`、中 `0.9`、近 `1.5`）：远看只剩方印，大小按在正文里被提及的次数（平方根），岛名放大，像一张星图；中距离出名字；近看是卡片，带摘要。从没在正文里出现的要素，方印和名字都淡一档。
- **线**有两种。正文里两个要素在同一章的同一段里都被提到，就连一条**砂线**（画在岛下面的画布上，越常同段越浓越宽）。它的开关在关系菜单（「全部」）的第一节「自动连线」：「正文同段」Chip 开关它，旁边的多选一定至少几段才画（默认 ≥2），下面一行写着它画的是什么。作者手建的**关系**仍是关系类型颜色的平细线（`1.5px`，选中 `2.2px`），画在砂线上面，不画箭头：方向写在详情卡里（「师徒 ←」是指向它的）。
- **聚焦**：点一个要素，它和它的邻居（有线相连的）亮着，其余淡到两成，别的关系线退后；再点或 Esc 取消。右上角浮出**浮岛**的小卡，排法和悬停卡一样：头部是方印与名字、右边提及次数，下面一行类目，再下是摘要；**出场**一节是一章一笔砂，按书序排，颜色取那一章的故事线，浓淡随提及次数，下面一行写出场几章、首次、末次与最长空档；**常同段**与**关系**各一节，是悬停卡的行（行首记号，次数靠右），点一下聚焦到那一个；最后一节是「只看它」（只留它和邻居）、「在标签页中打开」与「编辑」三行，没有主按钮，也没有关闭叉（再点一次那个要素或 Esc 关掉）。点岛名也不再离开全景：小卡换成这个类目，头部右边是要素数，下面列出它的要素（提及最多的在前，点一下聚焦那一个）。
- **浮岛**（2026-10-30 定，原型「要素全景原型」第三排的 B 案，`SuperElementIsland`）：小卡就是悬停卡那一张卡（`248px`、`16px` 圆角、静止细玻璃边，2026-10-31 起）。点「编辑」，小卡沿右边长成上下打通的浮岛：四周离画布留 `12px`、圆角 `14px`、浮起比菜单多一档，桌面色里放一张稿纸，不铺玻璃；长出与收回走结构性开合的 `420ms`。稿纸上就是主工作区的要素或类目编辑器本身（`ElementEditorView`／`CategoryEditorView` 按 id 挂载），内容、结构与逻辑完全相同，同一份 Yjs 文档：后面的标签页开着同一个要素时两边一起变；在浮岛里编辑不会把当前的预览标签变成固定标签（`TabPromotionSuppressedContext`）。编辑器上面一条是全景自己的信息——要素是出场刻度、出场摘要与常同段，类目是它的要素——可以收起。浮岛的左边可以拖，宽度在画布的 15% 到 75% 之间（默认 38%），记在本机；拖动时这条边按移动的距离流出玻璃，和拖宽侧栏一样。浮岛窄于 `360px` 时，头部只留名字、「收成小卡」与关闭（「在标签页中打开」在小卡上）。浮岛里的编辑器默认收起大纲（窄稿纸上它会压住页眉和标题）；稿纸工具栏的大纲按钮只在这座浮岛里展开它，不改工作区的设置（`EditorRailPresentationContext` 的 `onOutlineToggle`）。浮岛开着时点别的要素或岛名，浮岛直接换成那一个；它被浮岛挡住或在屏外时，画布把它挪到浮岛左边的中间。Esc 先把浮岛收回小卡，再按一次关掉；「在标签页中打开」离开全景、在工作区打开它。浮岛里的滚轮、按下与选字都归编辑器，不拖动画布。

- **头部**：找要素、远近、关系类型（「全部」菜单，第一节是正文同段）、重置；连线模式下头部写一句「从 · 起点的记号与名字 · 连到…」。新建关联、关联详情与卡片弹层和故事图谱共用同一套（见上面「故事图谱」「卡片弹层」）。
