# Drifting 设计系统

一张稿纸，两种材料。主工作区是一张平的桌面，上面只抬起一张稿纸；桌面上的一切要么是**玻璃**（手按的东西），要么是**砂笔**（作者留下的痕迹），其余一律是平的。

这套语言在 2026-10-27 至 10-29 之间成形：先在候选画布上逐项定稿，再迁进桌面端（Tauri）。移动端暂停，尚未采用；见文末「范围」。

## 原则

1. **一张抬起的稿纸。** 左右栏、Bottom Timeline、稿纸角上的按钮和顶边的标签都在同一张平面上，只有稿纸是抬起来的一级工作面。浮层（菜单、悬停卡）是唯一另外掀起来的东西。
2. **手按的是玻璃，留下的是砂笔，其余是平的。** 不引入第三种材料，不做纸纹，不做立体：没有高光、凹槽、上下不对称的边，按下也不靠投影。
3. **状态靠材料变化，不靠换字。** 静止、悬停、选中、按住是同一块玻璃的不同浓淡；开关是一个永远不变的词，开没开看玻璃。
4. **会动的东西有重量。** 拖动跟手但略落后、不回弹；被推开的面板像一大块冰，先慢后快；选中从旧项流到新项，而不是瞬移。
5. **痕迹要画出来。** 砂笔出现或消失都有过渡，不允许一帧切换；只有作者主动的操作才“画”，其余状态整块淡入。
6. **操作在东西旁边。** 没有自绘的右键菜单；一个东西能做的事放在它的悬停卡底部、它所在的面板头部或稿纸角上。
7. **减少动效时一律直接到位。** 所有流动、推进、水波与画框在 `prefers-reduced-motion: reduce` 下跳过过程。

## 完成度与缺口

已成体系的部分：

- 玻璃的五种状态（隐藏、静止细线、悬停流动、选中静止、按住加深）与它们之间的过渡；一个共享的 `.glass` 实现覆盖所有玻璃控件。
- 玻璃的三种运动：随距离流动（面板移动时的线、移动中的方块）、悬停时缓慢流动、同族选中的水波。
- 砂笔的五种用途：实体记号（`KindMark`）、选中时画出的框（`SandFrame`）、按钮和菜单里的图标（`BrushIcon`）、统计面板的读数（`.sand-stroke`）、书架封面上故事线的流带（`lib/sand-cover.ts`）。
- 动效词汇：结构性开合、重冰推进、有重量的弹簧、水波、玻璃流动、砂笔画出，各有固定的时长与曲线，定义在一个共享模块（`lib/motion.ts` 与同值的 `--motion-*` CSS 自定义属性，见 [motion.md](motion.md)）。
- 小块玻璃的纹理取样：矮的控件（`.glass--small`，圆形玻璃同样）固定取稠密的那块，大块玻璃留在轮换上（见 [materials.md](materials.md) 的「纹理取样」）。
- 深色主题逐项复核过（2026-10-29）：第一批全部表面，加上 Panel Tab 方块、筛选滑块、Header 外框流动、Dock 药丸与 Agent 面板。由此改了三处：浮起投影改用 `--shadow-ink`（深色是黑，不再是近白的墨色，见 [surfaces.md](surfaces.md)），有颜色的内晕在深色下往白里提 45%，开关轨道改取稠密纹理（见 [materials.md](materials.md)）。第二批的 Super View、设置页与书架由各自的迁移复核。
- 交互约定：悬停卡承接所有对象操作，没有自绘右键菜单，在空白处双击新建。
- 控件层：主按钮、次按钮与文字按钮、多行输入框、卡片、等你处理的卡片与刚到的步骤（推波），先在 Agent 面板里定下并实现；无色玻璃统一为浅灰。2026-10-29 补上对话框外壳、危险操作的按钮、单行输入框、下拉选择、整行开关、空状态、加载与进度，并把全局搜索、查找条、通知中心、账户菜单与各对话框迁了过去；共用的 `Button` 在桌面就是玻璃按钮。右栏的 Review 卡、稿纸边上的批注便笺与统计面板也已按这一层做；Agent 面板的工作记忆、历史对话与配置菜单也已换上（不再垫底色）；书架与登录对话框同日迁移，危险按钮改为危险色的静止细玻璃线。

尚未补齐的部分（按影响排序）：

1. **砂笔还没进正文。** 批注高亮、干笔下划线、故事线色带都在设计意图里，但编辑器里的批注高亮仍是平涂底色（`::highlight()` 只认背景色与文字装饰）。砂笔已经用在记号、画框、图标与统计读数上，素材笔记里的 `<mark>` 高亮与图片上的区域批注也是砂笔（见 [components.md](components.md)），正文编辑器还不是。
2. **控件层还没进设置页与其余视图。** 控件的定义都在 [components.md](components.md)；设置页仍用自己的 `.set-btn`、`.set-input`、原生下拉与描边卡片，Super View 仍有描边输入框与描边卡片，各自迁移时换成这里的定义（共用的 `Button` 已经跟着换了；实体编辑器、Review、批注便笺、统计面板、素材、书架与登录已经换上，见 [components.md](components.md) 的对应各节）。作品主页（Project Home）先整体重排结构，再按本设计系统重做。
3. **Chip（第二层控件）未定。** 状态 chip、标签类小件还没有归入玻璃或平面。
4. **移动端未采用。** `docs/design/mobile-v2/` 是砂笔与素玻璃之前的移动端提案，只作历史快照。
