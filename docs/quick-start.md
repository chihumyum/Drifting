# Drifting quick start

1. **Install.** Download the `.dmg` from
   [GitHub Releases](https://github.com/chihumyum/Drifting/releases/latest)
   (macOS 13+, Apple Silicon) and drag Drifting into Applications.
2. **First launch.** Choose **Continue locally** to write without an account,
   or **Sign in / sign up and sync** to create an account. The bookshelf opens
   with a sample project; explore it or delete it.
3. **Write.** Create a project, add a chapter or an idea, and start writing.
   Headings inside a chapter become scenes, beats and notes in the outline;
   acts are set on the timeline. Everything is saved on your Mac as you type.
4. **Plan.** Add elements and categories, connect them with relations, and
   arrange chapters on storylines and the timeline. Project Home shows your
   progress and lets you create anything from one place.
5. **Add the Agent (optional).** In **Settings → Models & API**, add a DeepSeek,
   Anthropic or OpenAI key, or sign in with a ChatGPT subscription. The Agent's
   edits land in your project, marked in the text; undo them from history.
6. **Keep copies.** Each project has a Markdown folder (Settings → Sync & Data
   shows where); chapters and ideas you edit there merge back. For a restorable
   copy of everything, export a `.drifting` library backup from the same page.
7. **Sync (optional).** With an account, **Settings → Account** connects sync,
   pauses or disconnects it. Let sync finish before switching to another Mac.
8. **Updates.** When a new version is out, a notice appears in the
   notification center; install it from **Settings → Updates** when you choose.
