# Drifting 0.1.0-alpha.1

First public desktop Alpha candidate for macOS 13+ on Apple Silicon.

Highlights:

- local-first writing without a Drifting account;
- optional Google Drive synchronization through the author's account;
- readable Relational Markdown export;
- isolated SQLite migration with an internal native safety snapshot;
- signed, user-confirmed Alpha updates;
- Experimental BYOK Copilot and General Agent.

Trust boundaries:

- Google Drive content is not end-to-end encrypted against Google;
- AI requests, cost, retention, training terms, and output risk follow the
  selected model provider.

This file supplies candidate release notes. Publishing remains prohibited until
the exact tagged SHA and downloaded artifacts satisfy
[the release contract](../alpha-release-contract.md), both desktop acceptance
records, and the public-page checks.
