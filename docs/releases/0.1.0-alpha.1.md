# Drifting 0.1.0-alpha.1

第一个公开测试版，支持 Apple Silicon 上的 macOS 13 及以上。

- 本地优先的长篇写作工作台：正文、构想、人物与世界设定、故事线和素材放在同一个项目里。
- 不注册也能用；注册后可以在多台 Mac 之间同步，并用链接分享章节给别人读和评论。
- Agent 可以读、搜索和修改你的项目，改动会在正文里标出，可以从历史快照撤回。
- 新版本会在 App 内提示，由你决定何时安装。

这是早期版本，请另外保留重要稿件的副本。

The first public preview, for macOS 13+ on Apple Silicon. Keep independent copies of important manuscripts.
