# Drifting 0.1.0-alpha.10

- 外部 Agent（Codex、Claude Code 等）每个只需连接一次，在书架或书里的设置中都能连，打开哪本书它就在哪本书里工作。重新连接会撤销旧版本按书建立的连接，并从客户端配置里删掉那些条目。
- 修复登录账号后一键连接外部 Agent 总是失败、提示路径太长的问题。
- Agent 新建要素后，没打开的章节、构想和其他要素里出现的名字也会链接到它。打开章节时会补上还没链接的名字，Agent 写进正文的名字直接带链接。
- Markdown 文件夹不再有默认位置，选好文件夹之前不写任何文件。升级后会再问一次放在哪里；之前已经写在默认位置的设备保持原样。
- 开着 Drifting 时每 3 小时检查一次更新。发现新版本后铃铛上会留一个记号，直到你打开通知中心；在 设置 › 更新 里点一次“安装并重启”即可。书架上也有铃铛了。
- 书架的设置里也能改外观、编辑器、语言、模型与 API、快捷键、外部 Agent 访问和主动建议。设置里不再把 Agent 标为实验性。
- 设置 › 编辑器 新增“打字时自动沉浸”：开始写正文就收起侧栏与工具，按 Esc 或点正文以外的地方回来。默认关闭。
- 用 Anthropic API Key 时，Agent 也可以联网搜索。
- 导出成稿时 H1、H2、H3 一律导出，不再有按层级取舍的开关。
- 导入 Markdown 或 Word 文件时，开头的标题只作为标题，不再在正文里重复一遍；没有标题的文件以文件名命名。
- 新建的书库里，除了《傲慢与偏见》，还有一本写到一半的《阿Q正传》示例。
- 修复 Agent 引用标题带空格的章节时，链接显示成一串原始文字的问题。
- 要素的一句话摘要统一叫“概述”。

这是早期版本，重要的稿件请另外保留副本。

- Each external Agent (Codex, Claude Code and others) connects once, from the bookshelf's settings or a book's, and works in whichever book is open. Reconnecting revokes the per-book connections an earlier version made and removes their entries from the client's configuration.
- One-click connections for external Agents no longer fail with a path-too-long error after you sign in.
- When the Agent creates an element, its name links in chapters, ideas and other elements you don't have open, too. Opening a chapter links names it hasn't linked yet, and names the Agent writes into the prose arrive linked.
- The Markdown folder has no default location: nothing is written until you choose a folder. After updating you are asked once more where it goes; a device already writing to the default location keeps it.
- While Drifting is open it checks for updates every 3 hours. A found update leaves a mark on the bell until you open the notification center, and one click on "Install and restart" in Settings › Updates does the rest. The bookshelf has the bell too.
- The bookshelf's settings also offer appearance, editor, language, models and API, shortcuts, external agent access and proactive suggestions. The settings no longer call the Agent experimental.
- Settings › Editor adds "Immersive writing as you type": writing in the paper tucks away the sidebars and tools, and Esc or a click outside the text brings them back. It is off by default.
- The Agent can search the web on an Anthropic API key, too.
- Manuscript export always includes H1, H2 and H3; the switches for leaving a level out are gone.
- When you import a Markdown or Word file, its opening heading becomes the title and no longer repeats in the text; a file without one is named after the file.
- A new library gets a second sample beside Pride and Prejudice: 阿Q正传 (The True Story of Ah Q), in Chinese and half written.
- A passage the Agent cites from a chapter whose title has a space links properly instead of showing as raw text.
- An element's one-sentence summary is called a summary everywhere, not a role.

This is an early release. Keep independent copies of important manuscripts.
