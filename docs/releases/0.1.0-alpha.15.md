# Drifting 0.1.0-alpha.15

- Windows：Codex、Claude Code 等外部 Agent 连上 Drifting 后，只要 5 秒没有动静就会断开，Agent 那边显示「Transport closed」。现在连接会一直保持，直到 Agent 或 Drifting 关闭。更新后重开一次 Agent 即可。macOS 不受影响。
- 同步请求现在复用已有的连接，不再每次重新建立，同步更快，网络不稳时也更不容易失败。

这是早期版本，重要的稿件请另外保留副本。

- Windows: external Agents such as Codex and Claude Code lost their connection to Drifting after five quiet seconds and reported "Transport closed". The connection now stays open until the Agent or Drifting closes it. Restart the Agent once after updating. macOS was not affected.
- Sync requests now reuse open connections instead of setting up a new one each time, so sync is quicker and fails less often on unreliable networks.

This is an early release. Keep independent copies of important manuscripts.
