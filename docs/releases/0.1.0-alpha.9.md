# Drifting 0.1.0-alpha.9

- Windows 预览版：提供 Windows 10、11 的 x64 与 ARM64 安装包。窗口按钮收在左上角的玻璃药丸里；在书架上关掉窗口，Drifting 会留在通知区域；外部 Agent 和 MCP 服务与 Mac 上一样可用。安装包暂未做代码签名，第一次运行时 Windows 可能提示“Windows 已保护你的电脑”（点“更多信息”→“仍要运行”）。
- 项目主页的主动建议都变成卡片，点了才做，点 × 忽略：Agent 留下的问题和提议、整理项目记忆的提议，以及把你上次写的新正文整理进要素的“整理”卡。回到 App 时不再自动整理。这些统一由主页设定里的“主动建议”开关控制。
- 修复主页建议有时生成失败、提示 “The check-in result is invalid” 的问题。
- 用 OpenAI API Key 或 ChatGPT 订阅时，Agent 可以联网搜索。
- OpenAI、Anthropic、DeepSeek 的模型菜单会列出你的 Key 能用的模型，新模型不用等更新就能选，列表自动刷新。没有 Key 或没登录 ChatGPT 时，那一家的模型会置灰。DeepSeek 模型按 DeepSeek 公布的上下文长度和输出上限使用。
- 中文正文里也能用 **粗体**、*斜体* 和 ~~删除线~~。
- Agent 新建要素时，正文里已经出现的名字会链接到它。被拆成两个链接的名字会合回一个；打开章节时，只链接了一部分的名字会被补全。
- 正文里链接的卡片能放下更长的内容。
- Agent 回答时，对话会一直跟到最新内容，除非你往上滚；回答里的中文粗体也能正确显示。
- Markdown 文件夹里的素材改放在“素材/”下，你自己放进原来“资料/”里的文件不会动。中文界面里素材的文件夹改叫“素材夹”。
- 清空含有章节的废纸篓会真正删掉它们，删除失败时会说明原因。删除章节都在废纸篓里的故事线、恢复所在分组已不存在的构想，不再失败。
- 登录或退出后，重新打开的窗口会出现在最前面。

这是早期版本，重要的稿件请另外保留副本。

- Windows preview: installers for Windows 10 and 11 on x64 and ARM64. The window buttons sit in a glass pill at the top left, closing the window on the bookshelf keeps Drifting in the notification area, and external Agents and MCP servers work as they do on the Mac. The installers are not code-signed yet, so Windows may say "Windows protected your PC" the first time (More info → Run anyway).
- Project Home's proactive suggestions are all cards that act only when you open them, and × skips them: the Agent's questions and offers, an offer to tidy the project's memory, and an Organize card that files what you last wrote into your elements. Drifting no longer organizes on its own when you come back to it. One Proactive suggestions switch in Home's settings covers them all.
- Home's suggestions no longer fail now and then with "The check-in result is invalid".
- The Agent can search the web when it runs on an OpenAI API key or a ChatGPT subscription.
- The model menus for OpenAI, Anthropic and DeepSeek keys list the models your key can use, so new models show up without waiting for an update, and the lists refresh on their own. Without a key, or without a ChatGPT sign-in, that provider's models are greyed out. DeepSeek models use the context length and output limit DeepSeek publishes.
- **Bold**, *italic* and ~~strikethrough~~ work inside Chinese prose.
- When the Agent creates an element, names already in your prose link to it. A name split across two links becomes one link again, and opening a chapter mends names left partly linked.
- A link's card in the prose holds long content.
- The Agent's answer keeps following as it writes unless you scroll up, and bold Chinese in its answers displays correctly.
- In the Markdown folder, materials now live under 素材/; files you put in the old 资料/ folder stay where they are. In Chinese, material folders are now called 素材夹.
- Emptying a Trash that holds chapters deletes them, and a delete that fails says why. Deleting a storyline whose chapters are in the Trash, and restoring an idea whose group is gone, no longer fail.
- After you sign in or out, the reopened window comes to the front.

This is an early release. Keep independent copies of important manuscripts.
