# Drifting 0.1.0-alpha.13

- 修复 Windows 上的粘贴：在 Drifting 里复制的文字再粘贴时，不再被单独分成一段、上下各多出两个换行。以前已经粘进稿子里的多余换行不会自动消失，需要手动删掉。
- 导入章节时可以不归入故事线：项目里还没有故事线时，章节会导入为「未归属」，之后随时可以归入故事线；已有故事线时也可以选「未归属」。
- 提交反馈时需要填写联系邮箱，这样我们才能回复你；登录后会自动填上账号邮箱。故障后的补充说明仍然可以不填。
- 去掉了 App 自带的语音输入：Agent 输入框的麦克风按钮和设置里的「语音转写」Key 都不再有。需要语音输入时，请用系统听写或其他语音输入工具。已经存进系统钥匙串的 Key 不会被读取，也不会被删除。
- 一个处理网址的依赖升级到修复了已知安全漏洞的版本。

这是早期版本，重要的稿件请另外保留副本。

- Fixed pasting on Windows: text copied in Drifting and pasted back no longer lands in a paragraph of its own with two extra line breaks above and below it. Extra line breaks that earlier versions already pasted into a manuscript stay there and have to be deleted by hand.
- Chapters can be imported without a storyline: in a project that has no storyline yet they come in as Unaffiliated and can be assigned to one at any time, and Unaffiliated can also be chosen when storylines exist.
- Sending feedback now needs a reply-to email address, so that we can answer you; when you are signed in, your account's address is filled in. A follow-up note after a crash can still be sent without one.
- In-app voice input is gone: the microphone button in the Agent's input box and the speech transcription key in Settings are no longer there. For voice input, use your system's dictation or another voice input tool. A key already stored in the system keychain is neither read nor deleted.
- A dependency that parses URLs moves to a version that fixes a known security vulnerability.

This is an early release. Keep independent copies of important manuscripts.
