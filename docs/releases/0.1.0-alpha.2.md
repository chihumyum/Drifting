# Drifting 0.1.0-alpha.2

- 打开的书在稿纸左下角显示同步状态：传得久时会浮出一朵砂笔云，需要你处理的同步问题放进通知铃铛。
- 带图片的书现在能正常完成同步。
- 断开同步只等这台 Mac 上的改动传完，会显示还剩多少，也可以不等直接断开；登出或暂停同步后也能断开。
- 登录了另一个账号时，提示里可以直接去断开同步。

这是早期版本，请另外保留重要稿件的副本。

Sync status now shows in the paper's corner, books with images finish syncing, and disconnecting waits only for this Mac's changes. Keep independent copies of important manuscripts.
