# Drifting 0.1.0-alpha.6

- While a library restores its books from the cloud, the shelf and Account settings show the progress, so a new account library no longer looks empty until everything arrives.
- Pressing Connect while a restore is running no longer starts it a second time.
- Account settings now says when a library is not syncing yet, and that connecting uploads only books made in this library.
- The Dock icon is clearer: the rings around the iceberg are gone and the iceberg is denser.

This is an early release. Keep independent copies of important manuscripts.
