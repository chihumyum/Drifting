# Drifting 0.1.0-alpha.5

- Each account now has its own library on this Mac. Signing in opens that account's books, and signing out returns to the books you keep without an account; books no longer move between accounts on their own. Drifting restarts when it switches. Your current books stay where they are: if this Mac syncs with an account, they become that account's library.
- Export a book as a `.driftingbook` file and import it into another library as a new book.
- Your settings follow your account across devices.
- Long Agent writing keeps going when a view stops with an error, no longer says it cannot reach its tools at a checkpoint, and is not paused while it is still saving chapters. Stop always clears a task that has already ended.
- The Elements overview and TODO & Materials show correctly again.
- When the page is narrow, the outline folds into dots; hover to read it.
- A book deleted on another device no longer leaves sync showing "Error".
- The app icon follows the light, dark, clear and tinted appearances.

This is an early release. Keep independent copies of important manuscripts.
