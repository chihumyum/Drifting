# Drifting 0.1.0-alpha.14

- 修复同步失败：同步现在跟随系统的代理设置（macOS 的网络设置、Windows 的 Internet 选项）。以前同步不看系统代理、直接连服务器，直连线路不稳时稿纸左下角会显示「云同步失败」（错误代码 provider-unavailable），而登录照常。开关代理后不用重启 App，下一次同步就生效。
- Agent 连接 OpenAI、ChatGPT 和读取模型列表时也跟随系统代理；这部分在 App 启动时读取一次，改了代理设置后需要重启 App。
- 深色主题的正文配色：要素、故事线和类目的正文不再发暗；章节里的标题、加粗、引用和行内代码不再接近黑色。正文的白色调柔和了一些，标题和加粗保持最亮。浅色主题没有变化。

这是早期版本，重要的稿件请另外保留副本。

- Fixed sync failures: sync now follows the system's proxy settings (the macOS network settings, the Windows internet options). Earlier versions ignored the system proxy and connected to the server directly, so where the direct route was unreliable the sync corner of the paper showed "Cloud sync failed" (error code provider-unavailable) while sign-in kept working. Turning a proxy on or off takes effect at the next sync, without relaunching the app.
- The Agent's requests to OpenAI and ChatGPT, and its model lists, follow the system proxy as well; these read the settings once when the app starts, so relaunch the app after changing them.
- Prose colours in the dark theme: the body text of elements, storylines and categories is no longer dim, and headings, bold text, quotes and inline code in chapters are no longer close to black. Body text is a little softer than before; headings and bold text stay at full brightness. The light theme is unchanged.

This is an early release. Keep independent copies of important manuscripts.
