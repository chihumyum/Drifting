# Drifting 0.1.0-alpha.11

- 外部 Agent（Codex、Claude Code 等）的连接不再分只读、可写、可删三档，每个连接都能使用全部能力。帮手删除或替换内容前也不再询问，“允许危险操作”开关已移除；需要找回时，用条目的历史快照。
- 同时连了好几个 MCP 服务器时，帮手能找到每个服务器提供的工具。
- 修复同步时偶尔因为本机正在写入而中断的问题。本机某次写入失败时会自动重试，诊断报告也会写明是哪一步失败。
- Windows 上开启较高的显示缩放时，窗口打开就完整落在屏幕里，底部不再被任务栏挡住。
- 故事图的拖动、平移和悬停更顺手。
- 在 Super View 的画布上按 Esc 能关掉悬停卡。
- 输入 / 或 @ 时，菜单刷新的一瞬间按下回车，不会再执行另一行的命令。
- 设置 › 编辑器 里的打字行位置，打字机模式关着时也能调（沉浸写作会用到它）。
- 内置的 SQLite 升级到修复了已知安全漏洞的版本，其他依赖里的已知漏洞也一并清除。
- 为以后的新版本做准备：每次打开和退出时整理好正文，以后升级时书能原样带过去。

这是早期版本，重要的稿件请另外保留副本。

- External Agent connections (Codex, Claude Code and others) are no longer read-only, writing or destructive: every connection can use everything. The Agent no longer asks before deleting or replacing content, and the "Allow dangerous operations" switch is gone; to get something back, use the entry's snapshot history.
- With several MCP servers connected, the Agent finds the tools each of them offers.
- Sync no longer stops now and then because the Mac or PC was writing at the same moment. A local write that fails once is retried, and diagnostic reports say which step failed.
- On Windows with high display scaling, the window opens fully on screen instead of running under the taskbar.
- Dragging, panning and hovering in the Story Graph feel steadier.
- Escape closes a hover card on a Super View canvas.
- Pressing Return just as the / or @ menu refreshes no longer runs a different row's command.
- The typing line position in Settings › Editor stays adjustable with typewriter mode off; immersive writing uses it.
- The bundled SQLite moves to a version that fixes a known security vulnerability, and the other known dependency vulnerabilities are cleared as well.
- Getting ready for a later version: each launch and quit tidies the prose so books carry over exactly when you upgrade.

This is an early release. Keep independent copies of important manuscripts.
