# 启动占位

`index.html` 在 `#root` 内直接提供居中的转圈和内联样式，不等 React、应用模块或平台
信息初始化。无百分比、无最短显示时长；React 首次提交自然替换占位节点。

独立的 `public/startup.js` 是无依赖的普通脚本，读取已保存的主题和界面语言，让加载状态
尽早匹配外观。它不写入设置，存储不可用或损坏时沿用应用的浅色/中文默认值；系统主题
和减少动态效果均受支持。脚本和样式符合现有 CSP，无需放宽 `script-src`。

```bash
node scripts/run-renderer-startup-placeholder.mjs
node scripts/run-renderer-startup-placeholder.mjs --check
```

`acceptance/startup-placeholder.json` 由隔离浏览器生成。开发和生产构建分别阻断启动脚本
及主入口，验证无 JS 时已有加载占位、保存/系统主题、语言、异常存储与减少动态效果。
释放主入口后，再延迟平台初始化前的步骤，确认占位仍存在；随后通过真实 `main.tsx`
的 React 挂载替换占位。App 内容使用合成组件，不读取作者数据库或账号。
挂载后还验证共用的局部加载组件能显示转圈、遵守减少动态效果，并在合成内容就绪后消失。

## 页面检查

实际应用只有 `index.html` / `main.tsx` 一个 React 根入口；`scripts/` 中的 HTML 是隔离
验收夹具，不是应用页面。根入口之外，以下等待状态已补齐：

- 公开登录入口的会话检查使用与受保护入口相同的本地化转圈。
- 桌面书架与移动书架两种布局在读取项目列表时显示局部转圈。
- 编辑器首次等待可展示的内容时，原空白遮罩显示转圈；节点正文读取和编辑器初始化
  同样提供反馈。已有标签切换仍保留前一完整页面，错误仍显示恢复提示。
- 故事图谱、元素图谱和素材/备忘录延迟模块加载时，保留返回导航并显示局部转圈；
  失败后仍提供重试。
- 未匹配的地址重定向到书架，避免空路由；项目入口浏览器证据验证这一行为。

`/project/:projectId/new` 的空路由元素由桌面工作区的创建面板负责展示，保留原有归属。
空书架、未选实体、关闭的弹窗和仅负责副作用的组件不属于等待状态。
上述页面归属经过代码检查；启动浏览器报告验证真实根入口及共用局部组件，
不将合成组件验收表述为完整页面或原生交互验收。

该证据覆盖 HTML 返回后至 React 首次提交；原生窗口创建至 HTML 返回前的时间和完整
应用启动速度不在测量范围。截图仅保存在本机 `.qa/startup-placeholder/`。

## 开发模式冷启动

`src/styles/index.css` 使用 `source(none)` 关闭 Tailwind 的全仓库自动源发现，
保留 `tailwind.config.js` 中的 `index.html` 和 `src/**/*.{js,ts,jsx,tsx}` 作为工具类来源。
开发服务仍会跟踪这些来源的变化，文档、Rust 和 Apple 原生目录不再成为样式扫描来源。
以后把带有 Tailwind 工具类的 UI 移到 `src` 之外时，需显式更新该来源配置。

2026-10-03 的本机隔离诊断中，原配置的 CSS 初始化耗时约 18.6 秒，其中约 18.1 秒
用于登记扫描依赖；限定来源后约为 0.20 秒。使用全新 Vite 缓存和隔离 Chromium，
前端入口加载从约 22.7 秒降到 2.26 秒。这些是单次诊断值，不是性能预算，
也不包含 Rust 编译、原生窗口创建、数据库打开或实际项目加载。

同一变更重新生成上述开发/生产启动占位报告，验证样式构建、加载反馈和 React 接管。
报告不将诊断耗时当作完整应用冷启动验收。
