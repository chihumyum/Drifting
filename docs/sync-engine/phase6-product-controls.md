# Sync product controls

The Drive-specific product controls and their evidence were retired on 2026-10-28.
The current App uses Hosted account connection, discovery, retry, pause/resume,
disconnect and sign-out. The local data settings continue to expose readable
exports, projection, snapshots and library backup.

See [Hosted behavior](../hosted-sync/README.md), [library backup](../library-backup.md)
and [the cleanup audit](../client-onboarding-and-hosted-readiness.md). Git history
retains the former Google Drive UI and physical acceptance plans; they are not
current release gates.
