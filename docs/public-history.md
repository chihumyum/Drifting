# Public history provenance

The public repository was derived from a private monorepo at source revision
`7d05de519c82db2067a06f527d64bcbb2f08fb18`.

The rewrite follows the client through four repository layouts: `frontend/`,
`core/`, a short root-level desktop-client period, and a later nested client
directory. Those paths were normalized to the public repository root. Server,
retired web, landing-site, prototype, deployment, cache, credential, private
corpus, and unpublished literary paths were omitted. Personal email addresses
and local machine identifiers were normalized, and Claude co-author/generated-
message trailers were removed at the maintainer’s request.

The extracted history contains 680 pre-publication commits and 13 merge
commits. Empty commits created by filtering were pruned. A separate public
preparation commit adds licensing, synthetic fixtures, standalone workspace
metadata, documentation, and CI. Commit hashes and some merge topology
therefore differ from the private monorepo.

This disclosure describes provenance; it does not expose the private source
mapping, original commit hashes beyond the fixed extraction anchor, or removed
material.
