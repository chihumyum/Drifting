掌上情节与时间线

v3 把时间线改回桌面的坐标语义：圆点严格落在 bookOrder / narrativeOrder 映射出的位置，作者可以把章节拉开或堆在一起，pinch 改比例；右侧条目只是圆点的投影，按拿到的空间变大变小，挤不下就聚簇。情节规划器沿用 v2。

情节规划器时间线手势表实现清单
情节规划器 · 已定（v2）
  • 横 / 竖 = 转置视图，数据不动；开关在 header，设备本地记忆。
  • 格子有自己的尺寸，加行加列只溢出不挤压；「适应」是 header 动作，让整张表正好填满后固定住。
  • 加行、加列进 header，追加在末尾；相对插入在表头菜单。
  • 表头菜单：重命名 / 移动 / 插入 / 删除。行列移动新增 mutation 一起做。
  • 点格子直接进编辑面并弹键盘。角部拖柄回到桌面端（改 cellW / cellH）；手机尺寸存本地、首次自动适应、双指捏合（横捏改宽、竖捏改高）加右下角浮动拖柄。
  • 桌面端同一套网格组件，格内直接写；Dock 只换壳。
时间线 · 已定（v3 新增标蓝）
  • 手机只做竖向，大屏设备直接走桌面 UI。保留轨道，最多 6 条。
  • v3直接复用桌面坐标体系：selectors、打散、分幕、标记、写入、拖动控制器、手势判定原样用；pinch 加轴向参数。
  • v3圆点 y = orderToPosition(order)；条目是投影，按到下一个点的距离分大 / 中 / 小 / 最小四档，放不下往下顺延并连线回圆点。
  • v3只有 pinch 缩到或堆到顺延失败时才聚簇；簇是一枚条目，点它临时放大这一段。
  • v3拖动等手势只给轨道里的圆点，条目不接排序手势；长按按 y 取最近的圆点。松手写手指位置的连续坐标。
  • 书序：未归属并进轨道。叙事时：未放置收进底部抽屉，chip 就是它的圆点，可拖出放置。
  • 点圆点或条目开菜单，条目尾「›」直达纸张。横向拖圆点换故事线不做，用菜单药丸。
  • 控件行「+」新建章节 / 幕 / 标记。打散进 ⋯，效果是把点拉成均匀间距。

附件栏 · 情节 · 桌面同步重构 · 同 v2

附件栏 · 时间线 · 仅竖屏 · 坐标复用桌面

把桌面时间线的横轴竖过来，坐标一个不改。轨道区里圆点的 y 就是 orderToPosition(order)：打散后相邻章节间隔 100px（比例 1.0），作者堆在一起就是几像素，拉开就是几百像素，pinch 改比例。幕边界和时间标记也落在各自精确的 y 上，在轨道区是一条横线。

右侧条目不占坐标，它是圆点的投影。每个条目按到下一个圆点的距离决定档位：大（带摘要）、中、小、最小；放不下就往下顺延，并用一根细线连回自己的圆点。只有顺延也顶不住时才把一段合成簇。所有手势只给圆点，条目只负责被看和被点。
