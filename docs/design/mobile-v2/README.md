# 移动端 v2 设计画板(空阔文房)

移动端 UI 重设计的画板源文件,与 Claude Design 画布保持同步。画布是评审与改样式的工作台,repo 里的这份是持久化快照;两边不一致时以画布上最近一次定稿为准,由 Claude 同步回这里。

- 每个 `*.dc.html` 是一块画板:自包含的 HTML + 内联样式,可直接用浏览器打开单板预览(顶部引用的 `support.js` 只在画布内解析,本目录不包含,忽略报错即可)。
- `canvas.json` 记录画板在画布上的分页、位置与批注。批注里写着交互机制(总览双形态阈值、圆点规则、header 骨架等),是画板之外的设计决定,同样是权威内容。

## 设计令牌

与 `src/styles` 对齐:纸色 `hsl(30 8% 96.5%)`,墨色阶 ink-1..5,强调色 `hsl(218 22% 52%)`,UI 字体 Inter Tight,正文宋体衬线;组件左侧一律不用彩色竖条,实体颜色只经由药丸描边与浅底表达。

## 情节规划器与时间线 v3（2026-09-06）

`plot-timeline-proto-v3.html` 是附件栏「情节」「时间线」两个工具的定稿原型：自包含 HTML，直接用浏览器打开即可，不是画布画板；画布上 `PaperToolsC` 与 `ToolsC` 里关于这两个工具的部分由它取代。原型里每块屏下面带标注，末尾有手势表、填满规则和实现清单。

定稿要点：

- **情节规划器**：横 / 竖 = 转置视图，数据不动，但整张表连格子一起转：宽高互换、比例取倒数（存的是横向坐标系下的尺寸和比例），开关在 header、设备本地记忆。格子有自己的尺寸，加行加列只溢出不挤压，超出的轴滚动，表头随表一起滚走、不钉住；「适应」是 header 里的动作，让整张表正好填满后固定住；手动改过比例（拖柄 / 捏合）后，比例按表存设备本地，之后的「适应」保持该比例只缩放：接近均衡就整表缩放到刚好装下，比例悬殊（超过 1.5×）就只适应短边、长边溢出滚动；桌面用同步的 cellW / cellH 并保留角部拖柄，手机尺寸存设备本地、首次打开自动适应、双指捏合调节（横捏改宽、竖捏改高、斜捏整体），手机不设拖柄。＋行 ＋列放在 header，追加末尾。表头菜单：重命名 / 移动 / 插入 / 删除，行列移动新增 `row.move` / `column.move` mutation 与 writer。点格子直接进底部编辑面并弹键盘。角部拖柄回到桌面端，cellW / cellH 仍由桌面写入；手机尺寸存本地不同步。桌面端用同一套新网格组件重构，格内直接写，Dock 只换壳。
- **时间线**：手机只做竖向，大屏设备直接走桌面 UI。直接复用桌面坐标体系（selectors、打散、分幕、标记、写入、拖动控制器、手势判定原样用，pinch 加轴向参数，比例 0.5–3×）。轨道区圆点 y = orderToPosition(order)，轨道最多 6 条。右侧条目是圆点的投影：按到下一点的距离分 大 ≥120 / 中 64 / 小 36 / 最小 24 四档，放不下往下顺延并连线回圆点，连续三个及以上条目挤在一起顺延时才聚簇，点簇原地临时放大。手势只给轨道区：长按按 y 取最近圆点拖起，松手写手指位置的连续坐标；幕边界把手与标记圆头同法；条目只接点按，点圆点或条目开菜单，条目尾 › 直达纸张。书序里未归属并进最右虚线轨道；叙事时里未放置收进底部抽屉，chip 即圆点，可拖出放置。打散进 ⋯，效果是把点拉成等距。
- **实现时**：`mobile-ui-foundation.md` 中「底部工具面挂载共享 BottomTimeline」的契约与 mobile-v2-planning、tool-workspaces 验收需随之改写。
