# 移动端 v2 设计画板(空阔文房)

移动端 UI 重设计的画板源文件,与 Claude Design 画布保持同步。画布是评审与改样式的工作台,repo 里的这份是持久化快照;两边不一致时以画布上最近一次定稿为准,由 Claude 同步回这里。

- 每个 `*.dc.html` 是一块画板:自包含的 HTML + 内联样式,可直接用浏览器打开单板预览(顶部引用的 `support.js` 只在画布内解析,本目录不包含,忽略报错即可)。
- `canvas.json` 记录画板在画布上的分页、位置与批注。批注里写着交互机制(总览双形态阈值、圆点规则、header 骨架等),是画板之外的设计决定,同样是权威内容。

## 页面

**page-1 现状**(迁移前的界面基线):`Shelf` 书架 · `ProjectHome` 项目主页 · `PaperRead` 纸张阅读 · `Main` 纸张编辑 · `Search` 纸内搜索 · `Overview` 纸张总览。

**page-2 重设计提案**(空阔文房):

| 画板 | 内容 |
| --- | --- |
| `ShelfC` | 书架:横滑切项目,页点可展开为列表 |
| `HomeC` | 项目主页:单层 header(总览+设定居右),一条内容流,底部常驻 tab 栏 |
| `OverviewC` | 纸张总览 ≤4 张:横向纸叠 |
| `OverviewD` | 纸张总览 >4 张:上下两排横滚,双排圆点计数 |
| `StructC` | 章节浮层:底部 tab 栏点击拉起的近全屏结构层(承接桌面左栏) |
| `ReadC` | 纸张静止/阅读:角落 chrome + folio,底部 tab 栏(阅读下滑收起) |
| `EditC` | 纸张专注编辑:无顶部 chrome,键盘附件条只剩格式+收起+字数 |
| `ToolsC` | 纸张工具面:右上按钮拉起,素材库/统计/查找(承接桌面右栏) |
| `Pills` | 实体药丸组件:归属色描边+浅底,glyph 对齐桌面 Tab 字符(§ ❦ ¶ ◆ ⌘ ☰) |

## 设计令牌

与 `src/styles` 对齐:纸色 `hsl(30 8% 96.5%)`,墨色阶 ink-1..5,强调色 `hsl(218 22% 52%)`,UI 字体 Inter Tight,正文宋体衬线;组件左侧一律不用彩色竖条,实体颜色只经由药丸描边与浅底表达。
