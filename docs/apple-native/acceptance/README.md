# First batch acceptance scope

`inventory.json` is generated by `pnpm apple:inventory`; it checks capability
mapping, source existence, source ownership and current file hashes.
`p1-native.json` is generated by `pnpm apple:acceptance` and records actual Rust,
Xcode and UI test execution. Its runtime fingerprint excludes prose status
updates but includes native source, fixtures, bridge, migrations and test runner.
Regenerate evidence after changing its inputs; never manually change a status.

The first batch was checked on 2026-09-25 with Xcode 27 and Rust 1.96.0:

- Shared database: 18 tests, including published-prefix upgrades, safety
  snapshots, tamper rejection, transaction ownership and seven SIGKILL stages.
- Fixture-only C ABI: 2 tests, including Unicode save/reopen, closed handles,
  malformed requests and refusal of ordinary library-directory input.
- Existing Tauri native suite: 90 passed, 1 ignored. `cargo check --all-targets`
  also passed after extraction. No new Tauri-window manual acceptance is claimed.
- Existing frontend suite: 2,989 passed, 1 skipped, 0 failed on a full run with
  two workers. An earlier run concurrent with native compilation had two timing
  failures; both focused and full reruns passed without changing thresholds.
- `ci:contract:check`, `public:check`, lint, typecheck and Agent capability
  checks passed. Lint retains existing warnings. Agent conversation evidence
  was regenerated, now testing the extracted database separately as well.
- Native Mac, iPhone simulator and iPad simulator each exercise editing the
  synthetic project name, saving, reopening and terminating/relaunching the app.
  The generated report is the authority for their execution and platform version.
- The Mac window and the iPhone simulator screenshot were inspected. Chinese
  and emoji project-name save/reopen were also exercised through the Mac UI.
  This is not Chinese IME composition acceptance or a prose-editor test.

Automatic desktop screenshots/recording are disabled in the generated schemes;
only the isolated iOS simulator has an explicit screenshot attachment. Raw
local test artifacts and diagnostic logs are ignored. No account, author
manuscript or production-library data is used. Added CI lanes have been
configured in source; hosted CI has not run for this uncommitted batch.
Verbose simulator diagnosis collection is disabled after it stalled a passing
test run. The final report comes from a complete rerun and verifies that its
runtime fingerprint stayed unchanged throughout execution.

P2 Yrs/editor/IME/undo/anchors, physical devices, real accounts, minimum-OS
execution, Intel packaging and signed distribution remain open. The unsigned
iPhone device-target build proves compilation only.

The default runner now excludes desktop XCTest; it is opt-in with `--macos-ui`

and mark omitted desktop XCTest `not-run`. The user subsequently authorized
desktop interaction; the failing input path still needs repair before repeated
reruns can be useful. Earlier successful runs remain
historical evidence; future desktop input acceptance still needs repair or a
different verified test method. No system permissions or preferences were changed.

## P2b first native binding slice

`p2b-binding.json` is generated by `pnpm apple:binding:acceptance`. It runs the
real Swift queue and Rust ABI against a temporary synthetic SQLite database,
including rapid Unicode input, local undo/redo, marked-text commit, reopen and
programmatic AppKit delegate input. It does not synthesize desktop events.
The bridge now has four tests, including document history/metadata after reopen
and retaining a failed save until retry. The document harness also covers native
global UTF-16 projection, stale-revision rejection and atomic replacement.

`p2b-native.json` is generated by `pnpm apple:acceptance
--output=docs/apple-native/acceptance/p2b-native.json`. Its simulator suites now
include project-name persistence and prose edit/undo/redo/reopen/process restart.
The old `p1-native.json` failure remains historical evidence. Consult the status
and fingerprint in each generated file for actual executed acceptance.

At the first binding slice, the P2b gate still lacked paragraph split/join,
comment remapping, remote updates during composition, multi-view selection,
real IME and physical-device input. The structural follow-up below adds a
bounded part of that scope. Full snapshot writes in the lab do
not establish production revision/journal, crash, compaction or performance gates.

The 2026-09-25 first binding run passed 18 shared database tests, four bridge
tests, three document Rust tests, ten cross-language cases (including the 576
concurrent authored edits), eight headless Swift/AppKit cases, and two UI tests
on each of the iPhone and iPad simulators. Mac, simulator and unsigned iPhone
device builds passed. Simulator screenshots were inspected after restart.

Separate targeted Mac inspection used the freshly built lab application:
paste synthetic Chinese/emoji text into the prose paragraph, Command-Z,
Command-Shift-Z, reopen the database, quit and relaunch. The text and displayed
entity-link formatting survived. This is a manual native-app observation,
not a passed desktop XCTest run, real keyboard composition, or release package.

## P2b sibling structure follow-up

The document report now adds 18 cases against the actual old chapter schema,
ProseMirror commands and BlockId plugin, plus forward comment endpoint mapping
and exact mark/metadata preservation. Six document Rust tests and nine headless
Swift/AppKit cases cover the same core, including queued typing immediately
after Enter, split/join undo and the recovered relative-position offset.
The simulator suite includes Enter, structural undo/redo and separator deletion;
the generated native report determines whether the current source passed it.

Yrs is vendored with one verified `follow_redone` fix and its MIT license.
The upstream suite excludes only seven unpublished benchmark-dataset cases;
377 self-contained tests ran successfully, with one upstream ignored test.
An intermittent nested-array pending-update failure was also reproduced on an
unpatched copy. It stayed open at this slice; the subsequent sparse-replay
repair and evidence below resolve that scoped defect while retaining the
original failure in `yrs-random-array-diagnostic.json`.

Forward comment maps do not yet update durable comment history or restore it
on undo. Cross-container commands, remote composition, per-view selections,
real IME, crash/compaction and performance also remain open. The lab continues
to reject real-library directories.

The structural follow-up run on 2026-09-25 passed both iPhone and iPad simulator
suites (two cases each), 18 database tests, four bridge tests, Mac compilation,
simulator compilation and unsigned device compilation. Both restart screenshots
were inspected: prose, Chinese/emoji text, paragraph spacing and entity-link
display remained visible. Current desktop interaction could not run because the
Mac was locked; no desktop/physical-IME result is inferred from simulator tests.

The array investigation produced a three-update reproducer: client A
inserts `A` into root `probe-a`, appends `B`, then inserts `C` into independent
root `probe-b`. Applying updates in order 3, 2, 1 leaves Yrs reporting a missing
update after all dependencies have arrived. Its largest client clock advanced
over a sparse hole before that hole was filled. At the end of the structural
slice the repair existed only in an ignored scratch copy. The following batch
integrates it into the shared core with source-matched native reports.

## P2a sparse dependency replay repair

The three new deterministic native regressions failed before the patch. They
now check all arrival orders, pending checkpoints, multiple holes, duplicates,
empty updates, pending deletion and subsequent history. The document suite has
nine Rust tests and thirteen cross-language cases. Its new 36-scenario matrix
combines six orders, two input encodings and three restart stages, then edits
locally and remotely, undoes/redoes and reopens again. Visible XML prose, exact
state vectors, retained independent roots and absence of pending work all agree
once every update has arrived. Intermediate eager visibility across unresolved
same-client holes is not treated as a compatibility requirement.

The recorded `src/transaction.rs` patch retries pending data after changes to
the sparse skip set, even if the client's largest clock does not advance.
The diagnostic generator restores every patched file from the verified original
archive, checks all original file hashes, and retains a baseline failure. All
100 patched fixed-seed stress runs then passed (300 iterations each). Separate
Cargo target directories prevent accidental reuse of a baseline test binary.
The unmodified upstream regression matrix also passes 377 tests, with its one
ignored test and seven missing-asset exclusions still stated explicitly.

`p2b-binding.json` and `p2b-native.json` must match the patched source fingerprint
before this change is considered integrated into the native hosts. The overall
P2b/P2c gates, desktop keyboard/IME interaction, physical devices, accounts and
distribution remain separate.

The source-matched repair run passed all nine Swift/AppKit binding cases, the
18 database and four bridge tests, and both simulator suites (two cases each).
Mac, simulator and unsigned device builds passed. Direct Mac interaction was
still unavailable because the host was locked; its status is not inferred from
the headless AppKit or simulator results.
