  • 一张安静的稿纸，手不离键盘。输入 #、##、### 就开始一个场景、节拍或笔记；**粗体**、*斜体*、> 和 --- 边打边成形。One quiet page and the keyboard. Type #, ## or ### to start a scene, a beat or a note; **bold**, *italic*, > and --- take shape as you type.
  • 每个项目同时也是一个 Markdown 文件夹。在 Obsidian 或任何文本编辑器里改过的章节和构想，会合并回 Drifting。Every project is also a folder of Markdown files. Edit chapters and ideas in Obsidian or any text editor, and the changes merge back into Drifting.
  • 单篇或整本书都可以复制、保存为 Markdown；可以导入 .md、.txt、.docx。Copy or save any document, or the whole book, as Markdown. Import .md, .txt and .docx.

照看Tend

        
照看整本书的 AgentAn Agent for the whole book

        
    
          
  • 可以用自己的 DeepSeek、Anthropic、OpenAI 密钥，也可以登录 ChatGPT 订阅（实验性）。不用 AI 也能正常写作。Bring your own key for DeepSeek, Anthropic or OpenAI, or sign in with a ChatGPT subscription (experimental). Writing never requires AI.
    • 
          
  • Agent 能读、搜索和修改你的项目：正文、要素、关联、故事线、素材、TODO。它的改动会在正文里标出，可以从历史快照撤回。The Agent reads, searches and edits your project: prose, elements, relations, storylines, materials, TODOs. Its edits are marked in the text and can be undone from history.
    • 
          
  • 你离开一阵再回来时，它可以把上次写的内容整理进要素、补丁和关联；它不会自行改动正文。When you come back after a break, it can file what you wrote into elements, patches and relations. It never edits prose on its own.
    • 
          
  • Codex、Claude Code、Antigravity 可以通过 MCP 连接到某一个项目，默认只读。Codex, Claude Code and Antigravity can connect to one project through MCP, read-only by default.
