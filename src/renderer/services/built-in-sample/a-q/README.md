# 阿Q正传: bundled text

The second [built-in sample project](../../../../../docs/sample-project.md) is
Lu Xun's 阿Q正传 (first published 1921–22), left half written. `text.json` is
generated by `scripts/build-a-q-sample.py`; do not edit it by hand.

- `text.json`: the first six of the nine chapters, each a list of paragraphs
  (`number`, `roman` as a Chinese numeral, `title`, `blocks`). Chapters seven
  to nine are planned in `../a-q.ts` and have no text here.

The source is Wikisource's transcription of the 1948 Complete Works (魯迅全集,
volume one, scan pages 380–437), in simplified characters as Wikisource renders it.
The build keeps the chapter text only and changes nothing else but: the
edition's 『』 and 「」 become “” and ‘’; the variant 偸 becomes 偷; seven
transcription slips are corrected (`ERRATA` in the script). The 1948 edition's
own readings and punctuation stay. Lu Xun died in 1936, so the text is in the
public domain; see [ASSET_PROVENANCE.md](../../../../../ASSET_PROVENANCE.md).

To rebuild (the response fetched on 2026-11-06 had SHA-256
`36321c50d5d3585cd5bd1f40a8bb0330809e6e56a1bf714480f8d3a37072cba5`; later edits
on Wikisource may change it):

```bash
curl -sS -A 'Drifting-sample-builder/1.0' -o a-q.json \
  'https://zh.wikisource.org/w/api.php?action=parse&page=%E9%98%BFQ%E6%AD%A3%E5%82%B3&prop=text&format=json&formatversion=2&variant=zh-hans'
python3 -I scripts/build-a-q-sample.py a-q.json
A_Q_WIKISOURCE_JSON=a-q.json pnpm exec vitest run src/renderer/services/built-in-sample/a-q.test.ts
```

The last command rebuilds into a temporary directory and checks that
`text.json` is byte-identical.
